# 病患淨推薦值

病患淨推薦值（NPS）衡量的是病患向他人推薦某數位健康產品或遠距醫療服務的意願，基於一個單一的調查問題——"您向朋友或同事推薦該服務的可能性有多大？"——以0到10分計分。得分9-10分的受訪者為"推薦者"，7-8分為"被動者"，0-6分為"貶損者"；NPS即推薦者百分比減去貶損者百分比。這是數位健康領域使用最廣泛、也是被批評最多的病患滿意度指標，因其簡單性而受到重視，但其單獨診斷問題的能力也有侷限。

## 為何重要

NPS為數位健康團隊提供了一個簡單、標準化、可跨機構比較的滿意度訊號，採整合本低廉，非專業利益相關方（高管、董事會、委託方）也能一目瞭然地理解，這正是儘管其方法論侷限已被充分記錄，它仍然廣受歡迎的原因。對於遠距醫療和數位前門產品而言，NPS往往是判斷當兩者都可用時，病患是否會繼續選擇數位渠道而非面對面替代方案的領先指標，這對渠道組合規劃和容量安排具有直接影響。然而，NPS是一個高度概括的單一數位：下降的NPS會告訴團隊出了問題，但不會告訴團隊問題是什麼，因此應始終與開放式文字反饋或更細緻的可用性工具配對，才能具有可操作性，而不僅僅是一個記分卡數位。

## 計算方法

```
NPS = 推薦者百分比（評分9-10）− 貶損者百分比（評分0-6）

結果是一個從 −100 到 +100 的數位，而非百分比，儘管它由
百分比推導而來——切勿在NPS數位後附加"%"符號。

應一併報告：
  應答率（受訪病患中做出應答的百分比）
  樣本量
  所使用的確切問題措辭
```

## 實例解析

某遠距醫療平臺在一次視訊問診後對1000名病患進行調查，收到400份應答（應答率40%）。在這400名應答者中，220人評分9-10（推薦者，55%），100人評分7-8（被動者，25%），80人評分0-6（貶損者，20%）。NPS為55 − 20 = 35。這一數位只有在特定情境下才有意義：35分的NPS，與更廣泛的遠距醫療行業相比可能是一個強勁的結果，也可能是與該平臺自身上一季度48分的分數相比出現的令人擔憂的下滑——將NPS用作單一產品隨時間推移的趨勢，遠比用作與不同產品進行一次性絕對基準比較更為有用。

## 資料來源與注意事項

NPS透過接觸後的調查採集，通常在視訊問診、應用會話或護理事件結束後立即觸發，應答率極為重要：過低的應答率（遠低於實例解析中所見的約40%）存在無應答偏倚的風險，即只有非常滿意或非常不滿意的病患才願意應答，從而將分數拉向極端，偏離人群的真實情緒。只有在問題措辭、時間安排和調查人群確實具有可比性的情況下，跨機構甚至同一機構不同渠道（例如遠距醫療與面對面）之間的NPS比較才具有效力；已知即使是微小的措辭變化也會可測量地改變分數。應將NPS視為需要被解釋的結果，而非目的本身——通常伴隨NPS調查出現的開放式評論通常比分數本身更具可操作性。

## 常見誤區

- **比較使用不同問題措辭或時間安排收集的NPS數位**：即使是微小的調查設計差異也可能使分數產生數個點的偏移，這使得跨機構NPS基準比較遠不如表面看起來那麼可靠。
- **忽視應答率**：根據10%應答率計算出的頭條NPS，其可信度遠低於根據60%應答率計算出的NPS，因為低應答率容易產生偏向最極端意見的無應答偏倚。
- **將NPS視為診斷工具而非概括性指標**：下降的NPS總是會說明有問題，但從不說明是什麼問題；應始終配以定性反饋或更細緻的滿意度或可用性工具，以找出原因。
- **將NPS本身作為追逐的目標**：狹隘地針對NPS數位進行最佳化（例如僅在異常積極的互動後才對病患進行調查）可能會改善所報告的分數，而潛在的病患體驗卻毫無改善，甚至實際上更差。
