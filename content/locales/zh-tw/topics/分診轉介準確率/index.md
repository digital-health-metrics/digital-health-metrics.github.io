# 分診轉介準確率

分診轉介準確率是指在病患接觸中，自動化或AI輔助分診工具依據經臨床驗證的參照標準，正確地將病患轉介至適當護理級別和場所——例如自我護理、初級護理、緊急護理或急診護理——的比例。這是任何數位前門、症狀自查工具或AI分診系統的安全性與有效性指標：這類工具的全部價值主張都建立在能否準確、快速且一致地轉介病患之上。

## 為何重要

分診不準確會在兩個方向上造成傷害：分診不足（將病患轉介至低於其實際需要的護理級別）可能延誤真正急症的治療，而分診過度（將病患轉介至高於其實際需要的護理級別）則會浪費稀缺的急診和緊急護理資源，並在沒有臨床獲益的情況下增加成本和病患焦慮。由於這兩種失敗模式的後果如此不同，分診轉介準確率應始終與錯誤方向一併報告，而不是作為一個掩蓋工具究竟是安全偏差還是危險偏差的單一綜合準確率數位。評估AI分診工具是否可用於部署的監管機構和醫療系統，越來越要求這種分層準確率報告作為臨床批准的條件，尤其是對於具有一定自主性、脫離臨床醫師監督的工具。

## 計算方法

```
分診轉介準確率 = 正確轉介的接觸數 / 分診接觸總數 × 100

分別報告分診不足率與分診過度率：
  分診不足率 = 轉介至低於參照標準急重程度的接觸數 /
              分診接觸總數 × 100
  分診過度率 = 轉介至高於參照標準急重程度的接觸數 /
              分診接觸總數 × 100

參照標準通常是對同一病例進行的回顧性臨床醫師審查，
並儘可能對工具的輸出結果保持盲態。
```

## 實例解析

一款AI症狀自查工具在一個月內對5000次病患接觸進行了分診。對其中500次接觸進行隨機抽樣的盲態臨床醫師審查發現，430次被轉介至正確的急重程度（準確率86%），45次分診不足（9%），25次分診過度（5%）。9%的分診不足率是最需要立即調查的數位，因為它代表了病患可能被轉介至比實際所需更低急迫程度護理的接觸；5%的分診過度率則是一個容量與成本問題，而非直接的安全問題。

## 資料來源與注意事項

用以衡量分診準確率的參照標準至關重要：由單一臨床醫師進行的審查會引入該醫師自身的判斷差異，因此可信的準確率數位通常需要多名獨立審查者並記錄評分者間一致性，或者與後續確認的臨床結果（病患實際需要的護理，事後確定）進行比較。抽樣方式同樣重要：僅審查方便獲取的樣本，或僅審查被標記為異常的病例，都不會得出能夠代表該工具整體表現的數位。在病例量允許的情況下，應按就診症狀或主訴類別分別報告準確率數位，因為分診工具在所有病種上的表現很少是均一的。

## 常見誤區

- **報告單一混合準確率數位**：將分診不足和分診過度合併為一個數位，會掩蓋工具的錯誤是偏向更危險的失敗模式，還是偏向另一種；應始終分別報告。
- **使用單一、非盲態的審查者作為參照標準**：這可能會悄悄地使準確率數位偏向該審查者自己會做出的判斷，而非獨立的臨床標準。
- **僅根據回顧性、便利性資料進行驗證**：工具在實際、模糊病患輸入下的真實轉介準確率，通常與其在開發過程中收集的經過整理的驗證集上的準確率存在實質差異。
- **忽視部署後的效能漂移**：隨著病患人群、就診症狀或護理路徑可用性的變化，AI分診模型的準確率可能隨時間推移而下降；應定期重新測量準確率，而非驗證一次後即假定其保持穩定。
