# 投資回報率（ROI）與投資價值（VOI）

投資回報率（ROI）是指數位健康平臺相對於其總成本——許可、硬體部署、實施與持續人員配置——所產生的淨財務回報，以比率或百分比表示。投資價值（VOI）是一項更廣泛的配套指標，用以捕捉純財務ROI計算無法捕捉的回報：護理品質的改善、病患與臨床醫師的滿意度、健康公平影響，以及機構聲譽，這些都無法乾淨地轉化為一個美元數位，但都關乎一項數位健康投資是否應被視為成功。兩者共同回答兩個不同但互補的問題：ROI問的是"這在財務上是否自負盈虧？"；VOI問的是"考慮到所有重要因素，這是否值得去做？"

## 為何重要

如果ROI計算忽略了專案在純粹成本抵消之外所產生的實質性價值，一項在第一年顯示出較差或負ROI的數位健康投資並不自動等同於失敗，一項顯示出強勁ROI的投資也不自動等同於成功——而這正是VOI存在的意義所在，僅依賴ROI的機構可能面臨撤資風險，撤掉那些具有真實價值、只是尚未（或永遠不會）以直接財務回報形式體現的專案。與此同時，VOI比ROI更主觀、更難以基準化，這使其容易被用來為一個實際上並未產生任何可衡量價值的專案的持續投資提供辯護；將兩者一併報告的這種紀律——儘可能使VOI的構成要素具體化、可衡量化——正是使這一框架保持誠實、而非成為規避財務問責手段的關鍵。長期數位健康投資決策——尤其是在品質與公平結果直接與支付掛鉤的基於價值的醫療中——越來越需要將這兩個數位並列呈現。

## 計算方法

```
ROI = (財務收益 − 總投資成本) / 總投資成本 × 100

財務收益來源：單次護理事件成本降低、床日減少量（轉化為
成本數位）、避免的急診就診（參見急診科分流率）、再入院
罰款減少，以及任何直接收入。

總投資成本：平臺許可、硬體/裝置部署與維護、實施與整合
成本、持續的臨床與技術人員配置。

VOI並非單一公式，而是一個結構化的多維度記分卡，將ROI與
已定義、可追蹤的非財務價值領域相結合，例如：
  臨床品質     （例如生物指標改善率、再入院率）
  病患體驗     （例如病患淨推薦值、SUS得分）
  公平性       （例如數位可及率、數位素養率）
  勞動力       （例如醫師職業倦怠率）
每個領域均按其自身標準報告，而非人為轉化為美元數位，與
財務ROI數位並列呈現。
```

## 實例解析

某遠端監測專案在第一年花費60萬美元（平臺許可、裝置部署和額外臨床人員配置），產生了75萬美元的可量化財務收益（床日減少量和避免的再入院罰款）。ROI為(75萬 − 60萬) / 60萬 × 100 = 25%。在此數位之外，該機構的VOI記分卡報告病患淨推薦值提高了5個點，登記高血壓病患的生物指標穩定率為68%，以及登記臨床醫師非工作時間文書記錄時間的可測量減少。這三項額外發現均未改變25%的ROI數位，但它們共同為持續投資建置了一個比單獨的ROI數位更強有力的論證，尤其是對那些同樣重視品質和公平結果與財務回報的利益相關方（臨床領導層、病患權益團體）而言。

## 資料來源與注意事項

ROI的財務收益一方，借鑑了本書其他部分使用的相同成本與結果資料——單次護理事件成本、床日減少量、急診科分流率——使用機構自身的成本核算方法轉化為美元數位，應使用保守、可辯護的假設，而非樂觀的最佳情況假設，因為基於激進假設建置的ROI數位無法經受住持懷疑態度的財務團隊的審查。VOI的每個非財務領域都應使用本書其他部分已經過驗證的指標（生物指標穩定率、病患淨推薦值、數位可及率、醫師職業倦怠率），而非非正式發明的替代指標，這樣VOI記分卡本身才能保持可審計性，並能隨時間進行比較，而不會淪為定義鬆散的敘述。

## 常見誤區

- **對具有實質性非財務價值的專案僅報告ROI**：這可能僅因某項價值未體現在純財務計算中，就冒著撤資真正具有臨床、公平或勞動力價值的專案的風險；應將ROI與結構化的VOI記分卡配對。
- **將VOI用作規避財務問責的手段**：VOI應為每個非財務領域使用具體的、已驗證的指標，而非模糊或未經測量的價值主張，否則它會成為一種在沒有真實證據的情況下為持續支出辯護的方式。
- **在ROI的成本規避計算中使用樂觀或未經驗證的假設**：基於激進的避免成本假設建置的ROI數位無法經受審查，並可能損害未來投資案例的可信度。
- **在未經調整的情況下比較成本結構差異很大的專案的ROI數位**：不應在單一年度的ROI數位上，將前期資本成本高、回收期長的專案與前期成本低、回收快的專案進行比較，而不考慮所涉及的不同時間跨度。
