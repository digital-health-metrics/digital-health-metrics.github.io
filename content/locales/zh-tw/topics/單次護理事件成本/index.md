# 單次護理事件成本

單次護理事件成本是指治療一個特定臨床事件——例如髖關節置換手術及其相關的恢復期，或一段糖尿病管理週期——所產生的總成本，與未接受所評估數位介入的歷史基線佇列進行比較。這是基於價值的醫療中財務比較的標準單位，因為它捕捉的是一次護理事件的完整經濟全貌，而非任何單一成本專案本身，也是支付方和醫療系統在同意為某數位健康專案提供大規模資金支援之前，最常要求提供的指標。

## 為何重要

基於價值的醫療合同日益按護理事件和結果付費，而非按單項服務付費，這意味著數位健康專案的財務論證必須以同樣的貨幣來表達：與該型別護理事件在介入措施出現之前的成本相比，單次事件的總成本如何變化。一個降低了某一成本類別（例如面對面隨訪次數減少）卻增加了另一類別（更多裝置成本、更多臨床監測人員時間）的專案，並不必然降低了單次事件的總成本，只有完整的事件級成本核算才能捕捉這種權衡；孤立地看待任何單一成本項都有可能得出誤導性的結論，無論方向如何。由於事件定義和基線期可以被建置成有利於某種特定結論的方式，這項指標比本書中大多數其他指標需要更高的方法論透明度，才能在持懷疑態度的支付方或財務團隊面前具有可信度。

## 計算方法

```
單次護理事件成本 = 特定事件視窗內提供的所有護理的總成本
                    （所有護理場所、所有成本類別）/ 事件數

與匹配的歷史基線佇列在同一臨床定義事件型別上的單次事件
成本進行比較，並按病例組合（年齡、合併症、嚴重程度）在
兩個佇列之間進行調整。

應納入，而非僅限於直接臨床成本：技術平臺與裝置成本、
額外的臨床人員時間，以及轉移場所（例如從住院轉為居家）
而非完全消失的任何護理。
```

## 實例解析

某醫療系統全髖關節置換事件（手術至90天恢復期）的歷史基線成本為每例28000美元，基於200例歷史事件計算得出。引入一項新的數位化術後監測專案後，使用該專案的150例新事件顯示平均成本為每例24500美元——每例減少3500美元，主要由急診就診次數減少和住院時長縮短所驅動。在針對數位監測佇列相較歷史基線略年輕、合併症較低的病例組合進行風險調整後，調整後的節省縮窄至每例2100美元——仍是真實的改善，但明顯小於未經調整的原始比較所暗示的數位。

## 資料來源與注意事項

事件總成本通常從醫療系統自身的成本核算或財務系統中彙總，結合理賠資料、內部成本分攤，以及在涉及數位平臺的情況下，其許可與硬體成本——準確彙總這一數位通常是任何數位健康價值分析中最困難、最耗費資源的部分，因為成本經常記錄在從未被設計為能在事件層面進行合併的獨立系統中。每當數位管理佇列與歷史基線佇列並非透過真正隨機分配確定時，病例組合調整至關重要，因為數位專案往往首先提供給參與度更高、總體更健康或更有積極性的病患，這可能產生表觀的成本節省，而實際上是選擇效應，而非真實的專案效應。

## 常見誤區

- **在病例組合不同的佇列間比較未經調整的成本**：數位管理佇列若恰好比歷史基線更健康或風險更低，其單次事件成本會更低，原因與數位介入本身無關；比較前應始終進行風險調整。
- **在成本比較的"數位"一方遺漏技術與人員成本**：僅追蹤臨床利用率降低、而忽略運作數位專案的平臺、裝置和人員成本的成本分析，會高估淨節省。
- **佇列間事件視窗定義不一致**：將一個佇列的90天事件視窗與另一個佇列的60天視窗進行比較，所產生的成本比較實際上並未衡量同一件事。
- **將成本轉移視為成本降低**：從一個護理場所轉移到另一個場所的成本（例如從住院轉為受監測的居家場所）是一個真實且有價值的發現，但在分析上與完全消除的成本不同，應分別報告。
