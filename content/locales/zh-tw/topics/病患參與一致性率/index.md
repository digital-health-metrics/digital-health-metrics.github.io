# 病患參與一致性率

病患參與一致性率衡量的是登記病患隨時間與數位健康產品互動的規律程度——例如記錄飲食或症狀、記錄體育活動、或檢視健康資料——而不僅僅是是否曾經使用過。這是一項縱向指標，不同於某一時間點的活躍使用計數：兩名病患可能擁有完全相同的"本月使用過該應用"狀態，而其中一人每天堅持記錄，另一人只記錄一次便消失三週，只有一致性指標才能區分這兩者。

## 為何重要

持續、規律地與數位健康工具互動，是臨床獲益最可靠的領先指標之一，尤其對於糖尿病、體重管理和心理健康等依賴行為的病症而言，因為這類工具的價值來自其所支援的習慣，而非任何單次使用。一款產品可能報告出健康的月活躍使用者數，而實際上服務的人群只是登入一次便逐漸流失，因為月活躍使用這一門檻很低，無法說明該月內的使用模式；一致性指標能夠以簡單活動計數無法做到的方式捕捉這一點。由於一致性也是數月而非數週內更難維持的事情之一，它比容易受到入門後新奇效應影響的短視窗參與度數位，更能誠實地反映產品品質與臨床契合度。

## 計算方法

```
參與一致性率 = 至少有一次合格互動的週數 / 登記總週數 × 100

應明確且一致地定義"合格互動"（例如一次飲食記錄條目、一次
症狀簽到，或一次已完成的活動同步）——絕不應是被動事件，
如未記錄任何操作的應用開啟。

應以分佈形式報告，而非僅報告人群平均值：
  例如周一致性 ≥ 80% 的病患比例、50-79% 的比例、
  < 50% 的比例
```

## 實例解析

一款營養指導應用登記一名病患12周。該病患在其中9周至少記錄一次合格的飲食條目，其個人參與一致性率為9 / 12 × 100 = 75%。在該應用登記滿12周以上的完整2000名病患佇列中，600名病患（30%）保持周一致性 ≥ 80%，900名（45%）落在50-79%區間，500名（25%）低於50%。若僅報告佇列平均值（可能約為65%），將掩蓋整整四分之一的病患幾乎完全沒有參與的事實——這一群體值得單獨調查，而不應被稀釋進整體平均值中。

## 資料來源與注意事項

一致性資料來自產品自身的事件日誌（飲食記錄、活動同步、簽到），"合格互動"的定義對所得比率有巨大影響——寬鬆的定義（任何應用開啟）總會比嚴格的定義（完成的、有意義的記錄條目）看起來更好，因此所使用的定義必須與任何報告的數位一併明確說明。自動同步的資料（例如聯網健身追蹤器在後臺同步活動）應與手動記錄的資料分開報告，因為自動同步可能虛增表觀一致性，而不反映病患對產品指導的任何主動努力或參與。

## 常見誤區

- **將應用開啟與有意義的參與混為一談**：被動的應用開啟（例如由推送通知觸發）與已記錄的飲食條目或已完成的簽到並不相同；應僅定義並報告合格互動。
- **僅報告人群平均值**：看似健康的平均一致性率可能掩蓋了高度參與與幾乎完全不參與病患並存的雙峰人群；應報告跨一致性區間的分佈，而非僅報告平均值。
- **忽視登記時長這一分母**：在不考慮登記時長的情況下比較登記時間差異很大的病患的一致性率，會偏向於測量視窗更短、更容易維持的那一組。
- **自動後臺同步虛增比率**：被動同步的可穿戴裝置資料流，可能讓未參與的病患顯得持續活躍，而實際上並無真實行為改變或產品參與。
