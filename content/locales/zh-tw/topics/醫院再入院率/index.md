# 醫院再入院率

醫院再入院率是指出院病患在特定時間視窗內——最常見為30天——非計劃性再次入院的比例。對數位健康而言，這是與支付方經濟利益和基於價值的醫療合同最直接相關的指標：無法證明對再入院率有可信影響的遠端監測、出院後隨訪或數位化護理過渡專案，無論其參與度數位看起來多好，都不太可能獲得持續的報銷支援。

## 為何重要

非計劃性再入院成本高昂、給病患帶來困擾，而且在許多醫療系統中如今會被直接處罰：例如美國醫院再入院減少計劃（Hospital Readmissions Reduction Program）等制度，會降低對特定病種再入院率高於預期的醫院的付款，這正是醫院積極委託開發旨在降低再入院率的數位化出院後與遠端監測專案的原因。相當一部分再入院被認為是潛在可預防的——由出院指導不充分、隨訪預約錯過、用藥理解錯誤，或未被察覺的症狀惡化所導致，而設計良好的數位化接觸點本可以更早發現這些問題——這正是數位化護理過渡工具所針對的缺口。再入院率應始終結合病例組合來解讀：服務於病情更復雜、更嚴重人群的專案，其結構性基線再入院率會高於服務健康人群的專案，這與專案品質無關。

## 計算方法

```
30天再入院率 = 出院後30天內非計劃再入院數 / 指標出院總數 × 100

從分子中排除：計劃性再入院（例如預定的後續手術），以及
作為同一護理事件延續而非新入院的轉院。

在比較不同病患人群或不同時期的比率之前，應儘可能使用公認
的病例組合或合併症指數進行風險調整。
```

## 實例解析

某醫院在一個季度內為1200名心力衰竭病患辦理出院。其中210人在30天內再入院，其中15人是為預定手術進行的計劃性再入院，予以排除。非計劃性30天再入院率為(210 − 15) / 1200 × 100 = 16.25%。針對其中400名病患（按臨床風險而非隨機方式選定）引入了遠端監測專案，其非計劃再入院率為14%，而未納入專案的800名病患為18%。由於納入專案是基於臨床風險而非隨機分配，這一差異只能作為提示性證據，而非專案效果的確證性證據，應結合風險調整分析來解讀，而非直接採信表面數位。

## 資料來源與注意事項

再入院資料通常來自醫院自身的入院-出院-轉院（ADT）資料流，用於追蹤同一機構的再入院情況，但再入院至另一家醫院的病患根本不會出現在該資料流中，因此僅依靠單一醫院的再入院追蹤會系統性地低估真實再入院率，除非輔以區域健康資訊交換資料、支付方理賠資料或州級全支付方資料庫。將再入院歸因於某個數位化專案需要謹慎：自願加入遠端監測專案的病患很少是出院人群的隨機樣本，因此對已加入與未加入病患的再入院率進行簡單比較，往往會受到正是那些促使部分病患更傾向於加入專案的選擇效應的干擾。

## 常見誤區

- **比較未經風險調整的原始比率**：服務於病情更重人群的專案會顯示出比服務健康人群的專案更高的原始再入院率，即使該專案本身更有效也是如此；比較前應始終進行風險調整。
- **低估轉至其他機構的再入院**：僅依賴單一醫院自身的ADT資料會遺漏轉至其他機構的再入院情況，從而低估真實比率，尤其是在存在多個競爭性醫院系統的地區。
- **自願專案加入中的選擇偏倚**：選擇加入數位化隨訪專案的病患，在健康素養、社會支援或積極性方面往往與未加入的病患存在系統性差異，這會干擾任何簡單的前後對比或加入/未加入對比。
- **將所有返回同一機構的情況都計為再入院**：計劃性、預定的再入院（例如預定的第二階段手術）並非出院失敗的訊號，應從分子中排除，而不應與真正的非計劃返回混為一談。
