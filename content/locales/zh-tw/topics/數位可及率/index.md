# 數位可及率

數位可及率是指符合條件的病患人群中，具備使用數位健康產品實際能力的比例：可靠的寬頻或移動資料連線、具備聯網能力的裝置，以及相關病患門戶或應用程式的有效賬戶。這是本書中所有其他數位健康指標的前提條件指標——無論產品設計得多好，一個在結構上無法觸及某產品的人群，都無法註冊、參與或從中獲益。

## 為何重要

數位健康的採納與參與度指標隱含地假定人群已經擁有數位可及性，在未先確立基礎可及率的情況下報告採納率或參與度，有可能悄悄地排除那些最不可能擁有該可及性的病患——而這些病患往往也是健康需求最大的病患。HIMSS數位健康公平衡量框架（DHEMF）等類似框架，將數位可及性視為一項基礎性、第一位的公平指標，正是因為未考慮可及性差距而建置的介入措施，往往會加劇而非縮小既有的健康差距：以遠距醫療為先的策略可能無意中降低了沒有可靠連線或裝置的病患的護理可及性，即使它同時可衡量地改善了已經擁有兩者的病患的體驗。應按人口統計和地理細分追蹤並報告數位可及率，因為全國性或機構層面的平均值經常性地掩蓋了特定人群的巨大差距。

## 計算方法

```
數位可及率 = 同時具備寬頻/移動連線、聯網能力裝置，及有效
              病患門戶或應用賬戶的病患數 / 符合條件的病患
              總人數 × 100

除綜合比率外，應分別報告每個子要素：
  連線率           = 擁有可靠網際網路連線的病患數 /
                    符合條件人數 × 100
  裝置擁有率       = 擁有聯網能力裝置的病患數 /
                    符合條件人數 × 100
  門戶啟用率       = 擁有有效門戶/應用賬戶的病患數 /
                    符合條件人數 × 100（關於更完整的
                    採納漏斗，參見病患門戶採納率）
```

## 實例解析

某醫療系統服務40000名符合條件的病患。病患調查與基礎設施資料顯示，34000人（85%）擁有可靠的寬頻或移動連線，33000人（82.5%）擁有聯網能力裝置，而在同時滿足這兩個條件的病患中，27000人（佔符合條件總人數的67.5%）擁有有效的病患門戶賬戶。按年齡細分顯示，65歲以上病患的綜合數位可及率僅為48%，而65歲以下病患為78%——這一差距被67.5%的機構整體平均值完全掩蓋，而這一差距本應直接指導是否可以為該人群安全地提供純數位化服務的決策。

## 資料來源與注意事項

連線性與裝置擁有資料通常來自病患自報（透過調查或接診問卷）、美國聯邦通訊委員會（FCC）或同等機構針對病患所在地理區域的國家寬頻可用性地圖資料，以及機構自身系統的門戶啟用資料的組合。區域層面的寬頻可用性（某提供商是否在特定郵政編碼區域提供服務）是比家庭層面連線性更弱的代理指標，因為區域層面的可用性資料並不能說明某個特定病患是否能夠負擔得起或是否已選擇訂閱該服務——不應將區域層面與家庭層面的可及率混為一談。裝置和連線的可及性也可能在家庭內共享（例如，一部智慧手機被多個家庭成員使用），家庭層面的調查資料比單獨的個人層面門戶登入資料更能捕捉這一點。

## 常見誤區

- **僅報告機構整體平均值**：這可靠地掩蓋了老年、低收入、農村或其他數位邊緣化病患細分群體的巨大可及性差距；應始終按人口統計和地理細分進行報告。
- **將區域層面的寬頻可用性與實際家庭可及性混為一談**：某郵政編碼區域被寬頻提供商"覆蓋"，並不意味著該區域內的每個家庭都訂閱或能負擔得起該服務。
- **將裝置擁有視為靜態的一次性事實**：裝置可及性可能是暫時性的（裝置老化、手機丟失或損壞、共享的家庭裝置被重新分配），因此應定期測量可及率，而非在評估一次後便假定其保持不變。
- **在確立受影響人群的可及率之前設計純數位化路徑**：在未先確認目標人群實際數位可及率的情況下，將某項服務轉為純數位化，有可能悄悄排除那些最無法觸及替代渠道的病患。
