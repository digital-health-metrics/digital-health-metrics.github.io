# 行銷效率比率

行銷效率比率（MER）是特定期間內，總收入除以所有渠道的總行銷支出。它的存在是為了對平臺報告的廣告支出回報率（ROAS）進行有意的獨立現實核查——ROAS衡量的是每個渠道自我聲稱對收入的貢獻，在結構上容易高估自身貢獻——而MER則轉而將總收入與總支出進行比較，這一數位無法被任何單一廣告平臺扭曲。

## 為何重要

每個廣告平臺都使用自己的歸因模型報告ROAS，由於大多數機構同時運作多個渠道，同一名轉化客戶常常被不止一個平臺記功，因此各平臺自我報告的ROAS之和，與實際總收入相比，經常性地高估了行銷的總體貢獻。MER透過在機構層面比較總收入與總支出，完全繞過了這個問題，使其更難透過歸因博弈或平臺有利的報告方式來扭曲，這正是財務和高管團隊越來越將其視為可信的整體效率核查標準、並以此校準單一平臺報告數位的原因。一個在每個單一渠道上都報告出強勁ROAS的行銷團隊，如果整體MER卻在下降，說明存在真實的效率或歸因重疊問題，而僅靠渠道層面的報告無法揭示這一點。

## 計算方法

```
MER = 總收入 / 總行銷支出（所有渠道，同一期間）

與ROAS不同，MER並非按渠道計算——它是一個機構層面的單一
數位，正因為其價值來自於不受任何單一平臺歸因主張的影響。

在支出穩定或增長的情況下，MER隨時間上升表明整體行銷效率
正在改善；收入增長而MER持平，可能表明增長來自非行銷驅動
的來源（例如轉介、自然搜尋、口碑）。
```

## 實例解析

某數位健康公司在一個季度內產生了240萬美元的收入，所有付費渠道的總行銷支出為48萬美元。MER為240萬 / 48萬 = 5.0。單獨來看，付費搜尋平臺報告ROAS為6.0，付費社交平臺報告ROAS為5.5，程式化展示廣告平臺報告ROAS為4.0——如果將這些數位簡單相加作為對總收入貢獻的主張，其暗示的歸因總收入將超過公司實際產生的收入，因為相當一部分轉化客戶接觸了不止一個渠道，被重複計算了兩次或三次。機構層面5.0的MER正是化解這一問題的數位：它無法像渠道層面的ROAS數位那樣，在結構上被歸因重疊所虛增。

## 資料來源與注意事項

總收入來自機構自身的財務或計費系統，總行銷支出來自跨所有渠道實際開票並支付的行銷成本——兩者都應獨立於任何廣告平臺自身的儀表盤進行核算。應將MER作為隨時間推移的趨勢來追蹤，而非以單一通用基準來評判，因為"良好"的MER因商業模式、利潤結構和增長階段而異極大：早期公司可能有意接受比成熟公司更低的MER，以大力投資增長，而後者則更注重最佳化盈利能力。MER本身無法診斷哪個渠道是效率變化的原因——這種診斷工作仍需要渠道層面的分析，理想情況下輔以增量測試（不接觸任何行銷的對照組），而非僅依賴平臺報告的歸因。

## 常見誤區

- **將平臺報告的ROAS視為可跨渠道相加**：每當一名客戶接觸並被不止一個渠道記功時（這種情況很常見），將各平臺自我報告的ROAS相加會高估行銷的總體貢獻；MER在設計上避免了這一點。
- **將MER與固定的通用基準進行比較**：合適的MER因商業模式、利潤和增長階段而異；應將其用作單一機構隨時間推移的趨勢，而非固定的達標/未達標閾值。
- **將MER用作渠道層面的診斷工具**：MER在設計上是一個機構層面的數位，本身無法識別哪個渠道正在驅動效率變化；應為此目的將其與渠道層面的分析和增量測試配對。
- **忽視非行銷收入驅動因素**：收入增長而MER持平或改善，可能反映的是自然增長（轉介、口碑、贏得的媒體曝光），而非行銷效率；應在可能的情況下按獲取來源拆分收入，以避免過度歸功於行銷。
