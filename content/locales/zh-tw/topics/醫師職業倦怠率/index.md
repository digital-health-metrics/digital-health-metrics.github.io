# 醫師職業倦怠率

醫師職業倦怠率是指報告顯著職業倦怠症狀的臨床醫師比例——通常透過經驗證的調查工具評估情緒衰竭、去人格化，或個人成就感低落——而對數位健康而言，這一指標特別與面向臨床醫師的數位工具負擔衡量指標一同追蹤，例如用於文書工作或電子健康檔案（EHR）記錄的時間。之所以將其納入數位健康指標框架，是因為設計不良的臨床軟體已被證實是職業倦怠的一個可衡量的促成因素，絕不應僅憑面向病患的指標來評估數位健康工具的成功，而忽視其對必須操作它的臨床醫師所造成的影響。

## 為何重要

數位健康工具經常以減輕臨床醫師行政負擔為明確目標而被引入，但設計不良的電子健康檔案工作流程、過多低價值的臨床警報（參見臨床警報忽略率），或笨拙的遠距醫療介面，同樣容易增加職業倦怠，而非減輕它——一款改善了面向病患參與度指標、卻悄悄增加了臨床醫師文書負擔的工具，並未為整個護理系統帶來淨正面的結果。職業倦怠在臨床文獻中與醫療差錯、臨床醫師流失和護理品質下降密切相關，因此它是下游安全與勞動力可持續性問題的領先指標，而不僅僅是工作場所滿意度方面的細枝末節。任何聲稱減輕臨床負擔的數位健康專案，都應能夠依據已測量的基線來證明這一主張，而非僅將其作為設計意圖來斷言。

## 計算方法

```
醫師職業倦怠率 = 得分超過經驗證工具倦怠閾值的臨床醫師數 /
                  接受調查的臨床醫師總數 × 100

常用的經驗證工具：馬斯拉赫職業倦怠量表（MBI）、職業成就
感指數，或經過與更完整工具驗證的單項倦怠篩查問題。

應一併報告可用的數位負擔代理指標：
  每次病患接觸的EHR系統內停留時間
  發生在預定臨床工作時間之外的文書記錄時間（"睡衣時間"）
```

## 實例解析

某醫院系統在引入一款旨在減少筆記書寫時間的環境臨床文書記錄工具之前，使用馬斯拉赫職業倦怠量表對300名醫師進行調查。基線資料顯示，135名醫師（45%）得分超過倦怠閾值，EHR審計日誌資料顯示，每位醫師每天平均有58分鐘的文書記錄時間發生在預定臨床工作時間之外。該工具推出六個月後，對同一批醫師的重複調查發現，108人（36%）超過倦怠閾值，同時非工作時間文書記錄時間降至每天34分鐘。倦怠率與客觀EHR代理指標的相關變化，都增強了該工具正在產生貢獻的論證，儘管正式的前後比較仍應考慮同期其他併發的工作量變化。

## 資料來源與注意事項

職業倦怠調查資料來自定期（每年或更頻繁）施測的經驗證工具，應答率至關重要：低應答率存在無應答偏倚的風險，即倦怠程度最高的臨床醫師（最沒有餘力完成額外調查的人）在系統性上代表性不足，從而低估真實比率。源自EHR的數位負擔代理指標——系統內停留時間、非工作時間文書記錄時間、每次接觸的點選次數——作為與定期調查資料互補的客觀、持續可用的指標很有用，但在將其作為獨立可靠的倦怠指標之前，應針對特定機構與調查報告的倦怠情況進行驗證，因為系統內停留時間與真實倦怠之間的關係可能因專科和個人工作方式而異。

## 常見誤區

- **僅依賴EHR代理指標**：系統內停留時間和點選計數在總體上與倦怠相關，但並不等同於倦怠本身，對於具有真正不同文書記錄需求的個別臨床醫師或專科而言，可能具有誤導性。
- **調查應答率低掩蓋真實比率**：受倦怠影響最大的臨床醫師往往最沒有餘力應答自願調查，這會使低應答率的結果人為地偏向看似更健康的數位。
- **在未考慮混雜因素的情況下將倦怠變化歸因於單一工具**：倦怠受許多併發因素影響（人員配置水平、病患量、組織變革）；圍繞某一工具推出的前後比較應儘可能控制這些因素，而非假設單一原因。
- **純粹將倦怠視為個人韌性問題**：倦怠研究一致發現，工作量、系統設計和組織因素是主要驅動因素；將其僅僅歸結為個別臨床醫師的問題，會使介入措施偏離數位工具和工作流程這一通常才是真正根本原因的方向。

## 來源

- 馬斯拉赫職業倦怠量表（MBI），經驗證的調查工具與計分指導
- 美國醫學會（AMA），醫師職業倦怠研究與STEPS Forward執業改善專案
- 關於EHR可用性、文書記錄負擔與臨床醫師職業倦怠的同行評審文獻，例如發表於JAMIA和《Annals of Internal Medicine》的研究
