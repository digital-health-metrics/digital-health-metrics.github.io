# RE-AIM框架

RE-AIM是一個公共衛生評估框架，從五個不同維度——覆蓋度（Reach）、有效性（Effectiveness）、採納度（Adoption）、實施度（Implementation）和維持度（Maintenance）——評估數位健康介入，而非透過任何單一指標。它的存在是為了糾正數位健康評估中一種特定且常見的失敗模式：一個從一個規模小、積極性高的試點人群中報告出令人印象深刻的有效性資料，卻從未在規模上被採納，或從未在其資助期結束後得以維持的專案，無論其頭條結果數位單獨看起來多好，都並未真正展示出真實的公共衛生價值。

## 為何重要

數位健康試點專案經常僅在有效性上——結果指標是否為使用者帶來了改善——接受評估，而其他四個維度卻未被測量或報告，這系統性地使證據基礎偏向那些在理想、小規模條件下表現良好、但對於其是否能在規模上運作、能否觸及最需要它的人群、或能否在初始資助和熱情消退後存續下來完全沒有說明力的介入措施。RE-AIM的開發正是為了迫使評估者在報告內部效度（這在這裡有效嗎）的同時，也報告外部效度（這在其他地方、對誰有效），這對於任何要基於單一研究或試點結果來決定是否資助、委託或推廣某數位健康介入的人而言，都至關重要。由於五個維度中的每一個都可以在個人和機構或場所兩個層面上進行測量，RE-AIM還揭示了單一綜合指標會完全掩蓋的權衡——例如，一項由高度篩選、高度訓練的人員提供的高效有效介入（有效性強，但採納代表性弱）。

## 如何應用

```
覆蓋度   = 參與的符合條件目標人群比例，以及參與者相對於
           該符合條件人群的代表性程度（而非僅僅是原始參
           與人數）

有效性   = 對主要結果的影響，包括生活品質和意外的負面後果，
           而非僅僅是單一的頭條結果指標

採納度   = 採納該介入措施的場所與工作人員/傳遞代理人的
           比例及代表性，相對於所有符合條件的場所與人員

實施度   = 按預期傳遞的一致性與忠實度，傳遞所需的時間與
           成本，以及在此過程中所做的調整

維持度   = 該介入措施在個人層面（持續的個人效果）和場所/
           機構層面（制度化）成為常規實踐一部分的程度
```

## 實例解析

一項數位糖尿病預防專案在一個擁有200家符合條件診所的地區，於20家初級護理診所進行試點。評估覆蓋度發現，在這20家試點診所估計的15000名符合條件病患中，有1200人參與（8%），且參與者被發現比整個符合條件人群略年輕、數位素養也略高——這是一個值得關注、而非忽視的代表性差距。有效性評估顯示，完成者的平均HbA1c出現了具有臨床意義的下降，但較高的流失率意味著，當以意向治療為基礎對所有登記病患進行評估時，這一效果被稀釋了，而不僅僅是針對完成者。採納度為200家符合條件診所中的20家（10%），集中在現有數位基礎設施高於平均水平的診所——這是另一個代表性方面的擔憂。實施忠實度評估發現，大多數診所基本按設計傳遞了該專案，儘管有兩家診所在時間壓力下大幅縮短了入職流程。在試點資助結束一年後進行的維持度評估發現，最初20家診所中只有6家仍在積極運作該專案——這一結果，若與最初令人鼓舞的有效性數位一併報告，會比單獨的有效性資料提供更完整、更誠實的專案實際前景圖景。

## 資料來源與注意事項

RE-AIM的每個維度通常依賴不同的資料來源：覆蓋度和採納度來自登記與資格記錄，有效性來自臨床或結果資料（通常是本書其他地方已用於計算某項特定指標的同一資料，例如生物指標改善率），實施度來自忠實度核查表、傳遞記錄或直接觀察，而維持度則來自在初始評估期之後經過充分時間進行的隨訪評估——這意味著無法在單一時間點完成完整的RE-AIM評估，需要從一開始就規劃評估，而非事後追加。由於誠實地報告全部五個維度（包括某些維度上的不佳結果）比僅報告有效性需要更多工作、也不那麼討喜，已發表的數位健康評估相較於有效性，系統性地對覆蓋度、採納度和維持度報告不足——這是一種已知的發表偏倚模式，任何使用帶有RE-AIM標籤的證據來指導決策的人都應留意。

## 常見誤區

- **僅報告有效性卻稱之為RE-AIM評估**：使用RE-AIM之名卻僅報告其五個維度之一，違背了該框架的初衷，不應將其描述為RE-AIM評估。
- **將覆蓋度和採納度衡量為原始計數而非符合條件人群的比例**：較大的原始參與人數仍可能代表介入措施理想上應觸及人群中的一小部分、不具代表性的比例；應始終對照完整的符合條件分母進行計算。
- **過早評估維持度**：只有在初始資助或新奇效應消退很久之後，才能很好地判斷制度化和持續效果；無論其他四個維度表現如何，緊接試點結束後進行的評估都無法說明維持度。
- **將五個維度視為權重相等或可合併為單一分數**：RE-AIM在設計上是一個多維度概況，而非單一數位；將各維度合併為一個綜合分數，恰恰拋棄了該框架旨在保留的權衡可見性。
