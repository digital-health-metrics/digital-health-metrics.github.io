# 急診科分流率

急診科（ED）分流率是指由數位分診工具或虛擬護理處理的病患接觸中，若無該介入、很可能會導致急診就診，但實際上透過較低急重程度路徑——自我護理建議、初級護理預約，或預約的緊急護理就診——得到安全管理的比例。這是分診轉介準確率（參見該主題）中一個特定的、高價值的子集，專注於避免的急診科利用，而這正是與醫療成本和急診容量緩解最直接相關的結果。

## 為何重要

急診科是每次接觸成本最高的護理場所之一，常被用於本可在其他地方安全處理的問題，因此數位分診工具將適當病例安全地引導離開急診科的能力，是其最具商業和營運價值的能力之一——也是向評估該工具投資回報的支付方或醫療系統傳達價值最容易的方式之一。但分流只有在安全的前提下才有價值：一款以漏診真正急症為代價而激進分流的工具，完全權衡錯了方向，這正是為何急診科分流率必須始終與一項追蹤被分流病患中漏診或延誤急症的安全性指標一併報告，而不應孤立地作為純粹的效率勝利單獨報告。

## 計算方法

```
急診科分流率 = 安全轉介至適當低急重程度路徑的病患接觸數 /
               評估為可能急診傾向的病患接觸總數 × 100

"安全轉介"需要透過隨訪或關聯健康檔案資料來確認，病患的
病情在特定隨訪視窗內（例如72小時）實際上並未需要急診護
理——不能僅因病患事後未立即前往急診科，就認定該分流決
定已被驗證為安全。

應一併報告：
  漏診急症率 = 在隨訪視窗內確實需要急診護理的被分流病患數 /
              被分流病患總數 × 100
```

## 實例解析

某數位分診服務在一個月內評估了3000次其臨床演算法判斷為可能急診傾向的病患接觸。其中1800次被轉介至較低急重程度路徑（分流率60%）。使用關聯健康檔案資料對被分流佇列進行72小時隨訪發現，1800名被分流病患中有45人在該視窗內確實前往急診科就診（漏診急症率為45 / 1800 × 100 = 2.5%）。若僅報告60%的分流數位而不報告2.5%的漏診急症率，則只呈現了實際決定該工具分流行為是否適當校準的安全性-效率權衡的一半。

## 資料來源與注意事項

確認被分流病患隨後並未需要急診護理，依賴於關聯資料——同一醫療系統自身的急診科記錄、區域健康資訊交換，或結構化的病患隨訪電話或調查——如果分流專案在運作時沒有這些資料支援，實際上無法驗證自身的安全性，只能基於沒有投訴這一現象來假設安全。適當的分流率和可接受的漏診急症率，是臨床政策決策，而非純粹的統計決策，應由臨床領導層有意識地設定，而不應任其成為分診演算法預設使用的某個閾值的附帶結果。應按就診症狀或主訴類別報告分流率，因為適當的分流率因病情而異極大（例如小裂傷與胸痛需要截然不同的分流閾值）。

## 常見誤區

- **報告分流率卻沒有關聯的漏診急症安全性指標**：透過低估真正急症的分診而實現的高分流率並非成功；必須始終將這兩項指標一併報告。
- **假設沒有急診就診就意味著分流是安全的**：病患可能前往另一個未關聯的醫院系統的急診科，或在從未就診任何急診科的情況下出現真正有害的結果；應透過關聯資料或結構化隨訪來驗證安全性，而非僅憑同一系統內沒有急診就診記錄。
- **純粹為最大化分流率而設定分流閾值**：一個為最大化分流而調優、卻沒有匹配安全約束的演算法或政策，會以病患安全換取看似更好的效率數位。
- **跨所有主訴型別合併分流率**：適當的分流率因就診主訴而異極大；單一的綜合比率無法說明該工具在臨床上最重要的特定病情上是否表現安全有效。
