# 遠距醫療就診率

遠距醫療就診率是指一項服務的全部診療中，透過視訊或電話遠端提供而非面對面提供的比例。這是一個反映診療渠道構成的指標，而不是活動量指標：它告訴你診療是如何提供的——這對容量規劃、可及性和臨床適宜性都很重要——與總體提供了多少診療量是完全獨立的兩件事。

## 為何重要

新冠疫情期間遠端會診的快速擴張改變了許多服務的營運模式，此後，機構需要一種穩定的方法來監測這一轉變是否得以持續、是否正在回落至疫情前的常態，或是否正被政策主動引導。遠距醫療並非面對面就診的統一替代品：其適宜性因專科、會診型別（藥物複查與體格檢查的情況截然不同）以及病患偏好而異，因此"合適"的比率是一個臨床與營運判斷問題，而非一個應當被最大化的目標。資助方和監管機構也會結合結果和安全性指標使用這一比率，來決定報銷政策，並核查遠端診療是否只是被簡單地替代到了那些本應面對面就診的病例上。

## 計算方法

```
遠距醫療就診率 = 遠端診療次數 / (遠端診療次數 + 面對面診療次數) × 100

在可能的情況下按方式分別報告：
  視訊比率   = 視訊診療次數 / 總診療次數 × 100
  純電話比率 = 僅電話診療次數 / 總診療次數 × 100

分母應僅計入已完成的診療（見常見誤區），並針對特定服務、專科和時間段統計。
```

## 實例解析

某社群精神衛生服務在一個季度內記錄了 4,000 次已完成的門診接觸：1,200 次面對面，1,600 次視訊，1,200 次電話。遠距醫療就診率為 (1,600 + 1,200) / 4,000 × 100 = 70%，其中視訊比率為 40%，純電話比率為 30%。如果只報告合併後的 70%，會掩蓋其中很大一部分"遠距醫療"實際上是純音訊，而這通常具有與視訊不同的臨床風險特徵和病患體驗。

## 資料來源與注意事項

診療型別通常記錄為電子健康記錄中的結構化欄位（就診型別或地點），或透過賬單程式碼推斷，例如服務地點程式碼或理賠單上的遠距醫療修飾符。不同機構之間、甚至同一機構不同臨床醫師之間的編碼習慣差異很大，因此在跨機構比較比率之前，應先確認各機構對"遠距醫療"的編碼方式是否一致。因技術問題從視訊降級為電話的就診應有一致的編碼規則（通常按承載了大部分臨床內容的方式編碼），且該規則應形成檔案，而非留給個人判斷。

## 常見誤區

- **計入嘗試而非已完成的就診**：連線失敗並重新預約的遠距醫療預約，不應使遠距醫療分母被重複計入。
- **將視訊和電話視為可互換**：兩者在臨床和公平性方面的影響不同（電話無法進行視覺評估，但對沒有智慧手機、可靠網路或私密視訊空間的病患更具可及性）；應儘可能分別報告。
- **忽視與爽約率的關係**：爽約行為常因就診方式而異；在僅憑遠距醫療比率上升就得出"可及性提高"的結論之前，請參閱[預約爽約率](../預約爽約率/)。
- **認為高比率本身就是好事**：對某些病種和會診型別而言，合適的遠距醫療比率因臨床設計而本就偏低，這並非數位化成熟度不足的表現。
