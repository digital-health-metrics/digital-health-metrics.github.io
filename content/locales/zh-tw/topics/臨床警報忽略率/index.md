# 臨床警報忽略率

臨床警報忽略率衡量由計算機化醫囑錄入系統（CPOE）生成的臨床決策支援（CDS）警報——例如藥物相互作用警告、過敏警報和劑量範圍檢查——中，被臨床醫師駁回或忽略而未採取行動的比例。這是用於檢測和管理"警報疲勞"的標準量化訊號：這是一種有充分文獻記錄的現象，即當低價值警告的數量變得讓人不堪重負時，臨床醫師會逐漸對警報變得麻木。

## 為何重要

已發表的藥物相互作用警報忽略率通常在大約一半到超過九成之間，而高忽略率並不自動意味著安全失誤：許多打斷性警報是針對在特定情境下臨床意義不大的相互作用觸發的，或者是重複了臨床醫師在同一醫囑組中此前已經處理過的警報，因此，一個調校良好的系統會有意減少觸發的警報數量、提高每條警報的價值，而不是一味追求將忽略率降到零。真正關乎安全的是隨時間變化的趨勢、各嚴重程度分級中的分佈情況，以及臨床醫師在忽略高嚴重度警報時是否記錄了理由；即使所有警報的平均忽略率看起來保持穩定，針對高嚴重度、實證充分的相互作用的忽略率上升，仍然是一個真實的治理問題。

## 計算方法

```
忽略率 = 被忽略的警報數 / 觸發的警報總數 × 100

按以下維度分段統計：
  - 嚴重程度分級（如禁忌、重大、中度）
  - 警報型別（藥物相互作用、過敏、重複用藥、劑量範圍）
  - 是否記錄了忽略理由

"已記錄忽略率"追蹤的是帶有記錄理由的忽略操作所佔的比例，
這本身就是一項治理指標。
```

## 實例解析

某醫院的 CPOE 系統一個月內觸發了 10,000 條藥物相互作用警報，其中 8,700 條被忽略，整體忽略率為 87%。按嚴重程度分段後可見，在 500 條"禁忌"警報中，60 條被忽略（12%）；而在 6,000 條"中度"警報中，5,700 條被忽略（95%）。中度分級的數位與已發表的基準大體一致，其本身並不值得擔憂；禁忌分級的數位則值得逐案審查，而更具行動價值的治理髮現是：該分級 500 條忽略操作中，只有 340 條記錄了理由。

## 資料來源與注意事項

電子健康記錄的審計日誌，或 CDS 供應商自身的警報模組，會記錄每一次警報觸發和回應事件，包括臨床醫師是否輸入了自由文字或結構化的理由。要在不同機構之間、甚至同一機構不同科室之間比較忽略率，需要先核實其底層警報規則集和嚴重程度分級方式是否一致；規則集調校得更為激進的醫院，其忽略率較低的原因可能與臨床醫師的行為無關。

## 常見誤區

- **將原始忽略率當作單一安全評分**：這會把對低價值警報的合理忽略，與對真正危險相互作用的不安全忽略混為一談；應始終按嚴重程度進行分段。
- **未記錄忽略理由**：如果沒有記錄的理由，就無法區分"這條警報本身有誤"和"這條警報是對的，但臨床醫師做出了不安全的判斷"，而這正是關乎病患安全的真正區別。
- **隨時間推移的警報規則膨脹**：為求"安全"不斷增加警報，卻不淘汰低價值警報，是忽略率上升和警報疲勞的直接原因；警報治理應包含對錶現不佳規則的定期審查和淘汰，而不僅僅是監測。
- **在打斷設計不同的系統之間比較忽略率**：打斷性、強制停止的警報與被動、非阻斷性的警報會產生不同的忽略行為，因此二者不能直接作為可比指標。
