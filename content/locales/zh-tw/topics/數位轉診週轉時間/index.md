# 數位轉診週轉時間

數位轉診週轉時間是指從轉診臨床醫師提交電子轉診，到接診服務方完成分診並作出接受、拒絕或預約決定之間經過的時間。這是一項流程（流轉）指標，不同於病患總體等待時間，也是最能清楚證明數位化系統變革（結構化電子轉診、基於影像的分診、標準化轉診表單）能夠改變營運數位、而不僅僅是滿意度分數的領域之一。

## 為何重要

緩慢或高度不穩定的分診環節，會在病患甚至尚未進入臨床候診名單之前就增加延誤，而由於這種延誤發生在任何臨床診療開始之前，它是純粹的流程浪費，而數位化工具恰好非常適合消除這種浪費。要求"退回轉診方"以補充缺失資訊的轉診系統，會產生返工迴圈，如果只統計第一次就順利透過的轉診的週轉時間，這種返工迴圈很容易被忽視。當某項服務引入了結構化數位轉診表單、必填欄位，或基於影像的分診（例如遠端皮膚科）時，週轉時間通常是證明其效益最有說服力的單一指標，因為它可以在變革前後用同一套統計方式加以衡量。

## 計算方法

```
週轉時間 = 分診決定的時間戳 − 轉診提交的時間戳

應報告中位數和一個較高的百分位數（通常為第 90 百分位），
而不僅僅是均值，因為被退回或複雜的轉診會使分佈嚴重右偏。

在系統能夠記錄的情況下，考慮各子階段的用時：
  提交 → 服務方接收
  接收 → 分診決定
  分診決定 → 預約成功（如適用）
```

## 實例解析

某電子轉診系統的審計記錄顯示，各專科從提交到分診決定的中位時間為 1.8 天，第 90 百分位時間為 6 天，主要由於因缺少臨床資訊而被退回轉診方的轉診所致。同一平臺上採用基於影像分診的遠端皮膚科路徑，中位週轉時間為 4 小時，第 90 百分位為 1 天，因為一張照片和結構化病史幾乎總是足以作出分診決定，無需進一步往返溝通。

## 資料來源與注意事項

電子轉診或轉診管理系統自身的審計記錄是主要資料來源，依據提交和決定的時間戳；機構應確認在轉診因需要更多資訊而被退回期間，"計時"是暫停還是持續運作，因為這兩種定義會對同一底層流程得出實質性不同的數位。週轉時間應統一以自然日或工作時長報告，因為週末和節假日效應否則會扭曲工作模式不同的服務之間的比較。

## 常見誤區

- **只統計"乾淨"的轉診**：將被拒絕或退回的轉診排除在計算之外，會掩蓋數位化工具往往正是為了減少的返工負擔。
- **報告均值而非中位數和百分位數**：少數耗時極長、被退回的轉診會將均值大幅拉高，遠超典型病患的實際體驗。
- **將週轉時間與總等待時間混淆**：週轉時間僅涵蓋分診環節；病患的整體體驗還包括後續的臨床候診名單，那是一個受不同容量限制約束的獨立指標。
- **不區分各子階段**：僅測量端到端時間的服務，無法判斷緩慢的數位是由轉診方提交資訊不完整、接診服務方的分診產能，還是二者共同造成的。
