# 日活/月活黏著度比率

日活/月活黏著度比率將日活躍使用者（DAU）與月活躍使用者（MAU）進行比較——用於周活躍使用者（WAU）與MAU的比較也採用同樣的基本衡量方式——以表達產品更廣泛使用者群體中，有多大比例在任意一天參與其中。這是衡量參與強度的標準產品分析指標，不同於使用者是否完全被留存（參見使用者留存率），也不同於某一特定登記病患隨時間推移的參與一致程度（參見病患參與一致性率）：黏著度描述的是人群層面的使用節奏，而非任何個體的模式。

## 為何重要

兩款數位健康產品可能報告出完全相同的月活躍使用者數，但其潛在的參與強度卻大相徑庭：一款是大多數使用者幾乎每天都開啟應用，另一款則是大多數使用者每月只開啟一次，恰好在被計為非活躍前完成。日活/月活黏著度比率用一個簡單、易懂、可隨時間追蹤並與已知行業範圍比較的單一基準數位，區分了這兩種截然不同的情況——約20%的比率是許多消費者應用常被引用的合理基準，而每日習慣型產品（病患被期望每天使用的飲食或症狀日記）則應以明顯更高的標準來衡量。由於黏著度對"活躍"的定義方式很敏感，它最適合用作單一產品隨時間的趨勢，以及與為類似使用模式而建置的產品之間的比較，而非跨行業的絕對基準。

## 計算方法

```
日活/月活黏著度比率 = 期間內平均日活躍使用者數 /
                      同期月活躍使用者數 × 100

周活/月活比率（原理相同）是一種較為溫和的變體，更適用於
預期每週使用幾次而非每天使用的產品。

必須在分子和分母中精確且一致地定義"活躍"（例如已完成的
合格操作，而非被動的應用開啟）。
```

## 實例解析

一款數位糖尿病管理應用在某月擁有10000名月活躍使用者，定義為該月內至少完成一次合格操作（血糖記錄、飲食記錄或用藥簽到）的使用者。將該月30天內的日活躍使用者數取平均，得出平均日活為2200。日活/月活黏著度比率為2200 / 10000 × 100 = 22%，表明在典型一天中，該應用約22%的月活使用者基礎會與其互動——對於一款每日習慣型慢性病工具而言，這是一個合理的數位，儘管產品團隊希望看到該數位隨時間推移而上升，因為理想行為（每日記錄）對登記病患而言變得更加習慣化。

## 資料來源與注意事項

DAU、WAU和MAU都是根據相同的基礎事件日誌計算得出的，在每個視窗中使用一個一致的"合格活躍"事件定義；如果在分子和分母的計算之間改變該定義（例如DAU計入任何應用開啟，而MAU僅計入已完成的操作），會產生一個無法反映真實參與強度的失真比率。黏著度的適當基準在很大程度上取決於產品的預期使用模式：預期每週使用一次的工具（每週症狀簽到）將會、也應該顯示出比預期每日使用的工具（連續血糖監測配套應用）更低的日活/月活比率，因此應始終根據產品自身的預期使用節奏來解讀黏著度，而非單一的通用目標。

## 常見誤區

- **在預期使用頻率不同的產品間比較黏著度比率**：即使兩款產品在各自使用場景下都表現如預期，每週使用型工具在結構上也會顯示出比每日使用型工具更低的日活/月活比率；應根據產品自身的預期節奏進行基準比較，而非單一通用目標。
- **在分子和分母中使用不一致的活動定義**：這可能產生一個無法反映真實參與強度、且無法隨時間或與其他產品進行有意義比較的黏著度比率。
- **在未檢查整體月活趨勢的情況下將上升的黏著度比率視為絕對積極的訊號**：由一個正在萎縮、但更為習慣化的核心使用者群驅動的上升比率，同時整體月活正在下降，這與由在穩定或增長的使用者基礎上真正增加每日參與所驅動的情況截然不同——且更令人擔憂。
- **忽視日活的星期幾與季節性效應**：對許多健康產品而言，日活可能因星期幾（工作日與週末）或季節而顯著變化；應在涵蓋完整自然週期的期間內對日活取平均，而非使用可能有偏差的短視窗。
