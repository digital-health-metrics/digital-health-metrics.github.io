# 使用者留存率

使用者留存率是指在初始期間活躍的使用者中，在後續期間仍保持活躍的比例，而其反面——流失率——則是完全停止使用產品的使用者比例。病患門戶採納率（參見該主題）衡量的是病患是否曾有意義地啟用數位健康產品，而留存率衡量的是他們是否持續使用它——對於任何訂閱式或持續護理型的數位健康產品而言，留存率通常是與臨床影響和商業可持續性聯絡最緊密的單一指標。

## 為何重要

無論初始採納或啟用數位有多強，無法留住使用者的數位健康產品就無法帶來持續的臨床獲益：一款使用兩週便被放棄的慢性病管理工具，不太可能改變一個依賴數月持續行為改變的生物指標結果。留存率也是數位健康公司向投資者和支付方報告的最具商業意義的指標之一，因為留存曲線（隨時間推移的下降形態，而非單一的留存百分比）揭示了該產品是否找到了真正可持續的使用模式，還是僅僅捕捉了會可預測地消退的新奇驅動型初始興趣。在初期下降後趨於平穩的留存曲線（熬過第一個月的病患往往會留下來）是一個截然不同、也健康得多的訊號，與持續穩步下降、沒有底線的曲線相比。

## 計算方法

```
留存率（第N期）= 在第N期仍活躍、且在起始佇列期間也活躍的
                  使用者數 / 起始佇列期間的使用者數 × 100

流失率 = 1 − 留存率（同一期間）

應以佇列留存曲線的形式報告（第1、2、3……天/周/月的留存），
而非單一時間點的數位，因為單一快照會將剛加入的使用者（尚未
有機會流失）與長期留存的使用者混為一談。
```

## 實例解析

一款數位健康應用在1月登記了1000名新使用者的佇列。到第1個月末，原始1000人中仍有640人保持活躍（第1個月留存率64%）。到第3個月末，仍有410人保持活躍（第3個月留存率41%）。到第6個月，仍有380人保持活躍（第6個月留存率38%）。這條曲線的形態——初期急劇下降，隨後在第3至第6個月間趨於平穩——表明該產品在使用者跨過初始採納門檻後能夠留住穩定的核心使用者群，這與第3至第6個月的下降若以同樣速度持續下去相比，是一個截然不同、也更為令人鼓舞的訊號。

## 資料來源與注意事項

留存率根據產品自身的登入或活動事件日誌計算，在所比較的每個佇列中一致地定義"活躍"（例如，在該期間內至少一次合格會話）。應在同等基礎上比較佇列——相同的"活躍"起始定義、相同長度的觀察視窗——因為即使是微小的定義差異（30天與28天的月份、更嚴格與更寬鬆的"活躍"閾值）也可能使報告的留存百分比產生數個百分點的偏移，而實際使用者行為並無任何真實差異。與新年決心或特定健康意識週期相關的季節性效應在健康類應用中很常見，因此同比佇列比較通常比比較來自不同時間段的相鄰佇列更具參考價值。

## 常見誤區

- **報告單一留存快照而非曲線**：沒有隨時間推移的下降形態，僅一個"X%的使用者仍然活躍"的數位，無法區分趨於平穩的產品（健康）與持續下降的產品（不健康）。
- **在報告期間改變"活躍"的定義**：放寬活躍使用者的定義（例如將被動應用開啟計入而非已完成的操作）可能使留存率看似改善，而實際使用行為完全沒有變化。
- **忽視佇列季節性**：將1月佇列的留存率（往往因新年決心而帶來平均積極性較低的佇列而被虛增）與不同時間獲取的佇列相比較，可能得出誤導性的趨勢結論。
- **混合自然獲取與付費獲取的佇列**：透過不同渠道獲取的使用者留存表現往往差異很大；將其混合為一個綜合留存數位，可能掩蓋特定渠道的留存問題。
