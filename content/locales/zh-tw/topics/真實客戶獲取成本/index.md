# 真實客戶獲取成本

真實客戶獲取成本（真實CAC）是獲取一名新付費客戶或登記病患的完全負載成本，不僅包括付費廣告支出，還包括所有實質性促成該次獲取的其他成本：代理與創意費用、行銷技術與分析基礎設施，以及——數位健康所特有的——用於接診、資格核驗和入職的臨床或營運人力成本。它之所以作為一個獨立指標存在，是因為廣告平臺報告的獲取成本數位，經常性且大幅地低估了機構獲取一名客戶的真實成本。

## 為何重要

僅使用廣告平臺報告的單次獲取成本數位來管理增長的數位健康機構，其資源分配決策系統性地基於遺漏了30%至50%真實獲取成本的數位，因為這些平臺數位僅捕捉媒體支出，排除了代理費用、行銷技術許可，以及——對醫療保健而言至關重要的——每一位新病患在被計為已獲取之前，臨床或營運團隊所投入的勞動密集型接診與資格核驗工作。這一差距在數位健康領域比大多數其他行業都更為重要，正是因為臨床接診人力昂貴且是強制性的，不同於電子商務，後者的一次"銷售"基本上不需要類似的後臺人力。針對人為偏低的CAC數位最佳化行銷支出的團隊，會系統性地過度投資於在平臺儀表盤上看似便宜、但計算出真實CAC後其實昂貴的渠道。

## 計算方法

```
真實CAC = (付費媒體支出 + 代理與創意費用 + 行銷技術與
           分析成本 + 臨床/營運接診人力成本) / 期間內
           獲取的新客戶或病患數

臨床/營運接診人力成本應根據完全負載人力成本（工資、福利、
管理費用）× 每位獲取病患在接診、資格核驗和入職上所花費
的平均小時數來估算。
```

## 實例解析

一家數位健康公司在一個月內獲取500名新病患。廣告平臺儀表盤報告的綜合單次獲取成本為120美元，基於6萬美元的付費媒體支出。加上9000美元的代理費用、6000美元的行銷技術成本，以及以每小時40美元的完全負載員工成本估算每位病患45分鐘的接診人力成本（500 × 0.75 × 40美元 = 1.5萬美元），總獲取成本達到6萬 + 9000 + 6000 + 1.5萬 = 9萬美元。真實CAC為9萬 / 500 = 180美元——比廣告平臺單獨報告的120美元數位高出50%，而這才是真正應該用來指導渠道預算分配和單位經濟決策的數位。

## 資料來源與注意事項

付費媒體支出和平臺報告的單次獲取成本直接來自廣告平臺本身（搜尋、社交、程式化）；代理費用和行銷技術成本來自財務或應付賬款記錄；接診人力成本是最難準確獲取來源的部分，通常需要進行時間與動作研究，或與營運領導層商定合理的估算，因為大多數機構並不天然地按獲取追蹤員工時間。在資料量允許的情況下，應按獲取渠道分別計算真實CAC，因為每位病患的接診人力成本在各渠道間往往相近，而媒體成本差異巨大，這意味著平臺報告CAC與真實CAC之間的差距，在那些看似最便宜的渠道上按比例最大。

## 常見誤區

- **僅依賴廣告平臺儀表盤**：平臺報告的單次獲取成本在結構上排除了代理費用、行銷技術成本和接診人力，不能替代真實CAC計算。
- **遺漏臨床或營運接診人力**：這在數位健康領域一貫是最常被遺漏的成本組成部分，通常也是平臺報告成本與真實CAC之間差距的單一最大貢獻因素。
- **在所有渠道間平均真實CAC**：一個綜合的真實CAC數位可能掩蓋某一渠道在計入負載成本後其實昂貴得多，即使它在廣告平臺上看起來最便宜。
- **未在接診流程變化時更新人力成本估算**：接診流程重新設計（例如自動化資格核驗）可能顯著改變真實CAC，陳舊的人力估算將無法準確反映當前數位。
