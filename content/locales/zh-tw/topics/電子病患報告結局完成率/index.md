# 電子病患報告結局完成率

電子病患報告結局完成率是指已安排的電子病患報告結局（ePROM）——標準化、經驗證的問卷，用以採集病患本人對其症狀、功能或生活品質的陳述，以數位方式而非紙質方式傳遞——實際完成的比例。這既是一項資料品質指標，也是一項參與度指標：PROM專案的臨床與研究價值完全取決於完成率是否足夠高，以使所收集的答覆能夠代表整個登記人群，而不僅僅是參與度最高或症狀最輕的那部分子群體。

## 為何重要

病患報告結局是對臨床醫師記錄或裝置測量資料的直接、病患親證的補充，它捕捉了病歷審查或生物指標讀數無法捕捉的健康維度——疼痛、功能、生活品質；將PROM採集數位化正是為了讓大規模採集比紙質方式更便宜、更容易。但完成率較低的PROM專案存在一種特定且嚴重的偏倚：感覺更差的病患往往更不願意完成冗長的問卷，因此下降的完成率本身可能是人群健康狀況惡化的早期預警訊號，而總體較低的完成率可能使所收集的答覆顯得比真實人群體驗更好，因為症狀最重的病患在已完成的問卷中代表性不足。這正是為何完成率應始終與PROM分數本身一併報告，而不應被視為次要的營運細節。

## 計算方法

```
電子病患報告結局完成率 = 完整完成的ePROM數 / 傳送或安排的
                          ePROM數 × 100

分別報告：
  初始完成率     （監測序列中的第一份問卷）
  縱向完成率     （持續監測序列中的後續問卷，通常會隨時間
                  推移而下降，應作為趨勢追蹤，而非單一數位）

應對"部分完成"的問卷進行定義，並與"完整完成"和"未開始"
分開報告。
```

## 實例解析

一家腫瘤診所在每月隨訪前向400名病患傳送一份經驗證的症狀負擔ePROM。第一個月，340名病患完整完成了問卷（完成率85%），30人部分完成，30人未開始。到該監測序列的第六個月，同一批400名病患中完整答覆已降至260份（65%），這一具有意義的縱向下降，如果僅報告第一個月85%的靜態整體指標，將完全被忽略。調查哪些病患流失（按症狀嚴重程度、疾病分期或年齡劃分）可以揭示這一下降是反映調查疲勞、症狀惡化使問卷更難完成，還是技術性獲取障礙。

## 資料來源與注意事項

完成資料通常來自ePROM平臺自身的傳送與答覆記錄，能夠區分"未開始"、"部分完成"和"完整完成"狀態——這一區分應始終保留並報告，而不應壓縮為完成/未完成的二元數位，因為部分完成往往指出問卷中病患遇到困難或退出的具體環節。解讀完成率時應結合問卷的傳遞方式（簡訊連結、應用通知，或需要登入門戶的傳遞方式），因為傳遞摩擦本身會影響完成率，與問卷內容或病患基礎病情無關。對於PROM本身，應始終使用經過驗證的工具（而非臨時拼湊的問題集），因為未經驗證工具的完成率，即使很高，也無法可靠說明所得資料的臨床實用性。

## 常見誤區

- **僅將完成率下降視為傳遞問題**：縱向完成率下降可能反映病患症狀真正惡化（病患病重到無法完成調查），而非調查疲勞或技術問題，這一區分對臨床解讀至關重要。
- **將部分完成與完整完成合併為一類**：部分完成的問卷在資料品質上與完整完成的問卷存在明顯差異；應分別報告，並調查病患在問卷流程中往往在哪個環節放棄。
- **報告完成率卻不報告應答偏倚風險**：中等完成率應促使調查應答者是否（在症狀嚴重程度、年齡、數位素養方面）與未應答者存在系統性差異，因為僅從應答者計算的PROM分數可能無法代表整個人群。
- **使用未經驗證或自行設計的問卷**：如果所完成的工具未針對所測量的疾病和人群進行臨床驗證，即使完成率很高，完成率作為資料品質訊號也是沒有意義的。
