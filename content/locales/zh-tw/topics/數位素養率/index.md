# 數位素養率

數位素養率是指病患人群中，能夠獨立且成功地完成數位健康平臺上常見任務——登入、預約、加入視訊問診，或檢視檢測結果——而無需他人協助的比例。它與數位可及率不同，也應始終與之分開測量：一名病患可能擁有智慧手機和寬頻連線，卻仍無法在無協助的情況下瀏覽遠距醫療平臺，將這兩項指標混為一談，恰恰掩蓋了這項指標本應揭示的人群。

## 為何重要

僅有數位可及性並不能保證病患能夠有效使用數位健康服務：健康素養較低、普遍缺乏技術使用經驗、存在認知或視力障礙，或與平臺介面存在語言障礙的病患，可能擁有完全的技術可及性，卻仍無法獨立完成任務，而這一差距與已經面臨其他健康差距的相同人口群體存在系統性關聯。HIMSS數位健康公平衡量框架正是出於這一原因，將數位素養視為與可及性不同的獨立支柱：僅彌合可及性差距而不同時解決素養差距，可能會留下一個技術上已連線、但功能上無法從中受益的人群。按語言和社會經濟指標細分，測量常見平臺操作的任務完成率和完成時間的機構，能夠比僅依賴可及性指標或整體滿意度分數的機構，更精確地識別素養障礙並有針對性地提供支援（簡化介面、輔助入職、替代語言內容）。

## 計算方法

```
數位素養率 = 無協助獨立完成特定任務的病患數 /
              嘗試該任務的病患數 × 100

測量的常見任務：賬戶登入、預約掛號、加入視訊問診、
檢視檢測結果、完成接診表格。

應按任務分別報告，而非合併為單一分數，因為簡單任務
（登入）與複雜任務（完成多步驟接診表格）的素養差異
很大，合併會掩蓋具體障礙所在。
```

## 實例解析

某醫療系統在一個月內的5000次已預約遠距醫療就診中，將加入視訊問診作為一項特定任務進行追蹤。其中4100名病患成功加入，且未在問診過程中撥打任何支援電話或獲得技術協助（該任務的數位素養率：82%）。按主要語言細分顯示，說英語的病患比率為89%，而主要語言與平臺預設介面語言不同的病患比率為61%——這一28個百分點的差距，如果僅報告混合的82%數位將完全無法察覺，而這一差距直接指向一項具體、可解決的介入措施（翻譯介面與說明），而非一個模糊的籠統素養問題。

## 資料來源與注意事項

任務完成資料通常從平臺自身的事件日誌中獲取（病患是否成功加入視訊問診、預約流程是否未中斷地完成），並輔以支援電話或幫助臺聯係資料，以識別那些僅因病患中途獲得實時協助而在技術上"完成"的任務。僅從系統日誌計為"已完成"的任務，可能掩蓋了病患需要家庭成員的電話或支援人員幫助才能完成的事實——在平臺能夠區分兩者的情況下，應將真正獨立於素養的完成情況與獲得協助的完成情況分別定義和追蹤。數位素養與健康素養及一般素養相關，但在分析上有所不同；在需要正式評估的情況下，應使用經過驗證的工具（而非僅基於年齡或人口統計的非正式假設）。

## 常見誤區

- **將數位素養與數位可及性混為一談**：一名擁有完全技術可及性的病患仍可能缺乏有效使用它的素養；這是需要不同介入措施的獨立指標，絕不應報告為單一合併數位。
- **將獲得協助的完成情況計為無協助的成功**：如果病患僅在支援電話或家庭成員幫助下才能完成任務，這是平臺掩蓋而非解決的素養差距；應在資料允許的情況下區分有協助與無協助的完成情況。
- **報告單一合併任務完成分數**：簡單任務（登入）與複雜任務（完成詳細接診表格）的素養差異很大；應按任務報告，以準確找出障礙所在。
- **假設年齡本身能預測數位素養**：儘管年齡在總體上與較低的數位素養相關，但對平臺介面語言的熟練程度和一般技術熟悉度往往是更強的個體預測因素，應直接測量，而非從年齡推斷。
