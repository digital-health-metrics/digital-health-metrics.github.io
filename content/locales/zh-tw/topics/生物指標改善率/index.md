# 生物指標改善率

生物指標改善率是指在數位健康專案中登記的病患中，在所追蹤的生物指標上取得具有臨床意義改善的比例——最常見的是糖尿病和心臟代謝專案中的糖化血紅蛋白（HbA1c），或體重管理專案中的體重指數（BMI）——在特定登記期限內。這是最終驗證數位健康產品臨床價值主張的結果性指標：參與度和採納率數位描述的是產品如何被使用，而生物指標改善則更接近於產品確實有效的證據。

## 為何重要

數位健康專案經常以改善健康結果的承諾來銷售和委託營運，而生物指標改善率是最直接、最可量化的方式，用以將該承諾與具體的、公認的臨床閾值進行對照檢驗，而非停留在含糊的"健康改善"說法上。支付方、僱主和醫療系統日益將報銷或合同續簽與已證明的生物指標變化掛鉤，因此無法可信地報告這一比率的專案，在商業上和臨床上都處於不利地位。這一指標也是對專案設計的紀律性檢驗：報告參與度（登入次數、傳送的訊息）遠比報告結果容易得多，團隊應對任何熱情報告前者卻對後者含糊其辭的專案保持警惕。

## 計算方法

```
生物指標改善率 = 達到特定臨床意義改善的病患數 / 具有有效
                  基線和隨訪測量值的病患數 × 100

常見的具有臨床意義的閾值：
  HbA1c   —— 下降 ≥ 0.5 個百分點，或從超出範圍的基線值
            達到特定目標（例如 < 7.0%）
  BMI     —— 相對基線體重下降 ≥ 5%，並持續到隨訪測量點

應針對每個追蹤的生物指標分別報告；切勿將 HbA1c 和 BMI 的改善
合併為單一的"改善"百分比。
```

## 實例解析

一個心臟代謝數位健康專案招募了800名基線HbA1c超出正常範圍的病患。其中，620人在6個月時同時擁有有效的基線和隨訪測量值（180人失訪，被排除在分母之外，而非被計為失敗）。在這620名擁有配對測量值的病患中，有340人實現了至少0.5個百分點的下降。生物指標改善率為340 / 620 × 100 = 55%。若將其與全部800名登記病患相比較（340 / 800 = 42.5%），則會將失訪與治療失敗混為一談，從而低估了實際完成測量的病患的改善率。

## 資料來源與注意事項

基線和隨訪生物指標值通常來自聯網裝置（藍芽血糖儀或智慧體重秤）、從電子健康檔案匯入的實驗室結果，或病患自報數值——這三種來源的可靠性差異很大，因此應在報告比率的同時註明資料來源。失訪很少是隨機的：脫離專案的病患往往也是最不可能改善的病患，因此僅根據完成隨訪的病患計算的高改善率可能高估專案在整體人群層面的真實效果。季節性效應和均值迴歸效應對HbA1c和體重而言都是真實存在的，因此專案應儘可能與同期或歷史對照組進行比較，而不是將任何改善都視為專案效果的證明。

## 常見誤區

- **排除而非報告失訪情況**：悄悄將無隨訪測量值的病患從分母中剔除，可能大幅虛增表觀改善率；應始終將隨訪完成率與改善率一併報告。
- **混合自報和裝置來源的測量值而不加標註**：自報體重的可靠性系統性地低於聯網智慧體重秤的讀數，混合兩種來源會掩蓋表觀改善中有多少其實是測量噪音。
- **沒有對照組或反事實比較**：許多慢性生物指標本身就會波動或向均值迴歸；沒有任何對照組的單臂改善率只能是提示性的，而非專案效果的確證性證據。
- **將適度的平均變化視為廣泛改善的證據**：人群層面較小的平均改善可能是由少數反應強烈者驅動的，而大多數病患並無變化；應報告分佈情況（例如跨越具有臨床意義閾值的比例），而非僅報告平均變化。
