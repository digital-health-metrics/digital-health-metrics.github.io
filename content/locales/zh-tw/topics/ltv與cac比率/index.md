# LTV與CAC比率

LTV與CAC比率將客戶生命週期價值（LTV）——機構預期從一名病患或客戶與產品的整個關係中獲得的總收入或利潤——與獲取該客戶的真實成本（參見真實客戶獲取成本）進行比較。這是判斷數位健康機構增長是否具有財務可持續性的單一最重要的單位經濟指標，因為如果獲取成本超過生命週期價值，不斷增長的客戶基礎實際上是在虧損，無論增長曲線看起來多麼積極，都不是健康的跡象。

## 為何重要

一家數位健康機構可能在穩步擴大使用者基礎的同時，悄悄地在每一位新客戶身上摧毀價值——只要獲取成本超過生命週期價值；LTV與CAC比率是唯一能夠以增長率或原始客戶數無法做到的方式，將這一點變得可見的指標。3:1的比率（生命週期價值至少是獲取成本的三倍）是被廣泛引用的可持續訂閱或經常性收入業務的基線基準，能留出足夠的利潤來覆蓋獲取之外的營運成本並仍能產生回報；低於1:1的比率意味著機構在每獲取一名客戶上都在虧錢，而遠高於3:1（例如10:1或更高）的比率實際上可能表明增長投資不足，因為這暗示該機構本可以盈利地獲取比目前更多的客戶。評估數位健康公司財務可持續性的投資者、董事會和支付方，都將這一比率視為他們最先要求瞭解的數位之一。

## 計算方法

```
LTV = 每位客戶每期的平均收入（或利潤）× 該期間單位下的
      平均客戶生命週期

LTV與CAC比率 = LTV / 真實CAC

3:1是被普遍引用的可持續基線；低於1:1表明機構在獲取上
虧錢；遠高於3:1（例如10:1以上）可能表明增長投資不足。
```

## 實例解析

某數位健康訂閱服務每位病患的平均月收入為40美元，平均病患保持訂閱18個月，得出LTV為40美元 × 18 = 720美元。該服務的真實CAC（參見該主題的實例解析方法）計算為每獲取一名病患180美元。LTV與CAC比率為720 / 180 = 4:1，舒適地高於3:1的可持續基線。如果真實CAC僅使用廣告平臺報告的成本（120美元，未計入代理費用和接診人力）計算，該比率將顯示為6:1——這是一幅比真實的4:1數位明顯更有利、也更具誤導性的單位經濟圖景。

## 資料來源與注意事項

LTV依賴於對平均客戶生命週期的假設，而該假設本身又源自機構自身的留存或流失資料（參見使用者留存率）——流失率高的企業其有效平均生命週期更短，因此LTV更低，即使其每期每客戶收入看起來不錯也是如此。由於LTV是一個前瞻性估算而非已觀察到的歷史事實，應隨留存資料的積累而定期重新計算，並在流失假設被證明有誤時予以修正，而非一次性設定後便任其陳舊。在這一比率中使用平臺報告的CAC而非真實CAC，是機構說服自己相信其單位經濟狀況比實際更健康的最常見方式之一，因為被低估的CAC會機械地虛增該比率。

## 常見誤區

- **使用平臺報告的CAC而非真實CAC**：這會機械地虛增該比率，並可能使不可持續的獲取策略看起來可持續；應始終使用完全負載的真實CAC數位。
- **使用陳舊或樂觀的平均客戶生命週期假設**：根據過時的留存曲線計算出的LTV，無法反映當前的流失行為，尤其是在產品、定價或市場變化改變留存之後。
- **將非常高的比率視為絕對良好**：遠高於3:1的比率可能表明增長投資不足，而非卓越效率，因為它暗示該機構很可能能夠盈利地獲取比目前更多的客戶。
- **對差異很大的客戶細分市場計算單一綜合比率**：一個收入高、流失低的細分市場可能掩蓋另一個單位經濟狀況不佳的細分市場；在資料量允許的情況下，應按有意義的細分（例如獲取渠道或產品線）計算該比率。
