# 真の顧客獲得コスト

真の顧客獲得コスト(真のCAC)とは、1人の新規有料顧客または登録患者を獲得するための全負荷コストであり、有料広告費だけでなく、その獲得に重要な形で寄与した他のすべてのコスト——代理店・クリエイティブ費用、マーケティングテクノロジーと分析インフラ、そしてデジタルヘルスに特有の、受付・資格確認・オンボーディングの臨床的または運用上の人件費を含む。これは独立した指標として存在する。なぜなら、広告プラットフォームが報告する獲得コストの数値は、組織の実際の獲得1件あたりの真のコストを日常的かつ大幅に過小評価するためである。

## なぜ重要か

広告プラットフォームが報告する獲得1件あたりのコスト数値のみを使用して成長を管理するデジタルヘルス組織は、実際の獲得コストの30-50%を省略した数値に基づいて日常的にリソース配分の決定を下している。なぜなら、そのプラットフォームの数値はメディア費用のみを捉え、代理店費用、マーケティングテクノロジーのライセンス費用、そして医療において重要な、臨床または運用チームが新規患者ごとに獲得としてカウントされる前に行う労働集約的な受付・資格確認作業を除外しているためである。このギャップは、eコマースとは異なり、ほとんどの他のセクターよりもデジタルヘルスにおいてより重要である。eコマースでは「販売」は本質的に匹敵するバックオフィスの労働を必要としないのに対し、臨床受付の人件費は高価かつ必須だからである。人為的に低いCACの数値に対してマーケティング費用を最適化するチームは、プラットフォームのダッシュボード上では安く見えるが真のCACを計算すると高価になるチャネルに体系的に過剰投資することになる。

## 算出方法

```
真のCAC = (有料メディア費用 + 代理店・クリエイティブ費用 +
          マーケティングテクノロジーと分析コスト + 臨床/運用
          受付人件費) / 期間内に獲得した新規顧客または患者数

臨床/運用受付人件費は、全負荷人件費(給与、福利厚生、
オーバーヘッド)× 受付、資格確認、オンボーディングに獲得
患者1人あたり費やされる平均時間から見積もるべきである。
```

## 計算例

あるデジタルヘルス企業が月に500人の新規患者を獲得する。広告プラットフォームのダッシュボードは、$60,000の有料メディア費用に基づいて、統合された獲得1件あたりコストを$120と報告する。$9,000の代理店費用、$6,000のマーケティングテクノロジーコスト、そして患者1人あたり45分の受付人件費(全負荷スタッフコスト$40/時間で500 × 0.75 × $40 = $15,000)を加えると、総獲得コストは$60,000 + $9,000 + $6,000 + $15,000 = $90,000になる。真のCACは$90,000 / 500 = $180であり——広告プラットフォーム単独が報告した$120という数値より50%高く、実際にチャネル予算配分とユニットエコノミクスの決定を知らせるべき数値である。

## データソースと注意点

有料メディア費用とプラットフォームが報告する獲得1件あたりコストは、広告プラットフォーム自体(検索、ソーシャル、プログラマティック)から直接得られる。代理店費用とマーケティングテクノロジーコストは財務または買掛金の記録から得られる。受付人件費は正確に把握することが最も難しい要素であり、通常は時間動作研究、または運用リーダーシップと合意した妥当な見積もりのいずれかが必要である。ほとんどの組織は獲得ごとのスタッフ時間をネイティブに追跡していないためである。真のCACは、ボリュームが許す限り獲得チャネルごとに計算されるべきである。患者1人あたりの受付人件費はチャネル間で類似していることが多い一方、メディアコストは大きく異なるため、プラットフォームが報告するCACと真のCACの間のギャップは、最も安く見えるチャネルで比例的に最大となる。

## 落とし穴

- **広告プラットフォームのダッシュボードのみに頼ること**: プラットフォームが報告する獲得1件あたりコストは、構造的に代理店費用、マーケティングテクノロジーコスト、受付人件費を除外しており、真のCAC計算の代替にはならない。
- **臨床または運用受付の人件費を省略すること**: これは特にデジタルヘルスにおいて一貫して最も一般的に見逃されるコスト要素であり、プラットフォームが報告するコストと真のCACの間のギャップの単一最大の寄与要因であることが多い。
- **すべてのチャネルにわたって真のCACを平均化すること**: 統合された真のCAC数値は、広告プラットフォーム単独で最も安く見えたとしても、全負荷コストを含めると1つのチャネルが劇的に高価であることを隠してしまう可能性がある。
- **受付プロセスの変化に合わせて人件費の見積もりを更新しないこと**: 受付プロセスの再設計(例えば資格確認の自動化)は真のCACを大きく変える可能性があり、古い人件費の見積もりは現在の数値を誤って伝えることになる。
