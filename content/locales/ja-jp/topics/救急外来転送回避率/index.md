# 救急外来転送回避率

救急外来(ED)転送回避率は、デジタルトリアージまたはバーチャルケアツールによって対応された患者接触のうち、その介入がなければ妥当にEDへの訪問につながっていたであろうが、代わりに低緊急度の経路——セルフケアのアドバイス、プライマリケアの予約、または予定された緊急ケア訪問——を通じて安全に管理された割合を測定する。これはトリアージ振り分け精度(その項目を参照)の特定の高価値サブセットであり、完全に回避された救急外来利用に焦点を当てている。これは医療コストとED容量の緩和の両方に最も直接的に結びついた結果である。

## なぜ重要か

救急外来は1回の受診あたり最も高コストなケア設定の1つであり、他の場所で安全に管理できる問題のために頻繁に利用されている。そのため、デジタルトリアージツールが適切なケースをEDから安全に転送する能力は、その最も商業的・運用的に価値のある能力の1つであり、ツールの投資収益率を評価する支払者や医療システムに伝える最も簡単な能力の1つでもある。しかし転送回避は安全である場合にのみ価値がある:真の緊急事態を見逃すという代償を払って患者をEDから積極的に転送するツールは、取引の完全に間違った側を最適化したことになる。これが、救急外来転送回避率が常に、転送された患者における見逃されたまたは遅延した緊急受診を追跡する安全性指標とともに報告されるべきであり、純粋な効率性の勝利として孤立して報告されるべきではない理由である。

## 算出方法

```
救急外来転送回避率 = ED から適切な低緊急度経路に安全に転送
                    された患者接触数 / 潜在的にED行きと評価
                    された患者接触総数 × 100

「安全に転送された」ことには、フォローアップまたは連携された
健康記録データを通じて、患者の状態が定められたフォローアップ
ウィンドウ(例:72時間)以内に実際には緊急ケアを必要としな
かったことの確認が必要である——転送の決定は、患者がその後
すぐにEDに行かなかったというだけでは安全であると検証された
ことにはならない。

以下とともに報告すること:
  見逃された緊急事態率 = フォローアップウィンドウ以内に実際に
                        緊急ケアを必要とした転送患者数 / 転送
                        患者総数 × 100
```

## 計算例

あるデジタルトリアージサービスが、月間3,000件の患者接触を評価し、その臨床アルゴリズムは介入がなければ潜在的にED行きであると判断する。このうち1,800件が低緊急度経路に転送される(転送回避率60%)。連携された健康記録データを使用して72時間で転送されたコホートをフォローアップすると、1,800人の転送患者のうち45人がそのウィンドウ内に実際にEDを受診していたことが判明する(見逃された緊急事態率45 / 1,800 × 100 = 2.5%)。見逃された緊急事態率2.5%なしに転送回避率60%を報告することは、ツールの転送回避行動が適切に較正されているかどうかを実際に決定する安全性-効率性トレードオフの半分しか提示しないことになる。

## データソースと注意点

転送された患者がその後緊急ケアを必要としなかったことを確認することは、連携されたデータに依存する——同じ医療システム自身のED記録、地域の健康情報交換、または構造化された患者フォローアップコールや調査のいずれかである——そして、これらのデータソースのいずれもなしに運用される転送プログラムは、実際には自身の安全性を検証できず、苦情の不在に基づいてそれを仮定することしかできない。適切な転送回避率と許容可能な見逃された緊急事態率は、純粋に統計的なものではなく臨床的な政策決定であり、トリアージアルゴリズムがたまたまデフォルトで使用する閾値の副産物として現れるままにするのではなく、臨床リーダーシップによって意図的に設定されるべきである。転送回避率は、提示された症状または訴えのカテゴリー別に報告されるべきである。適切な転送回避率は疾患によって大きく異なるためである(軽度の裂傷と胸痛では大きく異なる転送回避閾値が必要である)。

## 落とし穴

- **連携された見逃された緊急事態安全性指標なしに転送回避率を報告すること**: 真の緊急事態を過小トリアージすることによって達成された高い転送回避率は成功ではない。両方の指標は常に一緒に報告されるべきである。
- **ED受診がないことを転送が安全であったことと仮定すること**: 患者は異なる連携されていない病院システムのEDを受診する可能性があり、あるいはどのEDも受診することなく真に有害な結果を経験する可能性がある。同一システムのED受診の不在だけでなく、連携されたデータまたは構造化されたフォローアップを通じて安全性を検証すること。
- **転送回避率を最大化することのみを目的として転送閾値を設定すること**: 一致する安全性制約なしに転送を最大化するように調整されたアルゴリズムやポリシーは、より良く見える効率性の数値と引き換えに患者の安全性を犠牲にすることになる。
- **すべての訴えのタイプにわたって転送回避率を混ぜること**: 適切な転送回避率は提示される訴えによって大きく異なる。単一の統合率では、ツールが臨床的に最も重要な特定の疾患に対して安全かつ効果的に機能しているかどうかを示すことができない。
