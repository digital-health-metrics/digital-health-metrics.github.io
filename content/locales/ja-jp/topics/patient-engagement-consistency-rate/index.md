# 患者エンゲージメント一貫性率

患者エンゲージメント一貫性率とは、登録患者が時間をかけてデジタルヘルス製品とどれだけ定期的に相互作用しているか——例えば食事や症状を記録する、身体活動を記録する、健康データを閲覧するなど——を測定するものであり、単にそれを使用したことがあるかどうかではない。これは縦断的な指標であり、ある時点でのアクティブ使用数とは異なる。2人の患者が「今月アプリを使用した」という同一のステータスを持ちながら、一方は毎日一貫して記録し、もう一方は一度記録してから3週間姿を消すということがあり得る。これを区別できるのは一貫性指標だけである。

## なぜ重要か

デジタルヘルスツールとの持続的で定期的な相互作用は、臨床的利益のより信頼できる先行指標の1つであり、特に糖尿病、体重管理、メンタルヘルスのような行動依存型の疾患において顕著である。これらのツールの価値は、単一のセッションからではなく、それが支える習慣から生まれる。ある製品は健全な月間アクティブユーザー数を報告しながら、実際には一度ログインしてから離れていく集団にサービスを提供している可能性がある。なぜなら月間アクティブ利用は低いハードルであり、その月内の利用パターンについて何も語らないからである。一貫性指標は、単純なアクティビティカウントではできない方法でこれを捉える。一貫性は数週間ではなく数か月にわたって維持することがより困難なことの1つでもあるため、オンボーディング直後の新奇性効果の影響を受けやすい短期間のエンゲージメント数値よりも、製品の品質と臨床的適合性のより正直なシグナルとなる。

## 算出方法

```
エンゲージメント一貫性率 = 少なくとも1回の該当する相互作用が
                          あった週数 / 登録期間中の総週数 × 100

「該当する相互作用」は明示的かつ一貫して定義されるべきである
(例:食事記録エントリー、症状チェックイン、または完了した
アクティビティ同期)——記録されたアクションのないアプリを開く
といった受動的なイベントは決して含めない。

集団の平均値だけでなく、分布として報告する:
  例:週次一貫性80%以上の患者の割合、50-79%の割合、
     50%未満の割合
```

## 計算例

ある栄養コーチングアプリが患者を12週間登録する。その患者は12週間のうち9週間で少なくとも1回の該当する食事エントリーを記録し、9 / 12 × 100 = 75%の個人エンゲージメント一貫性率となる。少なくとも12週間登録されたアプリの全コホート2,000人の患者の中で、600人(30%)が週次一貫性80%以上を維持し、900人(45%)が50-79%の範囲に入り、500人(25%)が50%未満となる。コホート平均値のみを報告すること(おそらく65%前後になる)は、患者の4分の1がほとんどまったくエンゲージしていないことを隠してしまう——これは全体の平均に薄めてしまうのではなく、別途調査する価値のあるセグメントである。

## データソースと注意点

一貫性データは製品自体のイベントログ(食事エントリー、アクティビティ同期、チェックイン)から得られ、「該当する相互作用」の定義は結果として得られる率に非常に大きな影響を与える——緩い定義(あらゆるアプリの起動)は常に厳格な定義(完了した意味のある記録エントリー)よりも良く見えるため、使用される定義は報告される数値とともに明確に述べられなければならない。自動的に同期されたデータ(例えば、バックグラウンドでアクティビティを同期する接続されたフィットネストラッカー)は、手動で記録されたデータとは別に報告されるべきである。自動同期は、患者の積極的な努力や製品のガイダンスへのエンゲージメントを反映することなく、見かけ上の一貫性を膨らませる可能性があるためである。

## 落とし穴

- **アプリの起動を意味のあるエンゲージメントと混同すること**: 受動的なアプリの起動(例えばプッシュ通知によってトリガーされたもの)は、記録された食事エントリーや完了したチェックインと同じではない。該当する相互作用のみを定義し報告すること。
- **集団平均のみを報告すること**: 健全に見える平均一貫性率は、非常にエンゲージしている患者とほぼ完全に離脱している患者という二峰性の集団を隠してしまう可能性がある。平均値だけでなく一貫性帯域全体にわたる分布を報告すること。
- **登録期間の分母を無視すること**: 登録期間が大きく異なる患者間の一貫性率を登録期間を考慮せずに比較すると、より短く維持しやすい測定ウィンドウを持つグループに有利なバイアスがかかる。
- **自動バックグラウンド同期が率を膨らませること**: 受動的に同期されたウェアラブルデータストリームは、実際の行動変化や製品エンゲージメントなしに、離脱した患者を一貫して活動的に見せる可能性がある。
