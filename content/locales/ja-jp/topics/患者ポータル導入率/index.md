# 患者ポータル導入率

患者ポータル導入率は、オンライン患者ポータル(例えばNHS App、Patient Access、あるいはMyChartのように電子カルテと連携したポータル)に登録し、記録の閲覧、予約、ケアチームへのメッセージ送信のために積極的に利用している対象患者の割合を測定します。これはデジタルエンゲージメントの入り口となる指標です。一度もアカウントを有効化したことのない患者は、ポータルを基盤として構築されたいかなる後続のデジタルサービスからも恩恵を受けることができません。

## なぜ重要なのか

ポータルは患者が実際に利用して初めて価値を生み出すため、組織は導入率を単一の数字ではなく、ファネルとして追跡すべきです。登録、アクティベーション(最初の意味のある行動)、アクティブ利用(定められた期間内での利用)は、しばしば1つに混同されがちな3つの異なる比率です。デジタルサービスのチームは、単一の好ましい全体数値を報告するよう圧力を受けることが多く、より困難で誠実な内訳にこだわるには規律が必要です。低い、あるいは不均等に分布した導入率は、公平性の兆候でもあります。高齢の患者、デジタルリテラシーの低い患者、多数派言語を話さない患者、信頼できるブロードバンドやスマートフォンを持たない患者は、分子に含まれる可能性が体系的に低くなるため、平均導入率が上昇していても、サービスとの接触を最も必要としている患者との格差が拡大していることを覆い隠す場合があります。

## 計算方法

```
登録率     = ポータルアカウントを作成した患者数 / 対象患者数 × 100
アクティベーション率 = 最初の意味のある行動(結果の確認、予約、
             メッセージ送信)を完了した患者数 / アカウントを持つ患者数 × 100
アクティブ利用率 = 過去12か月間に少なくとも1回ログインした患者数 /
             対象患者数 × 100
```

対象患者数は通常、定められた振り返り期間(一般的には24か月)内に組織と少なくとも1回接触があり、年齢と同意の状況が本人名義のアカウント保有を許可する患者として定義されます。

## 解決済みの例

あるプライマリケアネットワークは、対象条件を満たす50,000人の患者にサービスを提供しています。このうち32,000人がポータルに登録しています(登録率64%)。この32,000人の登録者のうち27,000人が、検査結果の確認など少なくとも1つの意味のある行動を完了しています(登録者に対するアクティベーション率84%)。過去12か月間で、当初の対象患者50,000人のうち21,000人が少なくとも1回ログインしています(アクティブ利用率42%)。登録率64%という数字だけを報告すると、実際のエンゲージメントをかなり過大評価することになります。ポータルプログラムの資源配分の意思決定を導くべきなのは、42%というアクティブ利用率の数字です。

## データソースと注意点

ポータルの分析データは通常、ベンダーのプラットフォーム自体(ログインイベント、機能利用状況)か、基盤となる電子カルテの監査ログのいずれかから得られます。組織は、登録数のみを表示するベンダーのダッシュボードに懐疑的であるべきです。代理アクセス(親や介護者が患者に代わってアカウントを管理する場合)は別途タグ付けして報告すべきです。これは実際に誰が「利用者」であるかを変えるためです。分母の選び方は非常に重要です。真に対象となり連絡可能な集団ではなく、登録患者リスト全体に対して計算すると常に導入率を過小評価し、積極的に招待された患者のみに対して計算すると常に過大評価します。したがって、対象基準の定義は固定され、報告される各比率とともに公表されるべきです。

## よくある間違い

- **登録を導入と同一視する**: 作成されたが一度も使われていないアカウントの価値はほぼゼロです。登録の代わりではなく、登録に加えてアクティベーションとアクティブ利用を報告してください。
- **デジタル排除を無視する**: データガバナンスが許す限り、年齢、貧困、言語、障害によって常に層別化すべきです。全体の導入数値が上昇していても、最もデジタルに包摂されているグループと最も排除されているグループとの格差は拡大している可能性があります。
- **対象基準の定義が異なる組織を比較する**: 登録済みのメールアドレスを持つ患者のみを招待するポータルプログラムは、登録リスト全体に対して測定するプログラムよりも高い比率を報告しますが、これは実際のパフォーマンスの差を反映していません。
- **1回限りのログインを継続的なエンゲージメントとして扱う**: 12か月の振り返り期間が一般的ですが、より短い期間(例えば90日)を使うと、利用低下をより早期に警告できます。
