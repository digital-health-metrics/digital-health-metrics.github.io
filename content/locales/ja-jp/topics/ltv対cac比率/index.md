# LTV対CAC比率

LTV対CAC比率は、顧客生涯価値(LTV)——組織が製品との全関係を通じて患者または顧客から得ることが期待される総収益またはマージン——を、その顧客を獲得する真のコスト(真の顧客獲得コストを参照)と比較するものである。これは、デジタルヘルス組織の成長が財務的に持続可能かどうかを判断するための、単一の最も重要なユニットエコノミクス指標である。なぜなら、成長曲線がどれほど肯定的に見えても、損失を出して獲得された拡大する顧客ベースは健全性の兆候ではないからである。

## なぜ重要か

デジタルヘルス組織は、獲得コストが生涯価値を上回る場合、ユーザーベースを着実に成長させながら、新規顧客ごとに静かに価値を破壊することがある。LTV対CAC比率は、成長率や生の顧客数だけでは不可能な方法で、これを可視化する指標である。3:1の比率(生涯価値が獲得コストの少なくとも3倍)は、持続可能なサブスクリプションまたは経常収益ビジネスにとって広く引用される基準ベンチマークであり、獲得を超えた運営コストをカバーしながらも利益を生み出すのに十分なマージンを可能にする。1:1を下回る比率は、組織が獲得するすべての顧客で損失を出していることを意味し、3:1をはるかに上回る比率(例えば10:1以上)は、実際には成長への過少投資を示している可能性がある。なぜなら、それは組織が現在よりも多くの顧客を利益を出しながら獲得できることを示唆しているからである。デジタルヘルス企業の財務的持続可能性を評価する投資家、取締役会、支払者は、この比率を最初に尋ねる数値の1つとして扱う。

## 算出方法

```
LTV = 期間あたり顧客あたりの平均収益(またはマージン) × 同じ
      期間単位での平均顧客生涯

LTV対CAC比率 = LTV / 真のCAC

3:1の比率は一般的に引用される持続可能な基準である。1:1を下回る
場合、組織は獲得で損失を出していることを示す。3:1をはるかに
上回る場合(例:10:1以上)、成長への過少投資を示している
可能性がある。
```

## 計算例

あるデジタルヘルスサブスクリプションサービスが患者1人あたり月平均$40の収益を生み出し、平均患者は18か月間サブスクリプションを継続し、LTVは$40 × 18 = $720となる。このサービスの真のCAC(その項目の計算例のアプローチを参照)は、獲得患者1人あたり$180と計算される。LTV対CAC比率は$720 / $180 = 4:1であり、3:1の持続可能性基準を快適に上回っている。真のCACが広告プラットフォームが報告するコストのみ($120、代理店費用と受付人件費を含める前)を使用して計算された場合、比率は6:1として現れる——真の4:1の数値よりも大幅に好ましく、誤解を招くユニットエコノミクスの姿である。

## データソースと注意点

LTVは平均顧客生涯についての仮定に依存しており、これ自体は組織自身の継続またはチャーンデータ(ユーザー継続率を参照)から導出される——チャーンの高いビジネスは、1期間あたりの顧客あたり収益が健全に見えても、実効的な平均生涯が短くなり、したがってLTVが低くなる。LTVは観察された過去の事実ではなく将来を見据えた推定値であるため、継続データが蓄積されるにつれて定期的に再計算され、チャーンの仮定が誤りであることが判明した場合には修正されるべきであり、一度決めたら放置されるべきではない。この比率でプラットフォームが報告するCACを真のCACの代わりに使用することは、組織が自身のユニットエコノミクスが実際よりも健全であると自分自身を納得させる最も一般的な方法の1つである。過小評価されたCACは機械的に比率を膨らませるためである。

## 落とし穴

- **プラットフォームが報告するCACを真のCACの代わりに使用すること**: これは比率を機械的に膨らませ、持続不可能な獲得戦略を持続可能に見せる可能性がある。常に全負荷の真のCAC数値を使用すること。
- **古いまたは楽観的な平均顧客生涯の仮定を使用すること**: 古い継続曲線から計算されたLTVは、特に継続を変化させる製品、価格、または市場の変化の後では、現在のチャーン行動を反映しない。
- **非常に高い比率を無条件に良いと扱うこと**: 3:1をはるかに上回る比率は、例外的な効率性ではなく成長への過少投資を示している可能性がある。それは組織が現在よりも多くの顧客を利益を出しながら獲得できる可能性が高いことを示唆するためである。
- **非常に異なる顧客セグメントにわたって1つの統合比率を計算すること**: 高収益で低チャーンのセグメントが、ユニットエコノミクスの悪い別のセグメントを隠してしまう可能性がある。ボリュームが許す限り、意味のあるセグメント(例えば獲得チャネルや製品ラインによる)ごとに比率を計算すること。
