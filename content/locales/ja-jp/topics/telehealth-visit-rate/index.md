# 遠隔医療受診率

遠隔医療受診率とは、対面ではなくビデオまたは電話を通じて遠隔で提供される、サービス全体の接触件数に占める割合です。これは活動指標ではなく、ケア提供チャネルの構成比率を示す指標です。ケア全体としてどれだけ提供されているかとは全く別に、ケアがどのように提供されているかを示すものであり、これはキャパシティ計画、アクセス、臨床的適切性にとって重要です。

## なぜ重要なのか

新型コロナウイルス感染症(COVID-19)のパンデミック中にバーチャル診療が急速に拡大して以来、遠隔で提供されるケアの割合は多くのサービスの運営モデルを変えてきました。組織は、この変化が維持されているのか、パンデミック以前の水準に徐々に戻りつつあるのか、あるいは方針によって積極的に誘導されているのかを監視する安定した方法を必要としています。遠隔医療は対面受診の均一な代替手段ではありません。適切性は専門分野(薬剤レビューは身体診察とは大きく異なる振る舞いをします)や患者の希望によって異なるため、「適切な」比率は臨床的・運営的な判断の問題であり、最大化すべき目標ではありません。資金提供者や規制当局も、結果指標や安全性指標とともにこの比率を用いて、払い戻し方針を決定したり、対面で診るべき症例に遠隔ケアが単に置き換えられていないかを確認したりしています。

## 計算方法

```
遠隔医療率 = 遠隔医療の接触件数 / (遠隔医療の接触件数 + 対面の接触件数) × 100

可能な場合はモダリティ別に分けて報告してください:
  ビデオ率 = ビデオによる接触件数 / 総接触件数 × 100
  電話率   = 電話のみによる接触件数 / 総接触件数 × 100

分母には、定められたサービス、専門分野、期間について完了した
接触のみを計上すべきです(よくある間違いを参照)。
```

## 解決済みの例

ある地域精神保健サービスは、四半期に4,000件の完了した外来接触を記録しています。内訳は対面1,200件、ビデオ1,600件、電話1,200件です。遠隔医療率は(1,600 + 1,200) / 4,000 × 100 = 70%で、ビデオ率は40%、電話のみの率は30%です。合算した70%という数字だけを報告すると、ここでの「遠隔医療」の大部分が音声のみであるという事実が隠れてしまいます。これは通常、異なる臨床リスクプロファイルと患者体験を伴います。

## データソースと注意点

接触の種類は通常、電子カルテ内の構造化フィールド(受診タイプまたは場所)として記録されるか、サービス提供場所コードや請求書上の遠隔医療修飾子といった請求コードから推測されます。コーディングの慣行は組織間、さらには同じ組織内の臨床医間でも大きく異なるため、施設間で比率を比較する前に、まず「遠隔医療」がどの施設でも同じ方法でコーディングされているかを確認すべきです。ビデオで始まったが技術的な問題で電話に切り替わった受診は、一貫してコーディングされるべきです(通常、臨床内容の大部分を担ったモダリティに従います)。このルールは個々の判断に委ねるのではなく、文書化すべきです。

## よくある間違い

- **完了した受診ではなく試みられた受診を数える**: 接続に失敗して再予約された遠隔医療の予約は、遠隔医療の分母を二重に膨らませるべきではありません。
- **ビデオと電話を互換可能なものとして扱う**: 両者は臨床的にも公平性の観点からも異なる含意を持ちます(電話は視覚的評価を除外しますが、スマートフォンや信頼できる通信環境、ビデオのためのプライベートな空間を持たない患者にとってはよりアクセスしやすいものです)。可能な限り常に別々に報告してください。
- **不履行との関連を無視する**: 不履行の傾向はモダリティによって異なることが多いです。遠隔医療率の上昇だけから「アクセスの改善」という結論を出す前に、[予約不履行率](../appointment-no-show-rate/)を参照してください。
- **高い比率を本質的に良いものとして扱う**: 一部の疾患や受診タイプでは、適切な遠隔医療率は臨床的な設計によって低く抑えられているのであり、デジタル成熟度の不足によるものではありません。
