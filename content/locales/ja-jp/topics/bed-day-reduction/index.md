# 病床日数削減

病床日数削減とは、定められたケアエピソード——最も一般的には術後回復や急性疾患管理——を、従来の入院からバーチャル病棟や在宅入院プログラムのようなデジタル支援型の代替手段へと移行させることによって回避された入院病床日数の総数を測定する。これはバーチャル病棟や在宅入院イニシアチブにとっての主要なキャパシティ指標であり、臨床ケアモデルの変化を、病院運営やシステムプランナーが実際に管理対象とする通貨(病床キャパシティ)に直接変換するものである。

## なぜ重要か

入院病床キャパシティは、あらゆる病院システムにおいて最も制約が厳しく高コストな資源の1つであり、バーチャル病棟や在宅入院プログラムの中心的な価値提案は、物理的な病床を占有することなく、定められたレベルの臨床ケアを安全に提供できることであり、そのキャパシティを他の方法では管理できない患者のために解放することである。病床日数削減は、しばしば抽象的な主張(「このプログラムはケアを改善する」)を、病院のキャパシティプランナー、財務チーム、委託者が直接行動できる具体的な運用上の数値に変換する。これは、モニタリングプログラムへの投資が回避された病床コストでそれ自体の元を取るかどうか、そしてどれだけ取るかをモデル化するために使用できる。病床日数削減は患者の安全性が維持されている場合にのみ価値があるため、同じ集団について安全性成果指標(再入院率や入院ケアへのエスカレーション率など)と常に併せて報告されるべきであり、それに代わって報告されるべきではない。

## 算出方法

```
病床日数削減 = 標準的な入院ケアの下での予想病床日数(マッチング
              された患者コホートの過去の在院日数データに基づく)
              − バーチャル/デジタル経路の患者が実際に使用した
              病床日数

臨床経路ごとに報告すること(例:術後回復、急性呼吸器増悪)。
予想される在院日数は疾患によって大きく異なり、無関係な経路に
わたる統合された数値は意味をなさないためである。
```

## 計算例

ある病院の過去データは、特定の選択的外科手術から回復する患者の平均入院在院日数が4日であることを示している。あるバーチャル病棟プログラムが、同じ手術から回復する150人の患者を登録し、平均1.5入院日後に退院させ、残りの回復は遠隔でモニタリングされる。病床日数削減は、測定期間にわたって(4 − 1.5) × 150 = 375病床日である。この数値は、同じ150人の患者について、バーチャル病棟コホートの30日間の入院ケアへのエスカレーション率と再入院率とともに報告されるべきである。入院ケアへのエスカレーション率や再入院率が著しく高くなることで得られる病床日数の節約は、見出しの数値がそうでなければ示唆するような臨床的勝利ではないからである。

## データソースと注意点

予想病床日数には、信頼できる過去のベースラインが必要であり、理想的にはバーチャル病棟集団と類似した臨床的特徴(年齢、併存疾患、手術タイプ、重症度)を持つ、標準的な入院ケアの下で治療されたマッチングされた患者コホートから得られるべきである。マッチングされていない過去の平均と比較すると、デジタル管理されたコホートが過去の比較グループよりも体系的により健康であるかより重症であるかによって、真の削減を過大または過小評価するリスクがある。デジタル経路で使用された実際の病床日数は、病院自体のadmission-discharge-transfer(ADT)システムから得られる。モニタリングされた回復期間中に入院ケアへ戻るエスカレーションは、プログラムに対して誠実にカウントされるべきであり(使用された病床日数として、除外されるのではなく)、計算からエスカレーションを除外すると、見かけ上の削減を人為的に膨らませることになるためである。

## 落とし穴

- **マッチングされた安全性比較なしに病床日数削減を報告すること**: 病床日数を節約するが標準ケアよりも著しく悪いエスカレーションまたは再入院率を持つバーチャル病棟は、真の改善を示したことにはならない。常に両方を一緒に報告すること。
- **マッチングされていない、または時代遅れの過去のベースラインを使用すること**: 異なるケースミックス、併存疾患の負担、または臨床実践の時代を持つ過去のコホートと比較すると、真の病床日数の節約を大幅に過大または過小評価する可能性がある。
- **入院ケアへのエスカレーションを計算から除外すること**: バーチャルにモニタリングされているが回復の途中で入院病床にエスカレーションされた患者は、その病床日数がプログラムに対してカウントされるべきであり、黙って分析から除外されるべきではない。
- **予想される在院日数が大きく異なる経路を混ぜること**: 臨床的に無関係な経路(例えば、術後回復と慢性呼吸器管理を組み合わせること)にわたって病床日数削減を1つの数値に集計すると、どの特定の経路が実際に節約を牽引しているかが不明瞭になる。
