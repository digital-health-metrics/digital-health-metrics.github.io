# デジタル紹介処理時間

デジタル紹介処理時間とは、紹介元の臨床医が電子紹介状を提出してから、受け入れ側のサービスがトリアージを行い、受理、拒否、または予約に至るまでの経過時間です。これは患者の総待ち時間とは異なるプロセス(フロー)指標であり、デジタルシステムの変更(構造化された電子紹介、画像ベースのトリアージ、標準化された紹介フォーム)が、単なる満足度スコアではなく実際の運用上の数値を動かしていることを示すことができる、最も明確な事例の一つです。

## なぜ重要なのか

トリアージ段階が遅い、あるいは大きくばらつく場合、患者が臨床的な待機リストに加わる前の時点ですでに遅延が生じます。この遅延はいかなる臨床ケアが始まる前に発生するため、デジタルツールが取り除くのに適した純粋なプロセスの無駄です。情報不足のために「紹介元への差し戻し」のサイクルを強いる紹介システムは、再作業のループを生み出しますが、処理時間を最初からきれいに通過した紹介状のみで測定していると、これを見落としがちです。あるサービスが構造化されたデジタル紹介フォーム、必須項目、あるいは画像ベースのトリアージ(例えば遠隔皮膚科診療)を導入した場合、処理時間は通常、変更の前後で同じ計測手段によって測定可能であるため、その効果を示す最も説得力のある単一の指標となります。

## 計算方法

```
処理時間 = タイムスタンプ(トリアージ決定) − タイムスタンプ(紹介提出)

差し戻しや複雑な紹介によって分布が右に大きく偏るため、平均だけでなく
中央値と高いパーセンタイル(通常は90パーセンタイル)を報告してください。

システムが記録している場合は、サブステージごとの時間も考慮してください:
  提出 → サービスによる受領
  受領 → トリアージ決定
  トリアージ決定 → 予約確定(該当する場合)
```

## 解決済みの例

ある電子紹介システムの監査記録によると、すべての専門分野を通じて提出からトリアージ決定までの中央値は1.8日、90パーセンタイル値は6日であり、これは主に臨床情報の不足により紹介元に差し戻された紹介状によるものです。同じプラットフォームで画像ベースのトリアージを利用する遠隔皮膚科診療の経路は、中央値の処理時間4時間、90パーセンタイル1日を達成しています。これは、写真と構造化された病歴だけで、追加のやり取りをほぼ必要とせずにトリアージ決定を下すのに十分だからです。

## データソースと注意点

電子紹介または紹介管理システム自体の監査記録が、提出と決定のタイムスタンプを用いる主要なデータ源です。組織は、紹介状が追加情報のために差し戻されている間「時計」が一時停止するのか、それとも継続して動き続けるのかを確認すべきです。この2つの定義は、同じ基盤となるプロセスに対してかなり異なる数値を生み出すためです。処理時間は、週末や祝日の影響によって異なる勤務パターンを持つサービス間の比較が歪められないよう、暦時間または営業時間のいずれかで一貫して報告すべきです。

## よくある間違い

- **「きれいな」紹介状のみを測定する**: 拒否または差し戻された紹介状を計算から除外すると、デジタルツールがまさに軽減しようとしている再作業の負担が見えなくなります。
- **中央値やパーセンタイルの代わりに平均を報告する**: 長期化し差し戻された紹介状が少数あるだけで、平均は典型的な患者の実際の経験よりもはるかに高く引き上げられます。
- **処理時間を総待ち時間と混同する**: 処理時間はトリアージ段階のみをカバーします。患者の全体的な経験には、別のキャパシティ制約によって左右される、別個の指標である下流の臨床待機リストも含まれます。
- **サブステージを区別しない**: エンドツーエンドの時間のみを測定するサービスでは、遅い数値が紹介元による不完全な情報提出によるものなのか、受け入れ側サービスのトリアージ能力によるものなのか、あるいはその両方なのかを判断できません。
