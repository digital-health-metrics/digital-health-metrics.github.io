# 臨床アラート無効化率

臨床アラート無効化率は、コンピュータ化された医師指示入力システム(CPOE)が生成する薬物相互作用の警告、アレルギーアラート、用量範囲チェックなど、臨床意思決定支援(CDS)アラートのうち、臨床医が対応する代わりに却下または無効化する割合を測定します。これは、低価値の警告量が過剰になったときに臨床医がアラートに対して鈍感になっていくという、よく文書化された傾向である「アラート疲労」を検出・管理するために使われる標準的な定量指標です。

## なぜ重要なのか

薬物相互作用アラートについて公表されている無効化率は、一般的に約半分から90%超まで幅がありますが、高い比率が自動的に安全性の失敗を意味するわけではありません。多くの中断型アラートは、文脈上は臨床的に意味のない相互作用に対して発生するか、臨床医が同じ指示セット内ですでに対応したアラートを繰り返すものです。そのため、うまく調整されたシステムは、無効化率をゼロに近づけようとするのではなく、意図的により少なく、より価値の高いアラートを発生させます。安全性にとって実際に重要なのは、時間の経過に伴う傾向、重症度レベルごとの分布、そして臨床医が高重症度のアラートを無効化する際に理由を文書化しているかどうかです。すべてのアラートを平均すると安定して見える場合でも、高重症度でよく実証された相互作用に対する無効化率の上昇は、実質的なガバナンス上の懸念事項です。

## 計算方法

```
無効化率 = 無効化されたアラート数 / 発生した総アラート数 × 100

以下の軸でセグメント化してください:
  - 重症度レベル(例: 禁忌、重大、中等度)
  - アラートの種類(薬物間相互作用、アレルギー、重複治療、用量範囲)
  - 無効化の理由が文書化されたかどうか

「文書化された無効化率」は、記録された根拠を伴う無効化の割合を
追跡するもので、それ自体が一つのガバナンス指標です。
```

## 解決済みの例

ある病院のCPOEシステムが1か月間に薬物相互作用アラートを10,000件発生させ、そのうち8,700件が無効化され、全体の無効化率は87%となりました。重症度別に見ると、500件の「禁忌」アラートのうち60件が無効化され(12%)、6,000件の「中等度」アラートのうち5,700件が無効化されています(95%)。中等度レベルの数値は公表されている基準とおおむね一致しており、それ自体は懸念すべきものではありません。禁忌レベルの数値は個別の事例レビューに値するものであり、最も実用的なガバナンス上の発見は、そのレベルにおける500件の無効化のうち文書化された理由を伴うのはわずか340件であるという点です。

## データソースと注意点

電子カルテの監査ログ、あるいはCDSベンダー自体のアラートモジュールが、臨床医が自由記述または構造化された根拠を入力したかどうかを含め、アラート発生およびアラート対応のすべてのイベントを記録します。組織間、あるいは同じ組織内の部門間で無効化率を比較するには、基盤となるアラートのルールセットと重症度の階層化が同一であることを確認する必要があります。積極的に調整されたルールセットを持つ病院は、臨床医の行動とは無関係な理由でより低い無効化率を示すでしょう。

## よくある間違い

- **生の無効化率を単一の安全性スコアとして扱う**: これは、低価値アラートの十分に正当化された無効化と、実際に危険な相互作用の安全でない無効化を混同します。常に重症度別にセグメント化してください。
- **無効化理由を記録していない**: 文書化された理由がなければ、「このアラートが間違っていた」のか「このアラートは正しかったが、臨床医が安全でない判断を下した」のかを区別することができません。これこそが患者安全にとって実際に重要な区別です。
- **時間の経過に伴うアラートルールのインフレ**: 低価値のものを整理せずに「念のため」アラートを追加し続けることは、無効化率の上昇とアラート疲労の直接的な原因です。アラートガバナンスには、単なる監視だけでなく、成果の低いルールの定期的な見直しと廃止を含めるべきです。
- **中断設計の異なるシステム間で比率を比較する**: 強制停止型の中断アラートは、受動的で非ブロッキング型のアラートとは異なる無効化行動を生み出すため、この2つは直接比較可能な指標ではありません。
