# ケアエピソードあたりコスト

ケアエピソードあたりコストとは、定義された臨床エピソード——例えば股関節置換術とそれに伴う回復、または糖尿病管理期間——の治療にかかった総コストを、評価対象のデジタル介入なしで治療された過去のベースラインコホートと比較するものである。これは価値ベースケアにおける財務比較の標準単位である。なぜなら、単一の費目を孤立して見るのではなく、エピソードの完全な経済的全体像を捉えるからであり、支払者や医療システムが大規模にデジタルヘルスプログラムへの資金提供に同意する前に最も頻繁に要求する指標である。

## なぜ重要か

価値ベースケア契約は、個々のサービスではなく成果やエピソードに対してますます支払うようになっており、これはデジタルヘルスプログラムの財務的な論拠が同じ通貨で構築されなければならないことを意味する:エピソードあたりの総コストを、その介入が存在する前に同じタイプのエピソードにかかっていたコストと比較するものである。あるコストカテゴリーを削減する(例えば、対面フォローアップ訪問の減少)一方で別のカテゴリーを増加させる(より多くのデバイスコスト、より多くの臨床モニタリングスタッフの時間)プログラムは、必ずしもエピソードあたりの総コストを削減したわけではなく、この取引を捉えるのはエピソードレベルの完全なコスト計算のみである。どの単一の費目を孤立して見ることも、どちらの方向でも誤解を招く結論のリスクを伴う。エピソードの定義とベースライン期間は特定の結論を有利にするように構築される可能性があるため、この指標は、懐疑的な支払者や財務チームに信頼されるために、本書の他のほとんどの指標よりも大きな方法論的透明性を必要とする。

## 算出方法

```
ケアエピソードあたりコスト = 定義されたエピソードウィンドウ内で
                            提供されたすべてのケアの総コスト
                            (すべてのケア設定、すべてのコスト
                            カテゴリー) / エピソード数

同じ臨床的に定義されたエピソードタイプについて、過去のベース
ラインコホートのエピソードあたりコストと比較し、両コホート間の
ケースミックス(年齢、併存疾患、重症度)について調整すること。

直接的な臨床コストだけでなく含めること: テクノロジープラット
フォームとデバイスのコスト、追加の臨床スタッフの時間、そして
完全に消滅するのではなく設定が移行したケア(例:入院から在宅へ)。
```

## 計算例

ある医療システムの股関節全置換術エピソード(手術から90日間の回復まで)の過去のベースラインコストは、200件の過去のエピソードに基づいてエピソードあたり$28,000である。新しいデジタル術後モニタリングプログラムが導入され、このプログラムを使用した150件の新しいエピソードは、エピソードあたり平均$24,500のコストを示す——エピソードあたり$3,500の削減であり、主に回復中の救急外来受診の減少とより短い平均入院期間によって牽引されている。デジタルモニタリングされたコホートが過去のベースラインと比較してわずかに若く併存疾患の少ないケースミックスであることについてリスク調整した後、調整された節約額はエピソードあたり$2,100に縮小する——依然として真の改善であるが、調整前の生の比較が示唆したものよりも物質的に小さい。

## データソースと注意点

総エピソードコストは通常、医療システム自体のコスト会計または財務システムから組み立てられ、請求データ、内部コスト配分、そしてデジタルプラットフォームが関与する場合はそのライセンスとハードウェアコストを組み合わせる——この数値を正確に組み立てることは、通常あらゆるデジタルヘルス価値分析の中で最も困難でリソース集約的な部分である。コストは頻繁に、エピソードレベルで結合するために設計されたことのない別々のシステムに記録されているためである。ケースミックス調整は、デジタル管理されたコホートと過去のベースラインコホートが真の無作為化によって割り当てられなかった場合には常に不可欠である。デジタルプログラムは、より積極的で、一般的により健康で、またはより意欲的な患者に最初に提供されることが多く、これは真のプログラム効果ではなく選択効果である見かけ上のコスト削減を生み出す可能性があるためである。

## 落とし穴

- **異なるケースミックスを持つコホート間で未調整のコストを比較すること**: たまたまより健康または低リスクであるデジタル管理されたコホートは、デジタル介入自体とは無関係な理由で、過去のベースラインよりも低いエピソードあたりコストを示す。比較する前に常にリスク調整を行うこと。
- **比較の「デジタル」側からテクノロジーとスタッフのコストを省略すること**: 臨床利用の減少のみを追跡し、デジタルプログラムを運営するプラットフォーム、デバイス、スタッフのコストを無視するコスト分析は、純節約を過大評価することになる。
- **コホート間でエピソードウィンドウを一貫性なく定義すること**: あるコホートに90日のエピソードウィンドウを使用し、別のコホートに60日のウィンドウを使用して比較すると、実際には同じものを測定していないコスト比較が生成される。
- **コストの移行をコストの削減として扱うこと**: あるケア設定から別の設定へ移行したコスト(例えば入院からモニタリングされた在宅設定へ)は真の価値ある発見であるが、完全に排除されたコストとは分析的に異なり、両者は別々に報告されるべきである。
