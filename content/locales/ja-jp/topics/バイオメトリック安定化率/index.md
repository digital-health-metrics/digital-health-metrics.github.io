# バイオメトリック安定化率

バイオメトリック安定化率とは、接続されたモニタリングデバイスを使用して、単一の時点ではなく持続的な期間にわたり、バイオメトリック指標について臨床的に定義された目標範囲——最も一般的には130/80 mmHgのような閾値以下の血圧——を達成し維持している登録患者の割合を指す。これはバイオメトリック改善率(その項目を参照)とは異なる。改善はベースラインからの変化の大きさを測定するが、安定化は治療やモニタリングが開始された後、患者が安全な範囲内に確実に維持されているかどうかを測定する。これは、すでに目標に近いか、すでに治療中の患者にとって最も重要な成果である。

## なぜ重要か

慢性疾患プログラムの患者の大部分——特に高血圧では、ガイドラインの血圧目標が十分確立されており心血管リスクに直接結びついている——にとって、臨床的な目標は一回限りの改善ではなく持続的なコントロールであり、目標範囲を出入りして振動する患者は、一度改善してそのまま維持する患者とは物質的に異なるリスクをもたらす。接続デバイス(セルラー血圧計、持続血糖モニター)は、診察時のみではなく継続的に安定化を測定することを可能にし、診察時の読み取り値は制御されているように見えるが自宅での読み取り値は不安定である患者を明らかにする——これは仮面高血圧として知られるパターンであり、定期的な対面測定だけでは検出できない。単一の「目標達成」スナップショットだけでなく安定化率を報告することで、プログラムはどれだけ頻繁にではなく、どれだけ一貫して患者を範囲内に維持しているかに向き合うことを強いられる。

## 算出方法

```
バイオメトリック安定化率 = 測定期間中の読み取り値の80%以上が
                         目標範囲内にある患者数 / その期間に
                         最低限の有効な読み取り回数を持つ
                         患者数 × 100

閾値の例:
  血圧   — 目標 < 130/80 mmHg(または患者のリスクプロファイルに
          適用される臨床ガイドライン閾値)
  血糖値 — 持続血糖モニタリングガイダンスに従った目標範囲、
          「範囲内時間」として報告

患者が読み取り頻度の少なさで人工的に安定しているように見える
ことを避けるため、患者を分母に含める前に最低読み取り頻度閾値
(例:週3回以上)を設定すべきである。
```

## 計算例

ある高血圧遠隔モニタリングプログラムが、セルラー血圧計を持つ600人の患者を登録し、それぞれ週に3回以上の測定が期待されている。このうち540人が3か月の測定期間にわたって最低読み取り頻度閾値を満たし、分母に含まれる。その540人のうち、350人が読み取り値の80%以上で130/80 mmHg未満であり、バイオメトリック安定化率は350 / 540 × 100 = 65%となる。読み取り不足のため除外された60人は、分子にも「未安定化」グループにも組み込まれず、データ完全性のギャップとして別途報告される。彼らの真のコントロール状態は不良なのではなく、実際には不明だからである。

## データソースと注意点

読み取り値は接続デバイス自体のデータストリームから直接得られる。これは診察時の測定よりも客観的でかつはるかに頻繁であるが、デバイスの装着位置や技術の誤り(サイズや位置が不適切な血圧計カフ)は、単一の診察時検証読み取りでは必ずしも検出できない体系的バイアスをもたらす可能性がある。目標範囲の選択は、単一の普遍的な閾値ではなく、患者固有のリスクプロファイルと併存疾患に適用される現行の臨床ガイドラインに従うべきである。ガイドラインの目標値は患者の年齢、腎機能、心血管リスクによって異なるためである。読み取り頻度の低い患者をデフォルトで黙って「安定」とカウントすべきではない。除外を透明に報告しながら分母から除外する方が、少なすぎるデータに基づいて制御されている、または制御されていないとカウントするよりも誠実である。

## 落とし穴

- **単一の範囲内読み取りを安定化として扱うこと**: 安定化とは定められた期間にわたる持続的なコントロールのことであり、スナップショットではない。その期間にわたる範囲内読み取りの最低限の割合を常に要求し、単一の該当測定値だけに頼らないこと。
- **読み取り頻度の少ない患者を報告せずに黙って除外すること**: めったに読み取りを行わない患者は自動的に安定または不安定というわけではない。分母から透明に除外し、除外率を別個のデータ完全性指標として報告すること。
- **デバイスの較正と技術エラーを無視すること**: 不適切にフィットしたカフや較正されていないデバイスは、読み取り値を一方向に体系的に偏らせる可能性があり、生のデバイスデータから単純に計算された安定化率は、定期的な検証なしにはこれを検出できない。
- **すべての患者に単一の普遍的な目標範囲を使用すること**: 臨床ガイドラインの目標値は患者のリスクプロファイルと併存疾患によって異なる。臨床的に多様な集団に一律の閾値を適用すると、実際の個別化された目標に対して一部の患者を誤って安定化または未安定化と分類することになる。
