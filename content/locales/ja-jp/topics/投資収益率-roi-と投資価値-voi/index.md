# 投資収益率(ROI)と投資価値(VOI)

投資収益率(ROI)は、デジタルヘルスプラットフォームがその総コスト——ライセンス、ハードウェア展開、実装、継続的な人員配置——に対して生み出す純財務リターンを、比率またはパーセンテージとして表したものである。投資価値(VOI)は、純粋な財務ROI計算では捉えられないリターンを捉える、より広範な補完的指標である:ケアの質の改善、患者と臨床医の満足度、健康公平性への影響、組織の評判であり、これらのいずれもドル数値にきれいに変換されることはないが、すべてがデジタルヘルス投資が成功と見なされるべきかどうかに関係する。両者を合わせて、2つの異なる補完的な質問に答える:ROIは「これは財務的に元を取ったか?」と問い、VOIは「重要なすべてを考慮して、これは行う価値があったか?」と問う。

## なぜ重要か

初年度に乏しいまたは負のROIを示すデジタルヘルス投資は、ROI計算が純粋なコスト相殺以外でプログラムが生み出す重要な価値を無視している場合、自動的に失敗というわけではなく、強いROIを示すものが自動的に成功というわけでもない——これはまさにVOIが埋めるために存在するギャップであり、ROIのみに依存する組織は、まだ、あるいは決して直接的な財務リターンとして現れない真の価値を持つプログラムへの資金提供を打ち切るリスクを負う。同時に、VOIはROIよりも主観的でベンチマークが難しく、実際には何ら測定可能な価値を提供していないプログラムへの継続投資を正当化するために使用されることに対して脆弱になる。両者を一緒に報告し、VOIの構成要素を可能な限り具体的で測定可能にするという規律が、このフレームワークを財務的説明責任を回避する方法になることから守り、誠実に保つものである。長期的なデジタルヘルス投資の決定——特に、質と公平性の成果が支払いに直接結びついている価値ベースケアにおいて——は、ますます両方の数値を並べて必要とするようになっている。

## 算出方法

```
ROI = (財務的便益 − 総投資コスト) / 総投資コスト × 100

財務的便益の源泉: ケアエピソードあたりコストの削減、病床日数
削減(コスト数値に変換)、回避されたED受診(救急外来転送回避率
を参照)、削減された再入院ペナルティ、および直接的な収益。

総投資コスト: プラットフォームライセンス、ハードウェア/デバイス
の展開と保守、実装と統合のコスト、継続的な臨床・技術スタッフ
配置。

VOIは単一の公式ではなく、定義され追跡された非財務的価値ドメイン
をROIと組み合わせた、構造化された多次元スコアカードである。
例えば:
  臨床品質   (例:バイオメトリック改善率、再入院率)
  患者体験   (例:患者ネットプロモータースコア、SUSスコア)
  公平性     (例:デジタルアクセス率、デジタルリテラシー率)
  労働力     (例:医師バーンアウト率)
各ドメインは、人為的にドル数値に変換されるのではなく、財務ROI
数値とともにそれ自体の条件で報告される。
```

## 計算例

ある遠隔モニタリングプログラムは初年度に$600,000の費用がかかる(プラットフォームライセンス、デバイス展開、追加の臨床スタッフ配置)。そして$750,000の定量化可能な財務的便益を生み出す(病床日数削減と回避された再入院ペナルティ)。ROIは($750,000 − $600,000) / $600,000 × 100 = 25%である。この数値とともに、組織のVOIスコアカードは、患者ネットプロモータースコアの5ポイント改善、登録された高血圧患者のバイオメトリック安定化率68%、そして登録された臨床医の時間外文書作成時間の測定された削減を報告する。これら3つの追加の発見のいずれも25%のROI数値を変えないが、合わせると、特に質と公平性の成果を財務的リターンと同じくらい重視するステークホルダー(臨床リーダーシップ、患者擁護団体)にとって、ROI数値だけが支持するものよりも物質的に強い継続投資のケースを構築する。

## データソースと注意点

ROIの財務的便益の側面は、本書の他の場所で使用されているのと同じコストと成果のデータ——ケアエピソードあたりコスト、病床日数削減、救急外来転送回避率——に依拠しており、組織自身のコスト会計方法論を使用してドル数値に変換される。楽観的な最善のケースの仮定ではなく、保守的で擁護可能な仮定を使用すべきである。攻撃的な仮定に基づいて構築されたROI数値は、懐疑的な財務チームの精査に耐えられないためである。VOIの非財務ドメインはそれぞれ、非公式に考案された代替物ではなく、本書の他の場所からすでに検証済みの指標(バイオメトリック安定化率、患者ネットプロモータースコア、デジタルアクセス率、医師バーンアウト率)を使用すべきであり、それによってVOIスコアカード自体が、緩く定義されたナラティブになるのではなく、時間をかけて監査可能で比較可能なままであり続ける。

## 落とし穴

- **重要な非財務的価値を持つプログラムについてROIのみを報告すること**: これは、その価値が純粋な財務計算に現れないという理由だけで、真の臨床的、公平性的、または労働力的価値を持つプログラムへの資金提供を打ち切るリスクを伴う。ROIを構造化されたVOIスコアカードと組み合わせること。
- **VOIを財務的説明責任を回避する方法として扱うこと**: VOIは各非財務ドメインについて具体的で以前に検証された指標を使用すべきであり、曖昧または測定されていない価値の主張ではない。そうでなければ、真の証拠なしに継続的な支出を正当化する方法になってしまう。
- **ROIのコスト回避計算で楽観的または未検証の仮定を使用すること**: 回避されたコストについての攻撃的な仮定に基づいて構築されたROI数値は精査に耐えられず、将来の投資ケースの信頼性を損なう可能性がある。
- **調整なしに非常に異なるコスト構造を持つプログラム間でROI数値を比較すること**: 高い前払い資本コストと長い回収期間を持つプログラムは、関与する異なる時間軸を考慮せずに、低い前払いコストと速い回収を持つプログラムに対して単年度のROI数値で比較すべきではない。
