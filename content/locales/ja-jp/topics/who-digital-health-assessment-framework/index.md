# WHOデジタルヘルス評価フレームワーク

世界保健機関(WHO)は、国家規模の展開の前、最中、後にデジタルヘルス介入を評価するための一連のガイダンスを発行しており、モニタリングと評価の方法論、介入タイプの標準分類、そしてデジタルヘルスプログラムが拡大の準備ができているかどうかを判断するためのツールキットにまたがっている——公平性、実現可能性、安全性に特別かつ一貫した重点を置いており、これは非常に異なるデジタルおよび医療システムインフラを持つ国々にわたって集団の健康を保護するというWHOの使命を反映している。単一の名前付きチェックリストとは異なり、これは、国家または地域のデジタルヘルス展開を評価する組織が通常一緒に活用する、WHO刊行物の一貫した集合として理解する方が適切である。

## なぜ重要か

資源の豊富なパイロット環境でうまく機能するデジタルヘルス介入は、接続性、デジタルリテラシー、言語、医療システムの能力において著しく異なるレベルを持つ集団にわたって国家規模で展開されると失敗したり、積極的に害をもたらしたりすることがある——これはまさにWHOのガイダンスが埋めるために存在するギャップである。WHOの中核的な使命は、単一の医療システムやベンダーの利益ではなく、非常に不均等に資源が配分された加盟国全体の集団の健康公平性だからである。WHOの枠組みはまた、安全性と実現可能性を、介入がすでに機能した後に評価される後付けの考慮事項としてではなく、ゲーティングの考慮事項として扱う:デジタルヘルスツールは、単に集計で効果的であることが示されるだけでなく、拡大が検討される前に、不公平を悪化させたり新たな安全性リスクを導入したりしないことが示されなければならない。国家または複数国のデジタルヘルス展開を計画している組織にとって、評価をWHOのガイダンスに合わせることは、しばしば実際的な必要性でもある。これは保健省や多国間資金提供者が最も参照または要求する可能性の高いフレームワークだからである。

## 適用方法

```
WHOのガイダンスは、単一のスコア化されたチェックリストではなく、
いくつかの連動した評価活動にわたって適用される:

分類                 — 他の場所で評価された類似の介入との同等の
                      比較を確実にするために、WHOのDigital
                      Health Interventionsの分類に対して介入を
                      カテゴリー分けすること

モニタリングと         — 研究デザイン、成果の選択、データ品質を
評価デザイン           カバーする、デジタルヘルス介入のための
                      WHOのモニタリングと評価のガイダンスに
                      従うこと

拡大準備評価          — WHO/ITUと整合した拡大評価ツールキット
                      に対して、基盤整備、パートナーシップ、
                      財務的持続可能性、技術アーキテクチャ、
                      運用能力を評価すること

公平性と安全性の      — 拡大が進む前に、介入がアクセスまたは
レビュー              成果の不公平を悪化させる可能性があるか、
                      あるいは臨床的またはデータプライバシーの
                      安全性リスクを導入する可能性があるかに
                      ついての明示的なゲーティング評価
```

## 計算例

ある保健省が、単一地域のパイロットから国家展開まで、妊産婦健康SMSリマインダーサービスを拡大することを計画している。WHOの分類ガイダンスを適用すると、その介入はクライアント向けの対象を絞ったコミュニケーションデジタルヘルス介入として明確に分類され、完全に新規なものとして評価されるのではなく、他の場所で評価された類似の介入との比較が可能になる。WHOのガイダンスに従って、成果だけでなく到達度と臨床成果の両方を追跡するモニタリングと評価の計画が構築される。拡大準備評価では、パイロット地域のセルラーネットワークの信頼性が全国平均を大幅に上回っていることが特定され、これは公平性と安全性のレビューが重大なリスクをフラグ付けすることを意味する:農村部のネットワークカバレッジを最初に評価せずに全国的に拡大すると、すでにより良く接続されている、より裕福な地域に利益が集中し、既存の妊産婦健康の公平性のギャップを縮小するのではなく拡大する可能性がある。この発見——公平性が後付けの考慮事項ではなくゲーティング基準として扱われたために特に浮上した——は、保健省を、一律に拡大するのではなく、ネットワークカバレッジの層ごとに段階的に展開を進めることに導く。

## データソースと注意点

WHOのガイダンス文書は公開されており自由に入手できるが、それを適用するにはWHO自体が提供しないローカルデータが必要である——展開対象の国や地域に固有の接続性とデジタルリテラシーのデータ、現地の医療システム能力データ、現地の成果データ——これは、フレームワークが評価のための構造を提供するものであり、データそのものを提供するものではないことを意味する。WHOのガイダンスは非常に異なる国家的文脈に適用できるよう意図的に十分一般的であるため、それをうまく適用するには、国特有のリスクを見逃す一般的でチェックボックス式の評価を避けるための、真の現地の専門知識とデータが必要である。現地の医療システムと公平性のデータなしに実施されたWHOに沿った評価は、それが実際に捕捉するよう設計されているリスクを明らかにする可能性は低い。

## 落とし穴

- **分類のみを評価として扱うこと**: 介入のタイプを正しく分類することは比較のための出発点であり、それ自体は介入の安全性、有効性、または拡大への準備の評価ではない。
- **公平性評価をゲートではなく最終的な付加物として扱うこと**: WHOの枠組みは、公平性のリスクを、拡大がすでに起こった後に報告する注記ではなく、展開を遅らせるか再設計する理由として扱う。それを遡及的にのみ評価することはその目的を損なう。
- **現地の文脈データなしにフレームワークを適用すること**: WHOのガイダンスは意図的に一般的である。現地の接続性、リテラシー、医療システム能力のデータなしでは、それに対する評価は真のリスク評価ではなく一般的なチェックリストの演習になってしまう。
- **WHOとの整合が国家の規制または倫理審査の代替になると仮定すること**: WHOのガイダンスは評価に情報を与え構造化するが、国自体が要求する規制、データ保護、または倫理承認のプロセスを置き換えるものではない。
