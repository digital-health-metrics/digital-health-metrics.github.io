# DAU/MAU粘着率

DAU/MAU粘着率は、デイリーアクティブユーザー(DAU)をマンスリーアクティブユーザー(MAU)と比較するものであり——ウィークリーアクティブユーザー(WAU)とMAUを比較する場合も同じ基礎的な測定法が使われる——製品のより広範なユーザーベースのうち、任意の特定の日にエンゲージする割合を表現する。これはエンゲージメント強度の標準的なプロダクトアナリティクス指標であり、ユーザーがそもそも維持されているかどうか(ユーザー継続率を参照)や、特定の1人の登録患者が時間とともにどれだけ一貫してエンゲージしているか(患者エンゲージメント一貫性率を参照)とは異なる。粘着性は個人のパターンではなく、集団レベルの使用リズムを記述する。

## なぜ重要か

2つのデジタルヘルス製品が同一の月間アクティブユーザー数を報告しながら、根本的に非常に異なるエンゲージメント強度を持つことがある。1つはそのユーザーの大部分がほぼ毎日アプリを開く製品であり、もう1つは大部分が非アクティブとしてカウントされる直前に月に一度だけ開く製品である。DAU/MAU粘着率は、この2つの非常に異なる状況を、プロダクトチームや臨床チームが時間をかけて追跡し、既知の業界範囲と比較できる単一のシンプルでよく理解された基準数値で区別する——約20%の比率は多くの消費者向けアプリにとって一般的に引用される妥当なベンチマークであるが、日次習慣型の製品(患者が毎日使用することが期待される食事や症状の日記)は、意味のあるより高い基準に照らして判断されるべきである。粘着性は「アクティブ」がどのように定義されるかに敏感であるため、絶対的な業界横断的ベンチマークとしてよりも、1つの製品の時間経過に伴うトレンドとして、また類似の使用パターン向けに構築された製品との比較として最も有用である。

## 算出方法

```
DAU/MAU粘着率 = 期間内の平均デイリーアクティブユーザー数 / 同じ
               期間のマンスリーアクティブユーザー数 × 100

WAU/MAU比率(週次、同じ原理)はより緩やかなバリアントであり、
毎日ではなく週に数回使用されることが期待される製品により
適している。

「アクティブ」は、分子と分母の両方にわたって正確かつ一貫して
定義されなければならない(例:受動的なアプリの起動ではなく、
完了した該当アクション)。
```

## 計算例

あるデジタル糖尿病管理アプリが、特定の月に10,000人の月間アクティブユーザーを持ち、その月に少なくとも1回の該当アクション(血糖記録、食事記録、または服薬チェックオフ)を完了した任意のユーザーと定義される。その月の30日間の日次アクティブユーザー数の平均は2,200である。DAU/MAU粘着率は2,200 / 10,000 × 100 = 22%であり、典型的な日には、アプリの月間ユーザーベースの約22%がエンゲージしていることを示している——これは日次習慣型の慢性疾患ツールにとって妥当な数値であるが、理想的な行動(日次記録)が登録患者にとってより習慣的になるにつれて、プロダクトチームは時間とともに上昇傾向を見たいと考えるだろう。

## データソースと注意点

DAU、WAU、MAUはすべて同じ基礎的なイベントログから計算され、すべてのウィンドウにわたって「該当するアクティブ」イベントの一貫した定義を1つ使用する。分子と分母の計算の間でその定義を変更すること(例えば、DAUにはアプリの起動をカウントするが、MAUには完了したアクションのみをカウントすること)は、実際のエンゲージメント強度を反映しない歪んだ比率を生み出す。粘着性の適切なベンチマークは、製品の意図された使用パターンに大きく依存する。週に一度使用することを意図したツール(週次症状チェックイン)は、毎日使用することを意図したツール(持続血糖モニターのコンパニオンアプリ)よりも低いDAU/MAU比率を示す、またそうあるべきであり、粘着性は常に単一の普遍的な目標ではなく、製品自身の意図された使用頻度に照らして解釈されるべきである。

## 落とし穴

- **意図された使用頻度が異なる製品間で粘着率を比較すること**: 週次使用型のツールは、それぞれの使用ケースに対してまったく意図通りに機能していても、日次使用型のツールよりも構造的に低いDAU/MAU比率を示す。製品自身の意図されたリズムに照らしてベンチマークすること。
- **分子と分母で一貫性のないアクティビティ定義を使用すること**: これは真のエンゲージメント強度を反映せず、時間をかけてまたは他の製品と有意義に比較できない粘着率を生み出す可能性がある。
- **全体的なMAUトレンドを確認せずに上昇する粘着率を無条件に肯定的と扱うこと**: 全体的なMAUが減少する中で、縮小しているがより習慣的なコアユーザーベースによって牽引される上昇率は、安定または成長しているユーザーベース全体での真に増加する日次エンゲージメントによって牽引されるものとは、非常に異なり、より懸念される状況である。
- **DAUに対する曜日・季節効果を無視すること**: 多くの健康製品でDAUは曜日(平日対週末)や季節によって大きく変動する可能性がある。歪められる可能性のある短いウィンドウではなく、完全な自然サイクルを捉える期間にわたってDAUを平均すること。
