# バイオメトリック改善率

バイオメトリック改善率とは、デジタルヘルスプログラムに登録した患者のうち、追跡対象となっているバイオメトリック指標——最も一般的には糖尿病や心代謝プログラムにおけるヘモグロビンA1c(HbA1c)、または体重管理プログラムにおける体格指数(BMI)——において、定められた登録期間中に臨床的に意味のある改善を達成した患者の割合を指す。これはデジタルヘルス製品の臨床的な主張を最終的に正当化する成果指標である。エンゲージメントや採用率の数値は製品がどのように使われているかを示すが、バイオメトリック改善はそれが実際に効果があることに近い証拠となる。

## なぜ重要か

デジタルヘルスプログラムは「健康状態の改善」という約束のもとで販売・委託されることが多く、バイオメトリック改善率は、曖昧な「健康改善」という主張ではなく、特定の臨床的に認められた閾値に照らしてその約束を検証する最も直接的かつ定量化可能な方法である。支払者、雇用主、医療システムは、実証されたバイオメトリックの変化に払い戻しや契約更新をますます結びつけるようになっており、この率を信頼性高く報告できないプログラムは、臨床的にも商業的にも不利な立場に置かれる。この指標はまた、プログラム設計に対する規律チェックとしても機能する。エンゲージメント(ログイン、送信されたメッセージ)を報告する方が成果を報告するよりもはるかに容易であり、前者を熱心に報告しながら後者について曖昧なプログラムには疑いの目を向けるべきである。

## 算出方法

```
バイオメトリック改善率 = 定義された臨床的に意味のある改善を達成した
                        患者数 / 有効なベースラインと追跡測定値を
                        持つ患者数 × 100

一般的な臨床的に意味のある閾値:
  HbA1c  — 0.5パーセンテージポイント以上の低下、または範囲外の
           ベースラインから定められた目標値(例:7.0%未満)への到達
  BMI    — ベースライン体重の5%以上の減少で、追跡測定時点まで
           維持されたもの

追跡対象の各バイオメトリックごとに別々に報告すること。HbA1cと
BMIの改善を単一の統合「改善」パーセンテージに混ぜてはならない。
```

## 計算例

ある心代謝デジタルヘルスプログラムが、範囲外のベースラインHbA1cを持つ800人の患者を登録した。このうち620人が、6か月時点で有効なベースラインと追跡測定値の両方を持っている(180人は追跡不能となり分母から除外され、失敗としてはカウントされない)。ペア測定値を持つ620人のうち、340人が少なくとも0.5パーセンテージポイントの低下を達成した。バイオメトリック改善率は340 / 620 × 100 = 55%である。これを登録者全体800人に対して報告すると(340 / 800 = 42.5%)、追跡不能を治療失敗と混同することになり、実際に測定を完了した患者の率を過小評価することになる。

## データソースと注意点

ベースラインと追跡時のバイオメトリック値は通常、接続デバイス(Bluetooth血糖計やスマート体重計)、電子健康記録からインポートされた検査結果、または患者が自己報告した値のいずれかから得られる——これら3つの情報源は信頼性が大きく異なるため、情報源は率とともに報告されるべきである。追跡不能はめったにランダムではない。プログラムから離脱した患者は、改善していない可能性が最も高い患者であることが多いため、追跡を完了した患者のみで算出された高い改善率は、プログラムの真の集団レベルの効果を過大評価する可能性がある。季節性や平均回帰の効果はHbA1cと体重の両方で実在するため、プログラムは可能であれば並行または過去の対照群と比較すべきであり、いかなる改善もプログラムの効果の証明として扱うべきではない。

## 落とし穴

- **追跡不能を報告せず除外すること**: 追跡測定値がない患者を黙って分母から除外すると、見かけ上の改善率が大幅に膨らむ可能性がある。常に改善率とともに追跡測定の完了率を報告すること。
- **自己報告とデバイス由来の測定値をラベル付けせずに混ぜること**: 自己報告された体重は、接続されたスマート体重計の読み取り値よりも体系的に信頼性が低く、両者を混ぜることは見かけ上の改善のどれだけが測定ノイズであるかを不明瞭にする。
- **対照群や反事実がないこと**: 多くの慢性バイオメトリック指標は独自に変動したり平均へ回帰したりする。比較群のない単一アームの改善率は、プログラム効果の示唆的な証拠であって決定的な証拠ではない。
- **控えめな平均変化を広範な改善の証拠として扱うこと**: 小さな集団レベルの平均改善は、少数の大きな反応者によって牽引されている可能性があり、大多数の患者には変化が見られないことがある。平均変化だけでなく分布(例:臨床的に意味のある閾値を超えた割合)を報告すること。
