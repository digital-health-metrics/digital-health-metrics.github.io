# 医師バーンアウト率

医師バーンアウト率は、重大なバーンアウト症状を報告する臨床医の割合を測定するものであり、一般的には検証済みの調査道具を通じて、情緒的消耗、脱人格化、または個人的達成感の低下として評価される。デジタルヘルスに特有に、これは書類作業や電子健康記録(EHR)の文書作成に費やされる時間といった、臨床医が直面するデジタルツールの負担の測定値とともに追跡される。これは、設計の悪い臨床ソフトウェアがバーンアウトのよく文書化された測定可能な寄与要因であり、デジタルヘルスツールの成功は、それを操作しなければならない臨床医への影響を無視して、患者向けの指標だけで評価されるべきではないため、デジタルヘルス指標のフレームワークの中に存在する。

## なぜ重要か

デジタルヘルスツールは、臨床医の管理業務負担を軽減するという明確な目標を持って導入されることが多いが、設計の悪い電子健康記録ワークフロー、過剰な量の低価値な臨床アラート(臨床アラート却下率を参照)、または使いにくいテレヘルスインターフェースは、バーンアウトを軽減するのと同じくらい容易に増加させる可能性がある——そして、患者向けのエンゲージメント指標を改善しながら静かに臨床医の文書作成負担を増加させるツールは、ケアシステム全体にとって正味の肯定的な成果をもたらしていない。バーンアウトは臨床文献において医療過誤、臨床医の離職、ケアの質の低下と強く結びついているため、単なる職場満足度の問題ではなく、下流の安全性と労働力の持続可能性の問題の先行指標として機能する。臨床的負担を軽減すると主張するデジタルヘルスプログラムは、設計上の意図として主張するのではなく、測定されたベースラインに対してこの主張を示せるべきである。

## 算出方法

```
医師バーンアウト率 = 検証済み道具のバーンアウト閾値を超える
                    スコアを示す臨床医数 / 調査された臨床医
                    総数 × 100

一般的な検証済み道具: Maslach Burnout Inventory (MBI)、
Professional Fulfillment Index、またはより完全な道具に対して
検証された単一項目のバーンアウトスクリーニング質問。

利用可能な場合はデジタル負担の代理指標とともに報告すること:
  患者診察あたりのEHRシステム利用時間
  予定された臨床時間外に発生する文書作成時間
  (「パジャマタイム」)
```

## 計算例

ある病院システムが、ノート作成時間を削減することを意図した環境音声臨床文書作成ツールを導入する前に、Maslach Burnout Inventoryを使用して300人の医師を調査する。ベースラインでは、135人の医師(45%)がバーンアウト閾値を超えるスコアを示し、EHR監査ログデータは、医師1人あたり1日平均58分の文書作成時間が予定された臨床時間外に発生していることを示している。ツール導入から6か月後、同じ医師を対象とした再調査では、108人(36%)がバーンアウト閾値を超えており、時間外文書作成時間は1日34分に低下している。バーンアウト率と客観的なEHR由来の代理指標の両方における相関した動きは、ツールが改善に寄与しているという主張を強化するが、正式な前後比較は、同じ期間における他の同時並行的な業務量の変化を依然として考慮すべきである。

## データソースと注意点

バーンアウト調査データは、定期的に(年1回またはより頻繁に)実施される検証済み道具から得られ、回答率が重要である。低い回答率は非応答バイアスのリスクをもたらす。最もバーンアウトしている臨床医(追加の調査を完了する余力が最も少ない)が体系的に過小評価されやすく、真の率を過小評価することになる。デジタル負担のEHR由来の代理指標——システム利用時間、時間外文書作成時間、診察あたりのクリック数——は、定期的な調査データの客観的で継続的に利用可能な補完物として有用であるが、信頼できる単独のバーンアウト指標として扱われる前に、特定の組織について調査報告されたバーンアウトに対して検証されるべきである。システム利用時間と実際のバーンアウトの関係は、専門分野や個人の働き方によって異なる可能性があるためである。

## 落とし穴

- **EHR由来の代理指標のみに頼ること**: システム利用時間とクリック数は集計レベルではバーンアウトと相関するが、バーンアウトそのものと同じではなく、真に異なる文書作成ニーズを持つ個々の臨床医や専門分野にとって誤解を招く可能性がある。
- **低い調査回答率が真の率を覆い隠すこと**: バーンアウトの影響を最も受けている臨床医は、任意の調査に回答する余力が最も少ないことが多く、低回答率の結果を人為的に健全に見える数値に偏らせる。
- **交絡因子を考慮せずにバーンアウトの変化を単一のツールに帰属させること**: バーンアウトは多くの同時並行的な要因(人員配置レベル、患者数、組織変化)の影響を受ける。1つのツール導入をめぐる前後比較は、単一の原因を仮定するのではなく、可能な限りこれらを制御すべきである。
- **バーンアウトを純粋に個人のレジリエンスの問題として扱うこと**: バーンアウト研究は一貫して、業務量、システム設計、組織的要因が主要な推進要因であることを見出している。これを純粋に個々の臨床医の問題として捉えることは、しばしば実際の根本原因であるデジタルツールやワークフローから介入を逸らしてしまう。
