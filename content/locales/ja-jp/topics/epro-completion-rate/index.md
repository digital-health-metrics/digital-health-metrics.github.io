# ePROM完了率

ePROM完了率とは、予定された電子患者報告アウトカム指標(ePROM)——患者自身の症状、機能、または生活の質についての説明を、紙ではなくデジタルで取得する、標準化された検証済みの質問票——のうち、実際に完了したものの割合を測定する。これはエンゲージメント指標であると同時にデータ品質指標でもある。PROMプログラムの臨床的・研究的価値は、収集された回答が、最も積極的または最も症状の少ない部分集合だけでなく、登録された集団全体を代表するのに十分な高さの完了率を持つことに完全に依存している。

## なぜ重要か

患者報告アウトカムは、臨床医が記録したデータやデバイスで測定したデータに対する直接的で患者が保証する補完物であり、カルテレビューやバイオメトリック測定では捉えられない健康の側面——痛み、機能、生活の質——を捉える。PROM収集のデジタル化は、紙ベースの実施がこれまで可能にしてきたよりも安価かつ容易にこのデータを大規模に収集するために特に存在する。しかし完了率の低いPROMプログラムは、特定の深刻なバイアスのリスクを抱えている。気分が悪い患者は長い質問票を完了する可能性が低いことが多く、完了率の低下自体が集団の健康状態悪化の早期警告サインとなりうる。また、全体的な完了率が低いと、最も症状の重い患者が完了するものの中で過小評価されるため、収集された回答が実際の集団の経験よりも良く見える可能性がある。これが、完了率を二次的な運用上の詳細としてではなく、常にPROMスコア自体とともに報告すべき理由である。

## 算出方法

```
ePROM完了率 = 完全に完了したePROM数 / 送信または予定された
             ePROM数 × 100

以下について別々に報告する:
  初回完了率       (モニタリングシーケンスの最初の質問票)
  縦断的完了率     (進行中のモニタリングシーケンスの後続の
                   質問票。通常時間とともに低下するため、単一
                   の数値ではなく傾向として追跡すべき)

「部分的に完了した」質問票は、「完全に完了した」および
「未開始」の両方から区別して定義し報告すべきである。
```

## 計算例

ある腫瘍クリニックが、毎月のフォローアップ訪問の前に、検証済みの症状負担ePROMを400人の患者に送信している。最初の月には、340人の患者が質問票を完全に完了し(完了率85%)、30人が部分的に完了し、30人が開始しなかった。同じモニタリングシーケンスの6か月目までに、完全な回答は同じ400人の患者コホートのうち260人(65%)に減少しており、これは最初の月の85%という数値のみが静的な全体指標として報告された場合には完全に見逃されるであろう、意味のある縦断的な低下である。どの患者が脱落しているか(症状の重症度、疾患段階、または年齢別)を調査することで、その低下がアンケート疲労を反映しているのか、症状の悪化によって質問票の完了が難しくなっているのか、あるいは技術的なアクセス障壁を反映しているのかを明らかにすることができる。

## データソースと注意点

完了データは通常、ePROMプラットフォーム自体の配信・応答ログから得られ、「未開始」「部分完了」「完全完了」の状態を区別できる——この区別は常に保持し報告すべきであり、二値の完了/未完了の数値に崩すべきではない。部分完了はしばしば、患者が質問票のどの特定の時点で苦労しているか、あるいは離脱しているかを示すためである。完了率は、質問票がどのように配信されるか(テキストメッセージのリンク、アプリ通知、またはポータルログインを必要とする配信方法)とともに解釈されるべきである。配信の摩擦自体が、質問票の内容や患者の基礎疾患とは無関係に完了に影響を与えるためである。PROM自体には常に検証済みの道具(アドホックな質問セットではなく)を使用すべきである。未検証の道具の完了率は、完了率が高くても得られたデータの臨床的有用性について何も信頼できることを語らないためである。

## 落とし穴

- **低下する完了率を単に配信の問題として扱うこと**: 縦断的な完了率の低下は、アンケート疲労や技術的な問題ではなく、実際に悪化している患者の症状(調査を完了するには体調が悪すぎる患者)を反映している可能性があり、この区別は臨床的解釈にとって非常に重要である。
- **部分完了と完全完了を1つのカテゴリーにまとめること**: 部分的に完了した質問票は、完全に完了したものとは意味のあるデータ品質の違いがある。別々に報告し、患者が質問票の流れのどこで放棄する傾向があるかを調査すること。
- **応答バイアスのリスクを報告せずに完了率を報告すること**: 中程度の完了率は、応答者が非応答者と(症状の重症度、年齢、デジタルリテラシーにおいて)体系的に異なるかどうかの調査を促すべきである。応答者のみから計算されたPROMスコアは、集団全体を誤って表す可能性がある。
- **未検証または自作の質問票を使用すること**: 完了している道具自体が測定対象の疾患と集団について臨床的に検証されていない場合、完了率はデータ品質の信号として無意味である。
