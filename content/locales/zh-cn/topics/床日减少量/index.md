# 床日减少量

床日减少量衡量的是通过将特定护理事件——最常见的是术后恢复或急性病情管理——从传统住院转移至虚拟病房或居家医院等数字支持替代方案，所避免的住院床日总数。这是虚拟病房和居家医院项目的核心容量指标，将临床护理模式的改变直接转化为医院运营和系统规划者实际管理的货币（床位容量）。

## 为何重要

住院床位容量是任何医院系统中最受限、最昂贵的资源之一，虚拟病房或居家医院项目的核心价值主张在于：它能够在不占用实体床位的情况下安全地提供特定水平的临床护理，从而释放该容量以服务无法以其他方式得到管理的患者。床日减少量将一个通常抽象的主张（"这个项目改善了护理"）转化为医院容量规划者、财务团队和委托方可以直接采取行动的具体运营数字：它可用于建模对监测项目的投资是否能在避免的床位成本中收回，以及回收多少。由于床日减少量只有在维持患者安全的前提下才有价值，因此应始终与安全结果指标（如再入院率或转为住院护理的比率）一并报告，而绝不应单独报告。

## 计算方法

```
床日减少量 = 标准住院护理下的预期床日数（基于配对患者
              队列的历史住院时长数据）− 虚拟/数字路径
              患者实际使用的床日数

应按临床路径分别报告（例如术后恢复、急性呼吸系统病情加
重），因为预期住院时长因病情而异极大，跨越不相关路径
的混合数字没有意义。
```

## 实例解析

某医院的历史数据显示，接受特定择期手术的患者平均住院时长为4天。一个虚拟病房项目招募了150名接受同一手术的患者，平均在1.5个住院日后出院，其余恢复期通过远程监测进行。床日减少量为(4 − 1.5) × 150 = 375床日，涵盖测量期。该数字应与同一150名患者的30天转为住院护理率和再入院率一并报告，因为以显著更高的转院率或再入院率为代价换取的床日节省，并非头条数字所暗示的临床胜利。

## 数据来源与注意事项

预期床日数需要一个可信的历史基线，理想情况下来自在临床特征（年龄、合并症、手术类型、严重程度）上与虚拟病房人群相匹配的、接受标准住院护理的患者队列，因为与未匹配的历史平均值进行比较，若数字管理队列在系统性上更健康或更严重，就有夸大或低估真实减少量的风险。数字路径上实际使用的床日数来自医院自身的入院-出院-转院（ADT）系统；在监测恢复期间任何转回住院护理的情况，都应诚实地计入该项目（作为已使用的床日，而非被排除），因为将转院情况排除在计算之外会人为地虚增表观减少量。

## 常见误区

- **报告床日减少量却没有匹配的安全性比较**：一个节省了床日但转院率或再入院率明显更差的虚拟病房，并未真正展示出改善；应始终将两者一并报告。
- **使用未匹配或过时的历史基线**：与病例组合、合并症负担或临床实践时代不同的历史队列进行比较，可能会显著夸大或低估真实的床日节省量。
- **将转回住院护理的情况排除在计算之外**：接受虚拟监测但在恢复过程中转为住院床位的患者，其床日应计入该项目，而不应被悄悄从分析中剔除。
- **合并预期住院时长差异很大的路径**：将床日减少量跨临床不相关的路径汇总（例如将术后恢复与慢性呼吸道管理合并）成一个数字，会掩盖究竟是哪条特定路径带来了节省。
