# 电子患者报告结局完成率

电子患者报告结局完成率是指已安排的电子患者报告结局（ePROM）——标准化、经验证的问卷，用以采集患者本人对其症状、功能或生活质量的陈述，以数字方式而非纸质方式传递——实际完成的比例。这既是一项数据质量指标，也是一项参与度指标：PROM项目的临床与研究价值完全取决于完成率是否足够高，以使所收集的答复能够代表整个登记人群，而不仅仅是参与度最高或症状最轻的那部分子群体。

## 为何重要

患者报告结局是对临床医生记录或设备测量数据的直接、患者亲证的补充，它捕捉了病历审查或生物指标读数无法捕捉的健康维度——疼痛、功能、生活质量；将PROM采集数字化正是为了让大规模采集比纸质方式更便宜、更容易。但完成率较低的PROM项目存在一种特定且严重的偏倚：感觉更差的患者往往更不愿意完成冗长的问卷，因此下降的完成率本身可能是人群健康状况恶化的早期预警信号，而总体较低的完成率可能使所收集的答复显得比真实人群体验更好，因为症状最重的患者在已完成的问卷中代表性不足。这正是为何完成率应始终与PROM分数本身一并报告，而不应被视为次要的运营细节。

## 计算方法

```
电子患者报告结局完成率 = 完整完成的ePROM数 / 发送或安排的
                          ePROM数 × 100

分别报告：
  初始完成率     （监测序列中的第一份问卷）
  纵向完成率     （持续监测序列中的后续问卷，通常会随时间
                  推移而下降，应作为趋势追踪，而非单一数字）

应对"部分完成"的问卷进行定义，并与"完整完成"和"未开始"
分开报告。
```

## 实例解析

一家肿瘤诊所在每月随访前向400名患者发送一份经验证的症状负担ePROM。第一个月，340名患者完整完成了问卷（完成率85%），30人部分完成，30人未开始。到该监测序列的第六个月，同一批400名患者中完整答复已降至260份（65%），这一具有意义的纵向下降，如果仅报告第一个月85%的静态整体指标，将完全被忽略。调查哪些患者流失（按症状严重程度、疾病分期或年龄划分）可以揭示这一下降是反映调查疲劳、症状恶化使问卷更难完成，还是技术性获取障碍。

## 数据来源与注意事项

完成数据通常来自ePROM平台自身的发送与答复记录，能够区分"未开始"、"部分完成"和"完整完成"状态——这一区分应始终保留并报告，而不应压缩为完成/未完成的二元数字，因为部分完成往往指出问卷中患者遇到困难或退出的具体环节。解读完成率时应结合问卷的传递方式（短信链接、应用通知，或需要登录门户的传递方式），因为传递摩擦本身会影响完成率，与问卷内容或患者基础病情无关。对于PROM本身，应始终使用经过验证的工具（而非临时拼凑的问题集），因为未经验证工具的完成率，即使很高，也无法可靠说明所得数据的临床实用性。

## 常见误区

- **仅将完成率下降视为传递问题**：纵向完成率下降可能反映患者症状真正恶化（患者病重到无法完成调查），而非调查疲劳或技术问题，这一区分对临床解读至关重要。
- **将部分完成与完整完成合并为一类**：部分完成的问卷在数据质量上与完整完成的问卷存在明显差异；应分别报告，并调查患者在问卷流程中往往在哪个环节放弃。
- **报告完成率却不报告应答偏倚风险**：中等完成率应促使调查应答者是否（在症状严重程度、年龄、数字素养方面）与未应答者存在系统性差异，因为仅从应答者计算的PROM分数可能无法代表整个人群。
- **使用未经验证或自行设计的问卷**：如果所完成的工具未针对所测量的疾病和人群进行临床验证，即使完成率很高，完成率作为数据质量信号也是没有意义的。
