# RE-AIM框架

RE-AIM是一个公共卫生评估框架，从五个不同维度——覆盖度（Reach）、有效性（Effectiveness）、采纳度（Adoption）、实施度（Implementation）和维持度（Maintenance）——评估数字健康干预，而非通过任何单一指标。它的存在是为了纠正数字健康评估中一种特定且常见的失败模式：一个从一个规模小、积极性高的试点人群中报告出令人印象深刻的有效性数据，却从未在规模上被采纳，或从未在其资助期结束后得以维持的项目，无论其头条结果数字单独看起来多好，都并未真正展示出真实的公共卫生价值。

## 为何重要

数字健康试点项目经常仅在有效性上——结果指标是否为使用者带来了改善——接受评估，而其他四个维度却未被测量或报告，这系统性地使证据基础偏向那些在理想、小规模条件下表现良好、但对于其是否能在规模上运作、能否触及最需要它的人群、或能否在初始资助和热情消退后存续下来完全没有说明力的干预措施。RE-AIM的开发正是为了迫使评估者在报告内部效度（这在这里有效吗）的同时，也报告外部效度（这在其他地方、对谁有效），这对于任何要基于单一研究或试点结果来决定是否资助、委托或推广某数字健康干预的人而言，都至关重要。由于五个维度中的每一个都可以在个人和机构或场所两个层面上进行测量，RE-AIM还揭示了单一综合指标会完全掩盖的权衡——例如，一项由高度筛选、高度训练的人员提供的高效有效干预（有效性强，但采纳代表性弱）。

## 如何应用

```
覆盖度   = 参与的符合条件目标人群比例，以及参与者相对于
           该符合条件人群的代表性程度（而非仅仅是原始参
           与人数）

有效性   = 对主要结果的影响，包括生活质量和意外的负面后果，
           而非仅仅是单一的头条结果指标

采纳度   = 采纳该干预措施的场所与工作人员/传递代理人的
           比例及代表性，相对于所有符合条件的场所与人员

实施度   = 按预期传递的一致性与忠实度，传递所需的时间与
           成本，以及在此过程中所做的调整

维持度   = 该干预措施在个人层面（持续的个人效果）和场所/
           机构层面（制度化）成为常规实践一部分的程度
```

## 实例解析

一项数字糖尿病预防项目在一个拥有200家符合条件诊所的地区，于20家初级护理诊所进行试点。评估覆盖度发现，在这20家试点诊所估计的15000名符合条件患者中，有1200人参与（8%），且参与者被发现比整个符合条件人群略年轻、数字素养也略高——这是一个值得关注、而非忽视的代表性差距。有效性评估显示，完成者的平均HbA1c出现了具有临床意义的下降，但较高的流失率意味着，当以意向治疗为基础对所有登记患者进行评估时，这一效果被稀释了，而不仅仅是针对完成者。采纳度为200家符合条件诊所中的20家（10%），集中在现有数字基础设施高于平均水平的诊所——这是另一个代表性方面的担忧。实施忠实度评估发现，大多数诊所基本按设计传递了该项目，尽管有两家诊所在时间压力下大幅缩短了入职流程。在试点资助结束一年后进行的维持度评估发现，最初20家诊所中只有6家仍在积极运行该项目——这一结果，若与最初令人鼓舞的有效性数字一并报告，会比单独的有效性数据提供更完整、更诚实的项目实际前景图景。

## 数据来源与注意事项

RE-AIM的每个维度通常依赖不同的数据来源：覆盖度和采纳度来自登记与资格记录，有效性来自临床或结果数据（通常是本书其他地方已用于计算某项特定指标的同一数据，例如生物指标改善率），实施度来自忠实度核查表、传递记录或直接观察，而维持度则来自在初始评估期之后经过充分时间进行的随访评估——这意味着无法在单一时间点完成完整的RE-AIM评估，需要从一开始就规划评估，而非事后追加。由于诚实地报告全部五个维度（包括某些维度上的不佳结果）比仅报告有效性需要更多工作、也不那么讨喜，已发表的数字健康评估相较于有效性，系统性地对覆盖度、采纳度和维持度报告不足——这是一种已知的发表偏倚模式，任何使用带有RE-AIM标签的证据来指导决策的人都应留意。

## 常见误区

- **仅报告有效性却称之为RE-AIM评估**：使用RE-AIM之名却仅报告其五个维度之一，违背了该框架的初衷，不应将其描述为RE-AIM评估。
- **将覆盖度和采纳度衡量为原始计数而非符合条件人群的比例**：较大的原始参与人数仍可能代表干预措施理想上应触及人群中的一小部分、不具代表性的比例；应始终对照完整的符合条件分母进行计算。
- **过早评估维持度**：只有在初始资助或新奇效应消退很久之后，才能很好地判断制度化和持续效果；无论其他四个维度表现如何，紧接试点结束后进行的评估都无法说明维持度。
- **将五个维度视为权重相等或可合并为单一分数**：RE-AIM在设计上是一个多维度概况，而非单一数字；将各维度合并为一个综合分数，恰恰抛弃了该框架旨在保留的权衡可见性。
