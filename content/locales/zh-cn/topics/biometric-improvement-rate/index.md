# 生物指标改善率

生物指标改善率是指在数字健康项目中登记的患者中，在所追踪的生物指标上取得具有临床意义改善的比例——最常见的是糖尿病和心脏代谢项目中的糖化血红蛋白（HbA1c），或体重管理项目中的体重指数（BMI）——在特定登记期限内。这是最终验证数字健康产品临床价值主张的结果性指标：参与度和采纳率数字描述的是产品如何被使用，而生物指标改善则更接近于产品确实有效的证据。

## 为何重要

数字健康项目经常以改善健康结果的承诺来销售和委托运营，而生物指标改善率是最直接、最可量化的方式，用以将该承诺与具体的、公认的临床阈值进行对照检验，而非停留在含糊的"健康改善"说法上。支付方、雇主和医疗系统日益将报销或合同续签与已证明的生物指标变化挂钩，因此无法可信地报告这一比率的项目，在商业上和临床上都处于不利地位。这一指标也是对项目设计的纪律性检验：报告参与度（登录次数、发送的消息）远比报告结果容易得多，团队应对任何热情报告前者却对后者含糊其辞的项目保持警惕。

## 计算方法

```
生物指标改善率 = 达到特定临床意义改善的患者数 / 具有有效
                  基线和随访测量值的患者数 × 100

常见的具有临床意义的阈值：
  HbA1c   —— 下降 ≥ 0.5 个百分点，或从超出范围的基线值
            达到特定目标（例如 < 7.0%）
  BMI     —— 相对基线体重下降 ≥ 5%，并持续到随访测量点

应针对每个追踪的生物指标分别报告；切勿将 HbA1c 和 BMI 的改善
合并为单一的"改善"百分比。
```

## 实例解析

一个心脏代谢数字健康项目招募了800名基线HbA1c超出正常范围的患者。其中，620人在6个月时同时拥有有效的基线和随访测量值（180人失访，被排除在分母之外，而非被计为失败）。在这620名拥有配对测量值的患者中，有340人实现了至少0.5个百分点的下降。生物指标改善率为340 / 620 × 100 = 55%。若将其与全部800名登记患者相比较（340 / 800 = 42.5%），则会将失访与治疗失败混为一谈，从而低估了实际完成测量的患者的改善率。

## 数据来源与注意事项

基线和随访生物指标值通常来自联网设备（蓝牙血糖仪或智能体重秤）、从电子健康档案导入的实验室结果，或患者自报数值——这三种来源的可靠性差异很大，因此应在报告比率的同时注明数据来源。失访很少是随机的：脱离项目的患者往往也是最不可能改善的患者，因此仅根据完成随访的患者计算的高改善率可能高估项目在整体人群层面的真实效果。季节性效应和均值回归效应对HbA1c和体重而言都是真实存在的，因此项目应尽可能与同期或历史对照组进行比较，而不是将任何改善都视为项目效果的证明。

## 常见误区

- **排除而非报告失访情况**：悄悄将无随访测量值的患者从分母中剔除，可能大幅虚增表观改善率；应始终将随访完成率与改善率一并报告。
- **混合自报和设备来源的测量值而不加标注**：自报体重的可靠性系统性地低于联网智能体重秤的读数，混合两种来源会掩盖表观改善中有多少其实是测量噪音。
- **没有对照组或反事实比较**：许多慢性生物指标本身就会波动或向均值回归；没有任何对照组的单臂改善率只能是提示性的，而非项目效果的确证性证据。
- **将适度的平均变化视为广泛改善的证据**：人群层面较小的平均改善可能是由少数反应强烈者驱动的，而大多数患者并无变化；应报告分布情况（例如跨越具有临床意义阈值的比例），而非仅报告平均变化。
