# 用户留存率

用户留存率是指在初始期间活跃的用户中，在后续期间仍保持活跃的比例，而其反面——流失率——则是完全停止使用产品的用户比例。患者门户采纳率（参见该主题）衡量的是患者是否曾有意义地激活数字健康产品，而留存率衡量的是他们是否持续使用它——对于任何订阅式或持续护理型的数字健康产品而言，留存率通常是与临床影响和商业可持续性联系最紧密的单一指标。

## 为何重要

无论初始采纳或激活数字有多强，无法留住用户的数字健康产品就无法带来持续的临床获益：一款使用两周便被放弃的慢性病管理工具，不太可能改变一个依赖数月持续行为改变的生物指标结果。留存率也是数字健康公司向投资者和支付方报告的最具商业意义的指标之一，因为留存曲线（随时间推移的下降形态，而非单一的留存百分比）揭示了该产品是否找到了真正可持续的使用模式，还是仅仅捕捉了会可预测地消退的新奇驱动型初始兴趣。在初期下降后趋于平稳的留存曲线（熬过第一个月的患者往往会留下来）是一个截然不同、也健康得多的信号，与持续稳步下降、没有底线的曲线相比。

## 计算方法

```
留存率（第N期）= 在第N期仍活跃、且在起始队列期间也活跃的
                  用户数 / 起始队列期间的用户数 × 100

流失率 = 1 − 留存率（同一期间）

应以队列留存曲线的形式报告（第1、2、3……天/周/月的留存），
而非单一时间点的数字，因为单一快照会将刚加入的用户（尚未
有机会流失）与长期留存的用户混为一谈。
```

## 实例解析

一款数字健康应用在1月登记了1000名新用户的队列。到第1个月末，原始1000人中仍有640人保持活跃（第1个月留存率64%）。到第3个月末，仍有410人保持活跃（第3个月留存率41%）。到第6个月，仍有380人保持活跃（第6个月留存率38%）。这条曲线的形态——初期急剧下降，随后在第3至第6个月间趋于平稳——表明该产品在用户跨过初始采纳门槛后能够留住稳定的核心用户群，这与第3至第6个月的下降若以同样速度持续下去相比，是一个截然不同、也更为令人鼓舞的信号。

## 数据来源与注意事项

留存率根据产品自身的登录或活动事件日志计算，在所比较的每个队列中一致地定义"活跃"（例如，在该期间内至少一次合格会话）。应在同等基础上比较队列——相同的"活跃"起始定义、相同长度的观察窗口——因为即使是微小的定义差异（30天与28天的月份、更严格与更宽松的"活跃"阈值）也可能使报告的留存百分比产生数个百分点的偏移，而实际用户行为并无任何真实差异。与新年决心或特定健康意识周期相关的季节性效应在健康类应用中很常见，因此同比队列比较通常比比较来自不同时间段的相邻队列更具参考价值。

## 常见误区

- **报告单一留存快照而非曲线**：没有随时间推移的下降形态，仅一个"X%的用户仍然活跃"的数字，无法区分趋于平稳的产品（健康）与持续下降的产品（不健康）。
- **在报告期间改变"活跃"的定义**：放宽活跃用户的定义（例如将被动应用打开计入而非已完成的操作）可能使留存率看似改善，而实际使用行为完全没有变化。
- **忽视队列季节性**：将1月队列的留存率（往往因新年决心而带来平均积极性较低的队列而被虚增）与不同时间获取的队列相比较，可能得出误导性的趋势结论。
- **混合自然获取与付费获取的队列**：通过不同渠道获取的用户留存表现往往差异很大；将其混合为一个综合留存数字，可能掩盖特定渠道的留存问题。
