# 药物依从率

药物依从率衡量的是患者按医嘱服用处方药物的程度，最常表示为在特定时期内患者按处方获得药物的天数占比。这是最具影响力的数字健康指标之一，因为不依从现象普遍存在，且在恰当支持下很大程度上可以预防，并与更差的临床结果和更高的下游成本直接相关——而这正是用药提醒应用、智能药盒和药房续方提醒工具旨在弥合的差距。

## 为何重要

公共卫生机构估计，某些疾病的慢性病用药不依从率高达50%，这是导致可避免住院、疾病进展和治疗失败的主要可预防原因，而这些后果常被错误地归咎于药物本身，而非用药的不一致性。数字依从性工具正是为弥合这一差距而存在，因此对于任何包含用药环节的项目而言，依从率通常是最能指导决策的单一指标：它在因果链上位于生物指标改善、再入院及大多数项目可能报告的其他临床结果指标的上游。一个提升了参与度或满意度却未能改变依从率的项目，很可能尚未展示出临床获益的合理机制。

## 计算方法

```
覆盖天数比例（PDC） = 期间内持有药物的天数（基于配药供应
                      天数）/ 测量期间总天数 × 100

用药占有率（MPR） = 期间内获得的总供应天数 / 期间总天数 × 100
                    （提前续方可能导致超过100%；因此通常更
                    倾向使用PDC）

按照广泛使用的质量测量惯例，PDC阈值≥80%通常将患者归类为
"依从"。
```

## 实例解析

一名患者在90天的测量期间内被处方每日慢性病用药。药房配药记录显示，该患者获得的药物足以覆盖90天中的76天，存在两个缺口：一个是用完药后续方前的9天缺口，另一个是住院期间的5天缺口。PDC为76 / 90 × 100 = 84%，超过了传统的80%依从阈值。如果使用基于配药供应天数（而非实际覆盖天数）的MPR来衡量同样的缺口，期间内其他地方的提前续方可能会将比率推高至100%以上，这说明了为何PDC是更为保守、也更受青睐的衡量方式。

## 数据来源与注意事项

药房理赔或配药数据（来自药品福利管理机构或联网药房系统）是标准数据来源，因为它反映了患者实际获得的药物，而非仅是处方所记录的；仅凭处方数据会高估依从性，因为它无法确认患者是否曾取药。数字依从性工具——智能药盒、可摄入传感器、针对哮喘和慢性阻塞性肺病等呼吸系统疾病记录每次吸入动作的联网智能吸入器，以及基于应用程序的签到——能提供更高分辨率的数据，说明剂量是否确实被服用，而不仅仅是被获得，但使用这些工具的患者只是一小部分、可能不具代表性的群体，因此在人群层面将设备确认的依从性与基于理赔的PDC混合使用时需谨慎解读。依从性应在足够长的时期内测量，以平滑单次漏服的影响，但又要足够短，以便在造成临床伤害前及时发现有意义的下降——对慢性病用药而言，90天的滚动窗口较为常见。

## 常见误区

- **使用MPR而不说明其可能超过100%**：提前续方或囤药导致的无法解释的超过100%比率，会使跨患者和跨期间的比较变得不可靠，除非使用PDC或对比率明确设置上限。
- **将处方或医嘱数据视为依从性的证明**：开出或发送至药房的处方并不能说明患者是否取药或服药；只有配药或设备数据才能弥合这一差距。
- **不加区分地对所有疾病应用同一依从阈值**：漏服20%剂量的临床后果因药物类别（例如抗凝剂与他汀类药物）而异，因此普遍采用单一80%阈值可能会低估或高估某些药物的临床风险。
- **忽视药物更换和停药**：如果计算中未考虑换药情况，一名在临床上被适当更换为另一种药物的患者，在原药物上可能表现为依从率的大幅下降。
