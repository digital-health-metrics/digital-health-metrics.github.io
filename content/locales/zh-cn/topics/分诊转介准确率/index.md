# 分诊转介准确率

分诊转介准确率是指在患者接触中，自动化或AI辅助分诊工具依据经临床验证的参照标准，正确地将患者转介至适当护理级别和场所——例如自我护理、初级护理、紧急护理或急诊护理——的比例。这是任何数字前门、症状自查工具或AI分诊系统的安全性与有效性指标：这类工具的全部价值主张都建立在能否准确、快速且一致地转介患者之上。

## 为何重要

分诊不准确会在两个方向上造成伤害：分诊不足（将患者转介至低于其实际需要的护理级别）可能延误真正急症的治疗，而分诊过度（将患者转介至高于其实际需要的护理级别）则会浪费稀缺的急诊和紧急护理资源，并在没有临床获益的情况下增加成本和患者焦虑。由于这两种失败模式的后果如此不同，分诊转介准确率应始终与错误方向一并报告，而不是作为一个掩盖工具究竟是安全偏差还是危险偏差的单一综合准确率数字。评估AI分诊工具是否可用于部署的监管机构和医疗系统，越来越要求这种分层准确率报告作为临床批准的条件，尤其是对于具有一定自主性、脱离临床医生监督的工具。

## 计算方法

```
分诊转介准确率 = 正确转介的接触数 / 分诊接触总数 × 100

分别报告分诊不足率与分诊过度率：
  分诊不足率 = 转介至低于参照标准急重程度的接触数 /
              分诊接触总数 × 100
  分诊过度率 = 转介至高于参照标准急重程度的接触数 /
              分诊接触总数 × 100

参照标准通常是对同一病例进行的回顾性临床医生审查，
并尽可能对工具的输出结果保持盲态。
```

## 实例解析

一款AI症状自查工具在一个月内对5000次患者接触进行了分诊。对其中500次接触进行随机抽样的盲态临床医生审查发现，430次被转介至正确的急重程度（准确率86%），45次分诊不足（9%），25次分诊过度（5%）。9%的分诊不足率是最需要立即调查的数字，因为它代表了患者可能被转介至比实际所需更低急迫程度护理的接触；5%的分诊过度率则是一个容量与成本问题，而非直接的安全问题。

## 数据来源与注意事项

用以衡量分诊准确率的参照标准至关重要：由单一临床医生进行的审查会引入该医生自身的判断差异，因此可信的准确率数字通常需要多名独立审查者并记录评分者间一致性，或者与后续确认的临床结果（患者实际需要的护理，事后确定）进行比较。抽样方式同样重要：仅审查方便获取的样本，或仅审查被标记为异常的病例，都不会得出能够代表该工具整体表现的数字。在病例量允许的情况下，应按就诊症状或主诉类别分别报告准确率数字，因为分诊工具在所有病种上的表现很少是均一的。

## 常见误区

- **报告单一混合准确率数字**：将分诊不足和分诊过度合并为一个数字，会掩盖工具的错误是偏向更危险的失败模式，还是偏向另一种；应始终分别报告。
- **使用单一、非盲态的审查者作为参照标准**：这可能会悄悄地使准确率数字偏向该审查者自己会做出的判断，而非独立的临床标准。
- **仅根据回顾性、便利性数据进行验证**：工具在实际、模糊患者输入下的真实转介准确率，通常与其在开发过程中收集的经过整理的验证集上的准确率存在实质差异。
- **忽视部署后的性能漂移**：随着患者人群、就诊症状或护理路径可用性的变化，AI分诊模型的准确率可能随时间推移而下降；应定期重新测量准确率，而非验证一次后即假定其保持稳定。
