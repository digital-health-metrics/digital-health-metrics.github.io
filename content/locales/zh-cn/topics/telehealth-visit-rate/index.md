# 远程医疗就诊率

远程医疗就诊率是指一项服务的全部诊疗中，通过视频或电话远程提供而非面对面提供的比例。这是一个反映诊疗渠道构成的指标，而不是活动量指标：它告诉你诊疗是如何提供的——这对容量规划、可及性和临床适宜性都很重要——与总体提供了多少诊疗量是完全独立的两件事。

## 为何重要

新冠疫情期间远程会诊的快速扩张改变了许多服务的运营模式，此后，机构需要一种稳定的方法来监测这一转变是否得以持续、是否正在回落至疫情前的常态，或是否正被政策主动引导。远程医疗并非面对面就诊的统一替代品：其适宜性因专科、会诊类型（药物复查与体格检查的情况截然不同）以及患者偏好而异，因此"合适"的比率是一个临床与运营判断问题，而非一个应当被最大化的目标。资助方和监管机构也会结合结果和安全性指标使用这一比率，来决定报销政策，并核查远程诊疗是否只是被简单地替代到了那些本应面对面就诊的病例上。

## 计算方法

```
远程医疗就诊率 = 远程诊疗次数 / (远程诊疗次数 + 面对面诊疗次数) × 100

在可能的情况下按方式分别报告：
  视频比率   = 视频诊疗次数 / 总诊疗次数 × 100
  纯电话比率 = 仅电话诊疗次数 / 总诊疗次数 × 100

分母应仅计入已完成的诊疗（见常见误区），并针对特定服务、专科和时间段统计。
```

## 实例解析

某社区精神卫生服务在一个季度内记录了 4,000 次已完成的门诊接触：1,200 次面对面，1,600 次视频，1,200 次电话。远程医疗就诊率为 (1,600 + 1,200) / 4,000 × 100 = 70%，其中视频比率为 40%，纯电话比率为 30%。如果只报告合并后的 70%，会掩盖其中很大一部分"远程医疗"实际上是纯音频，而这通常具有与视频不同的临床风险特征和患者体验。

## 数据来源与注意事项

诊疗类型通常记录为电子健康记录中的结构化字段（就诊类型或地点），或通过账单代码推断，例如服务地点代码或理赔单上的远程医疗修饰符。不同机构之间、甚至同一机构不同临床医生之间的编码习惯差异很大，因此在跨机构比较比率之前，应先确认各机构对"远程医疗"的编码方式是否一致。因技术问题从视频降级为电话的就诊应有一致的编码规则（通常按承载了大部分临床内容的方式编码），且该规则应形成文档，而非留给个人判断。

## 常见误区

- **计入尝试而非已完成的就诊**：连接失败并重新预约的远程医疗预约，不应使远程医疗分母被重复计入。
- **将视频和电话视为可互换**：两者在临床和公平性方面的影响不同（电话无法进行视觉评估，但对没有智能手机、可靠网络或私密视频空间的患者更具可及性）；应尽可能分别报告。
- **忽视与爽约率的关系**：爽约行为常因就诊方式而异；在仅凭远程医疗比率上升就得出"可及性提高"的结论之前，请参阅[预约爽约率](../appointment-no-show-rate/)。
- **认为高比率本身就是好事**：对某些病种和会诊类型而言，合适的远程医疗比率因临床设计而本就偏低，这并非数字化成熟度不足的表现。
