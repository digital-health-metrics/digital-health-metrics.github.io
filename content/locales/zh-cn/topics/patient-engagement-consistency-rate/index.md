# 患者参与一致性率

患者参与一致性率衡量的是登记患者随时间与数字健康产品互动的规律程度——例如记录饮食或症状、记录体育活动、或查看健康数据——而不仅仅是是否曾经使用过。这是一项纵向指标，不同于某一时间点的活跃使用计数：两名患者可能拥有完全相同的"本月使用过该应用"状态，而其中一人每天坚持记录，另一人只记录一次便消失三周，只有一致性指标才能区分这两者。

## 为何重要

持续、规律地与数字健康工具互动，是临床获益最可靠的领先指标之一，尤其对于糖尿病、体重管理和心理健康等依赖行为的病症而言，因为这类工具的价值来自其所支持的习惯，而非任何单次使用。一款产品可能报告出健康的月活跃用户数，而实际上服务的人群只是登录一次便逐渐流失，因为月活跃使用这一门槛很低，无法说明该月内的使用模式；一致性指标能够以简单活动计数无法做到的方式捕捉这一点。由于一致性也是数月而非数周内更难维持的事情之一，它比容易受到入门后新奇效应影响的短窗口参与度数字，更能诚实地反映产品质量与临床契合度。

## 计算方法

```
参与一致性率 = 至少有一次合格互动的周数 / 登记总周数 × 100

应明确且一致地定义"合格互动"（例如一次饮食记录条目、一次
症状签到，或一次已完成的活动同步）——绝不应是被动事件，
如未记录任何操作的应用打开。

应以分布形式报告，而非仅报告人群平均值：
  例如周一致性 ≥ 80% 的患者比例、50-79% 的比例、
  < 50% 的比例
```

## 实例解析

一款营养指导应用登记一名患者12周。该患者在其中9周至少记录一次合格的饮食条目，其个人参与一致性率为9 / 12 × 100 = 75%。在该应用登记满12周以上的完整2000名患者队列中，600名患者（30%）保持周一致性 ≥ 80%，900名（45%）落在50-79%区间，500名（25%）低于50%。若仅报告队列平均值（可能约为65%），将掩盖整整四分之一的患者几乎完全没有参与的事实——这一群体值得单独调查，而不应被稀释进整体平均值中。

## 数据来源与注意事项

一致性数据来自产品自身的事件日志（饮食记录、活动同步、签到），"合格互动"的定义对所得比率有巨大影响——宽松的定义（任何应用打开）总会比严格的定义（完成的、有意义的记录条目）看起来更好，因此所使用的定义必须与任何报告的数字一并明确说明。自动同步的数据（例如联网健身追踪器在后台同步活动）应与手动记录的数据分开报告，因为自动同步可能虚增表观一致性，而不反映患者对产品指导的任何主动努力或参与。

## 常见误区

- **将应用打开与有意义的参与混为一谈**：被动的应用打开（例如由推送通知触发）与已记录的饮食条目或已完成的签到并不相同；应仅定义并报告合格互动。
- **仅报告人群平均值**：看似健康的平均一致性率可能掩盖了高度参与与几乎完全不参与患者并存的双峰人群；应报告跨一致性区间的分布，而非仅报告平均值。
- **忽视登记时长这一分母**：在不考虑登记时长的情况下比较登记时间差异很大的患者的一致性率，会偏向于测量窗口更短、更容易维持的那一组。
- **自动后台同步虚增比率**：被动同步的可穿戴设备数据流，可能让未参与的患者显得持续活跃，而实际上并无真实行为改变或产品参与。
