# 投资回报率（ROI）与投资价值（VOI）

投资回报率（ROI）是指数字健康平台相对于其总成本——许可、硬件部署、实施与持续人员配置——所产生的净财务回报，以比率或百分比表示。投资价值（VOI）是一项更广泛的配套指标，用以捕捉纯财务ROI计算无法捕捉的回报：护理质量的改善、患者与临床医生的满意度、健康公平影响，以及机构声誉，这些都无法干净地转化为一个美元数字，但都关乎一项数字健康投资是否应被视为成功。两者共同回答两个不同但互补的问题：ROI问的是"这在财务上是否自负盈亏？"；VOI问的是"考虑到所有重要因素，这是否值得去做？"

## 为何重要

如果ROI计算忽略了项目在纯粹成本抵消之外所产生的实质性价值，一项在第一年显示出较差或负ROI的数字健康投资并不自动等同于失败，一项显示出强劲ROI的投资也不自动等同于成功——而这正是VOI存在的意义所在，仅依赖ROI的机构可能面临撤资风险，撤掉那些具有真实价值、只是尚未（或永远不会）以直接财务回报形式体现的项目。与此同时，VOI比ROI更主观、更难以基准化，这使其容易被用来为一个实际上并未产生任何可衡量价值的项目的持续投资提供辩护；将两者一并报告的这种纪律——尽可能使VOI的构成要素具体化、可衡量化——正是使这一框架保持诚实、而非成为规避财务问责手段的关键。长期数字健康投资决策——尤其是在质量与公平结果直接与支付挂钩的基于价值的医疗中——越来越需要将这两个数字并列呈现。

## 计算方法

```
ROI = (财务收益 − 总投资成本) / 总投资成本 × 100

财务收益来源：单次护理事件成本降低、床日减少量（转化为
成本数字）、避免的急诊就诊（参见急诊科分流率）、再入院
罚款减少，以及任何直接收入。

总投资成本：平台许可、硬件/设备部署与维护、实施与集成
成本、持续的临床与技术人员配置。

VOI并非单一公式，而是一个结构化的多维度记分卡，将ROI与
已定义、可追踪的非财务价值领域相结合，例如：
  临床质量     （例如生物指标改善率、再入院率）
  患者体验     （例如患者净推荐值、SUS得分）
  公平性       （例如数字可及率、数字素养率）
  劳动力       （例如医生职业倦怠率）
每个领域均按其自身标准报告，而非人为转化为美元数字，与
财务ROI数字并列呈现。
```

## 实例解析

某远程监测项目在第一年花费60万美元（平台许可、设备部署和额外临床人员配置），产生了75万美元的可量化财务收益（床日减少量和避免的再入院罚款）。ROI为(75万 − 60万) / 60万 × 100 = 25%。在此数字之外，该机构的VOI记分卡报告患者净推荐值提高了5个点，登记高血压患者的生物指标稳定率为68%，以及登记临床医生非工作时间文书记录时间的可测量减少。这三项额外发现均未改变25%的ROI数字，但它们共同为持续投资构建了一个比单独的ROI数字更强有力的论证，尤其是对那些同样重视质量和公平结果与财务回报的利益相关方（临床领导层、患者权益团体）而言。

## 数据来源与注意事项

ROI的财务收益一方，借鉴了本书其他部分使用的相同成本与结果数据——单次护理事件成本、床日减少量、急诊科分流率——使用机构自身的成本核算方法转化为美元数字，应使用保守、可辩护的假设，而非乐观的最佳情况假设，因为基于激进假设构建的ROI数字无法经受住持怀疑态度的财务团队的审查。VOI的每个非财务领域都应使用本书其他部分已经过验证的指标（生物指标稳定率、患者净推荐值、数字可及率、医生职业倦怠率），而非非正式发明的替代指标，这样VOI记分卡本身才能保持可审计性，并能随时间进行比较，而不会沦为定义松散的叙述。

## 常见误区

- **对具有实质性非财务价值的项目仅报告ROI**：这可能仅因某项价值未体现在纯财务计算中，就冒着撤资真正具有临床、公平或劳动力价值的项目的风险；应将ROI与结构化的VOI记分卡配对。
- **将VOI用作规避财务问责的手段**：VOI应为每个非财务领域使用具体的、已验证的指标，而非模糊或未经测量的价值主张，否则它会成为一种在没有真实证据的情况下为持续支出辩护的方式。
- **在ROI的成本规避计算中使用乐观或未经验证的假设**：基于激进的避免成本假设构建的ROI数字无法经受审查，并可能损害未来投资案例的可信度。
- **在未经调整的情况下比较成本结构差异很大的项目的ROI数字**：不应在单一年度的ROI数字上，将前期资本成本高、回收期长的项目与前期成本低、回收快的项目进行比较，而不考虑所涉及的不同时间跨度。
