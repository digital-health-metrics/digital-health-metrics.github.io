# 单次护理事件成本

单次护理事件成本是指治疗一个特定临床事件——例如髋关节置换手术及其相关的恢复期，或一段糖尿病管理周期——所产生的总成本，与未接受所评估数字干预的历史基线队列进行比较。这是基于价值的医疗中财务比较的标准单位，因为它捕捉的是一次护理事件的完整经济全貌，而非任何单一成本项目本身，也是支付方和医疗系统在同意为某数字健康项目提供大规模资金支持之前，最常要求提供的指标。

## 为何重要

基于价值的医疗合同日益按护理事件和结果付费，而非按单项服务付费，这意味着数字健康项目的财务论证必须以同样的货币来表达：与该类型护理事件在干预措施出现之前的成本相比，单次事件的总成本如何变化。一个降低了某一成本类别（例如面对面随访次数减少）却增加了另一类别（更多设备成本、更多临床监测人员时间）的项目，并不必然降低了单次事件的总成本，只有完整的事件级成本核算才能捕捉这种权衡；孤立地看待任何单一成本项都有可能得出误导性的结论，无论方向如何。由于事件定义和基线期可以被构建成有利于某种特定结论的方式，这项指标比本书中大多数其他指标需要更高的方法论透明度，才能在持怀疑态度的支付方或财务团队面前具有可信度。

## 计算方法

```
单次护理事件成本 = 特定事件窗口内提供的所有护理的总成本
                    （所有护理场所、所有成本类别）/ 事件数

与匹配的历史基线队列在同一临床定义事件类型上的单次事件
成本进行比较，并按病例组合（年龄、合并症、严重程度）在
两个队列之间进行调整。

应纳入，而非仅限于直接临床成本：技术平台与设备成本、
额外的临床人员时间，以及转移场所（例如从住院转为居家）
而非完全消失的任何护理。
```

## 实例解析

某医疗系统全髋关节置换事件（手术至90天恢复期）的历史基线成本为每例28000美元，基于200例历史事件计算得出。引入一项新的数字化术后监测项目后，使用该项目的150例新事件显示平均成本为每例24500美元——每例减少3500美元，主要由急诊就诊次数减少和住院时长缩短所驱动。在针对数字监测队列相较历史基线略年轻、合并症较低的病例组合进行风险调整后，调整后的节省缩窄至每例2100美元——仍是真实的改善，但明显小于未经调整的原始比较所暗示的数字。

## 数据来源与注意事项

事件总成本通常从医疗系统自身的成本核算或财务系统中汇总，结合理赔数据、内部成本分摊，以及在涉及数字平台的情况下，其许可与硬件成本——准确汇总这一数字通常是任何数字健康价值分析中最困难、最耗费资源的部分，因为成本经常记录在从未被设计为能在事件层面进行合并的独立系统中。每当数字管理队列与历史基线队列并非通过真正随机分配确定时，病例组合调整至关重要，因为数字项目往往首先提供给参与度更高、总体更健康或更有积极性的患者，这可能产生表观的成本节省，而实际上是选择效应，而非真实的项目效应。

## 常见误区

- **在病例组合不同的队列间比较未经调整的成本**：数字管理队列若恰好比历史基线更健康或风险更低，其单次事件成本会更低，原因与数字干预本身无关；比较前应始终进行风险调整。
- **在成本比较的"数字"一方遗漏技术与人员成本**：仅追踪临床利用率降低、而忽略运行数字项目的平台、设备和人员成本的成本分析，会高估净节省。
- **队列间事件窗口定义不一致**：将一个队列的90天事件窗口与另一个队列的60天窗口进行比较，所产生的成本比较实际上并未衡量同一件事。
- **将成本转移视为成本降低**：从一个护理场所转移到另一个场所的成本（例如从住院转为受监测的居家场所）是一个真实且有价值的发现，但在分析上与完全消除的成本不同，应分别报告。
