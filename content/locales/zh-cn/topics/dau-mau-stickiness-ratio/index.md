# 日活/月活粘性比率

日活/月活粘性比率将日活跃用户（DAU）与月活跃用户（MAU）进行比较——用于周活跃用户（WAU）与MAU的比较也采用同样的基本衡量方式——以表达产品更广泛用户群体中，有多大比例在任意一天参与其中。这是衡量参与强度的标准产品分析指标，不同于用户是否完全被留存（参见用户留存率），也不同于某一特定登记患者随时间推移的参与一致程度（参见患者参与一致性率）：粘性描述的是人群层面的使用节奏，而非任何个体的模式。

## 为何重要

两款数字健康产品可能报告出完全相同的月活跃用户数，但其潜在的参与强度却大相径庭：一款是大多数用户几乎每天都打开应用，另一款则是大多数用户每月只打开一次，恰好在被计为非活跃前完成。日活/月活粘性比率用一个简单、易懂、可随时间追踪并与已知行业范围比较的单一基准数字，区分了这两种截然不同的情况——约20%的比率是许多消费者应用常被引用的合理基准，而每日习惯型产品（患者被期望每天使用的饮食或症状日记）则应以明显更高的标准来衡量。由于粘性对"活跃"的定义方式很敏感，它最适合用作单一产品随时间的趋势，以及与为类似使用模式而构建的产品之间的比较，而非跨行业的绝对基准。

## 计算方法

```
日活/月活粘性比率 = 期间内平均日活跃用户数 /
                      同期月活跃用户数 × 100

周活/月活比率（原理相同）是一种较为温和的变体，更适用于
预期每周使用几次而非每天使用的产品。

必须在分子和分母中精确且一致地定义"活跃"（例如已完成的
合格操作，而非被动的应用打开）。
```

## 实例解析

一款数字糖尿病管理应用在某月拥有10000名月活跃用户，定义为该月内至少完成一次合格操作（血糖记录、饮食记录或用药签到）的用户。将该月30天内的日活跃用户数取平均，得出平均日活为2200。日活/月活粘性比率为2200 / 10000 × 100 = 22%，表明在典型一天中，该应用约22%的月活用户基础会与其互动——对于一款每日习惯型慢性病工具而言，这是一个合理的数字，尽管产品团队希望看到该数字随时间推移而上升，因为理想行为（每日记录）对登记患者而言变得更加习惯化。

## 数据来源与注意事项

DAU、WAU和MAU都是根据相同的基础事件日志计算得出的，在每个窗口中使用一个一致的"合格活跃"事件定义；如果在分子和分母的计算之间改变该定义（例如DAU计入任何应用打开，而MAU仅计入已完成的操作），会产生一个无法反映真实参与强度的失真比率。粘性的适当基准在很大程度上取决于产品的预期使用模式：预期每周使用一次的工具（每周症状签到）将会、也应该显示出比预期每日使用的工具（连续血糖监测配套应用）更低的日活/月活比率，因此应始终根据产品自身的预期使用节奏来解读粘性，而非单一的通用目标。

## 常见误区

- **在预期使用频率不同的产品间比较粘性比率**：即使两款产品在各自使用场景下都表现如预期，每周使用型工具在结构上也会显示出比每日使用型工具更低的日活/月活比率；应根据产品自身的预期节奏进行基准比较，而非单一通用目标。
- **在分子和分母中使用不一致的活动定义**：这可能产生一个无法反映真实参与强度、且无法随时间或与其他产品进行有意义比较的粘性比率。
- **在未检查整体月活趋势的情况下将上升的粘性比率视为绝对积极的信号**：由一个正在萎缩、但更为习惯化的核心用户群驱动的上升比率，同时整体月活正在下降，这与由在稳定或增长的用户基础上真正增加每日参与所驱动的情况截然不同——且更令人担忧。
- **忽视日活的星期几与季节性效应**：对许多健康产品而言，日活可能因星期几（工作日与周末）或季节而显著变化；应在涵盖完整自然周期的期间内对日活取平均，而非使用可能有偏差的短窗口。
