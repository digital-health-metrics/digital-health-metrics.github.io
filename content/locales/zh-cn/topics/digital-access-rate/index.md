# 数字可及率

数字可及率是指符合条件的患者人群中，具备使用数字健康产品实际能力的比例：可靠的宽带或移动数据连接、具备联网能力的设备，以及相关患者门户或应用程序的有效账户。这是本书中所有其他数字健康指标的前提条件指标——无论产品设计得多好，一个在结构上无法触及某产品的人群，都无法注册、参与或从中获益。

## 为何重要

数字健康的采纳与参与度指标隐含地假定人群已经拥有数字可及性，在未先确立基础可及率的情况下报告采纳率或参与度，有可能悄悄地排除那些最不可能拥有该可及性的患者——而这些患者往往也是健康需求最大的患者。HIMSS数字健康公平衡量框架（DHEMF）等类似框架，将数字可及性视为一项基础性、第一位的公平指标，正是因为未考虑可及性差距而构建的干预措施，往往会加剧而非缩小既有的健康差距：以远程医疗为先的策略可能无意中降低了没有可靠连接或设备的患者的护理可及性，即使它同时可衡量地改善了已经拥有两者的患者的体验。应按人口统计和地理细分追踪并报告数字可及率，因为全国性或机构层面的平均值经常性地掩盖了特定人群的巨大差距。

## 计算方法

```
数字可及率 = 同时具备宽带/移动连接、联网能力设备，及有效
              患者门户或应用账户的患者数 / 符合条件的患者
              总人数 × 100

除综合比率外，应分别报告每个子要素：
  连接率           = 拥有可靠互联网连接的患者数 /
                    符合条件人数 × 100
  设备拥有率       = 拥有联网能力设备的患者数 /
                    符合条件人数 × 100
  门户激活率       = 拥有有效门户/应用账户的患者数 /
                    符合条件人数 × 100（关于更完整的
                    采纳漏斗，参见患者门户采纳率）
```

## 实例解析

某医疗系统服务40000名符合条件的患者。患者调查与基础设施数据显示，34000人（85%）拥有可靠的宽带或移动连接，33000人（82.5%）拥有联网能力设备，而在同时满足这两个条件的患者中，27000人（占符合条件总人数的67.5%）拥有有效的患者门户账户。按年龄细分显示，65岁以上患者的综合数字可及率仅为48%，而65岁以下患者为78%——这一差距被67.5%的机构整体平均值完全掩盖，而这一差距本应直接指导是否可以为该人群安全地提供纯数字化服务的决策。

## 数据来源与注意事项

连接性与设备拥有数据通常来自患者自报（通过调查或接诊问卷）、美国联邦通信委员会（FCC）或同等机构针对患者所在地理区域的国家宽带可用性地图数据，以及机构自身系统的门户激活数据的组合。区域层面的宽带可用性（某提供商是否在特定邮政编码区域提供服务）是比家庭层面连接性更弱的代理指标，因为区域层面的可用性数据并不能说明某个特定患者是否能够负担得起或是否已选择订阅该服务——不应将区域层面与家庭层面的可及率混为一谈。设备和连接的可及性也可能在家庭内共享（例如，一部智能手机被多个家庭成员使用），家庭层面的调查数据比单独的个人层面门户登录数据更能捕捉这一点。

## 常见误区

- **仅报告机构整体平均值**：这可靠地掩盖了老年、低收入、农村或其他数字边缘化患者细分群体的巨大可及性差距；应始终按人口统计和地理细分进行报告。
- **将区域层面的宽带可用性与实际家庭可及性混为一谈**：某邮政编码区域被宽带提供商"覆盖"，并不意味着该区域内的每个家庭都订阅或能负担得起该服务。
- **将设备拥有视为静态的一次性事实**：设备可及性可能是暂时性的（设备老化、手机丢失或损坏、共享的家庭设备被重新分配），因此应定期测量可及率，而非在评估一次后便假定其保持不变。
- **在确立受影响人群的可及率之前设计纯数字化路径**：在未先确认目标人群实际数字可及率的情况下，将某项服务转为纯数字化，有可能悄悄排除那些最无法触及替代渠道的患者。
