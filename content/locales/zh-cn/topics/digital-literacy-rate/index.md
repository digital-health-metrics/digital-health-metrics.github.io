# 数字素养率

数字素养率是指患者人群中，能够独立且成功地完成数字健康平台上常见任务——登录、预约、加入视频问诊，或查看检测结果——而无需他人协助的比例。它与数字可及率不同，也应始终与之分开测量：一名患者可能拥有智能手机和宽带连接，却仍无法在无协助的情况下浏览远程医疗平台，将这两项指标混为一谈，恰恰掩盖了这项指标本应揭示的人群。

## 为何重要

仅有数字可及性并不能保证患者能够有效使用数字健康服务：健康素养较低、普遍缺乏技术使用经验、存在认知或视力障碍，或与平台界面存在语言障碍的患者，可能拥有完全的技术可及性，却仍无法独立完成任务，而这一差距与已经面临其他健康差距的相同人口群体存在系统性关联。HIMSS数字健康公平衡量框架正是出于这一原因，将数字素养视为与可及性不同的独立支柱：仅弥合可及性差距而不同时解决素养差距，可能会留下一个技术上已连接、但功能上无法从中受益的人群。按语言和社会经济指标细分，测量常见平台操作的任务完成率和完成时间的机构，能够比仅依赖可及性指标或整体满意度分数的机构，更精确地识别素养障碍并有针对性地提供支持（简化界面、辅助入职、替代语言内容）。

## 计算方法

```
数字素养率 = 无协助独立完成特定任务的患者数 /
              尝试该任务的患者数 × 100

测量的常见任务：账户登录、预约挂号、加入视频问诊、
查看检测结果、完成接诊表格。

应按任务分别报告，而非合并为单一分数，因为简单任务
（登录）与复杂任务（完成多步骤接诊表格）的素养差异
很大，合并会掩盖具体障碍所在。
```

## 实例解析

某医疗系统在一个月内的5000次已预约远程医疗就诊中，将加入视频问诊作为一项特定任务进行追踪。其中4100名患者成功加入，且未在问诊过程中拨打任何支持电话或获得技术协助（该任务的数字素养率：82%）。按主要语言细分显示，说英语的患者比率为89%，而主要语言与平台默认界面语言不同的患者比率为61%——这一28个百分点的差距，如果仅报告混合的82%数字将完全无法察觉，而这一差距直接指向一项具体、可解决的干预措施（翻译界面与说明），而非一个模糊的笼统素养问题。

## 数据来源与注意事项

任务完成数据通常从平台自身的事件日志中获取（患者是否成功加入视频问诊、预约流程是否未中断地完成），并辅以支持电话或帮助台联系数据，以识别那些仅因患者中途获得实时协助而在技术上"完成"的任务。仅从系统日志计为"已完成"的任务，可能掩盖了患者需要家庭成员的电话或支持人员帮助才能完成的事实——在平台能够区分两者的情况下，应将真正独立于素养的完成情况与获得协助的完成情况分别定义和追踪。数字素养与健康素养及一般素养相关，但在分析上有所不同；在需要正式评估的情况下，应使用经过验证的工具（而非仅基于年龄或人口统计的非正式假设）。

## 常见误区

- **将数字素养与数字可及性混为一谈**：一名拥有完全技术可及性的患者仍可能缺乏有效使用它的素养；这是需要不同干预措施的独立指标，绝不应报告为单一合并数字。
- **将获得协助的完成情况计为无协助的成功**：如果患者仅在支持电话或家庭成员帮助下才能完成任务，这是平台掩盖而非解决的素养差距；应在数据允许的情况下区分有协助与无协助的完成情况。
- **报告单一合并任务完成分数**：简单任务（登录）与复杂任务（完成详细接诊表格）的素养差异很大；应按任务报告，以准确找出障碍所在。
- **假设年龄本身能预测数字素养**：尽管年龄在总体上与较低的数字素养相关，但对平台界面语言的熟练程度和一般技术熟悉度往往是更强的个体预测因素，应直接测量，而非从年龄推断。
