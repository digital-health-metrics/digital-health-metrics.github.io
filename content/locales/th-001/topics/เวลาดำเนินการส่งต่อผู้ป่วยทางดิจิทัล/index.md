# เวลาดำเนินการส่งต่อผู้ป่วยทางดิจิทัล

เวลาดำเนินการส่งต่อผู้ป่วยทางดิจิทัลคือเวลาที่ผ่านไปตั้งแต่การส่งต่อผู้ป่วยทางอิเล็กทรอนิกส์โดยแพทย์ผู้ส่งต่อ จนถึงการคัดกรองและการตอบรับ ปฏิเสธ หรือนัดหมายโดยบริการผู้รับ เป็นตัวชี้วัดกระบวนการ (การไหล) ที่แตกต่างจากเวลารอคอยทั้งหมดของผู้ป่วย และเป็นหนึ่งในจุดที่ชัดเจนที่สุดที่การเปลี่ยนแปลงระบบดิจิทัล (การส่งต่อทางอิเล็กทรอนิกส์แบบมีโครงสร้าง การคัดกรองด้วยภาพ แบบฟอร์มการส่งต่อมาตรฐาน) สามารถแสดงให้เห็นว่าเปลี่ยนตัวเลขการดำเนินงานได้จริง ไม่ใช่เพียงคะแนนความพึงพอใจ

## เหตุใดจึงสำคัญ

ขั้นตอนการคัดกรองที่ช้าหรือมีความผันผวนสูงเพิ่มความล่าช้าก่อนที่ผู้ป่วยจะเข้าสู่รายการรอทางคลินิกด้วยซ้ำ และเนื่องจากความล่าช้านี้เกิดขึ้นก่อนที่การดูแลทางคลินิกใดๆ จะเริ่มต้น จึงเป็นความสูญเปล่าของกระบวนการล้วนๆ ที่เครื่องมือดิจิทัลมีความพร้อมในการขจัดออก ระบบส่งต่อที่บังคับให้เกิดวงจร "ส่งกลับไปยังผู้ส่งต่อ" เนื่องจากข้อมูลไม่ครบถ้วนจะสร้างวงจรการทำงานซ้ำที่ง่ายต่อการมองข้ามหากเวลาดำเนินการถูกวัดเฉพาะการส่งต่อที่ผ่านไปอย่างราบรื่นในครั้งแรกเท่านั้น ในกรณีที่บริการได้นำแบบฟอร์มการส่งต่อดิจิทัลแบบมีโครงสร้าง ฟิลด์บังคับ หรือการคัดกรองด้วยภาพ (เช่น ในโรคผิวหนังทางไกล) มาใช้ เวลาดำเนินการมักเป็นตัวชี้วัดเดียวที่โน้มน้าวใจได้มากที่สุดในการแสดงประโยชน์ เนื่องจากสามารถวัดได้ทั้งก่อนและหลังการเปลี่ยนแปลงด้วยเครื่องมือวัดเดียวกัน

## วิธีคำนวณ

```
เวลาดำเนินการ = เวลาประทับ(การตัดสินใจคัดกรอง) − เวลาประทับ(การส่งต่อ)

รายงานค่ามัธยฐานและเปอร์เซ็นไทล์สูง (โดยทั่วไปคือเปอร์เซ็นไทล์ที่ 90)
ไม่ใช่แค่ค่าเฉลี่ยเท่านั้น เนื่องจากการกระจายตัวมักเบ้ไปทางขวาอย่างมาก
จากการส่งต่อที่ถูกส่งกลับหรือมีความซับซ้อน

พิจารณาการจับเวลาในขั้นตอนย่อยหากระบบสามารถบันทึกได้:
  การส่ง → ได้รับโดยบริการ
  ได้รับ → การตัดสินใจคัดกรอง
  การตัดสินใจคัดกรอง → นัดหมาย (หากเกี่ยวข้อง)
```

## ตัวอย่างการคำนวณ

เส้นทางการตรวจสอบของระบบส่งต่อทางอิเล็กทรอนิกส์แสดงเวลามัธยฐานจากการส่งถึงการตัดสินใจคัดกรองที่ 1.8 วันในทุกสาขาเฉพาะทาง โดยมีเวลาเปอร์เซ็นไทล์ที่ 90 อยู่ที่ 6 วัน ซึ่งขับเคลื่อนส่วนใหญ่โดยการส่งต่อที่ถูกส่งกลับไปยังผู้ส่งต่อเนื่องจากข้อมูลทางคลินิกไม่ครบถ้วน เส้นทางโรคผิวหนังทางไกลที่ใช้การคัดกรองด้วยภาพบนแพลตฟอร์มเดียวกันบรรลุเวลาดำเนินการมัธยฐาน 4 ชั่วโมงและเปอร์เซ็นไทล์ที่ 90 อยู่ที่ 1 วัน เนื่องจากภาพถ่ายและประวัติแบบมีโครงสร้างเพียงพอเกือบตลอดเวลาสำหรับการตัดสินใจคัดกรองโดยไม่ต้องติดต่อเพิ่มเติม

## แหล่งข้อมูลและข้อควรระวัง

เส้นทางการตรวจสอบของระบบส่งต่อทางอิเล็กทรอนิกส์หรือระบบจัดการการส่งต่อเองเป็นแหล่งข้อมูลหลัก โดยใช้เวลาประทับการส่งและการตัดสินใจ องค์กรควรยืนยันว่า "นาฬิกา" หยุดชั่วคราวหรือไม่ในขณะที่การส่งต่อถูกส่งกลับเพื่อขอข้อมูลเพิ่มเติม หรือเดินต่อเนื่อง เนื่องจากคำนิยามทั้งสองแบบให้ตัวเลขที่แตกต่างกันอย่างมีนัยสำคัญสำหรับกระบวนการเดียวกัน เวลาดำเนินการควรรายงานเป็นเวลาตามปฏิทินหรือเวลาทำการอย่างสม่ำเสมอ เนื่องจากผลกระทบของวันหยุดสุดสัปดาห์และวันหยุดนักขัตฤกษ์อาจบิดเบือนการเปรียบเทียบระหว่างบริการที่มีรูปแบบการทำงานต่างกัน

## ข้อผิดพลาดที่พบบ่อย

- **วัดเฉพาะการส่งต่อที่ "สะอาด"**: การตัดการส่งต่อที่ถูกปฏิเสธหรือส่งกลับออกจากการคำนวณจะซ่อนภาระงานซ้ำที่เครื่องมือดิจิทัลมักมีจุดประสงค์เฉพาะในการลด
- **รายงานค่าเฉลี่ยแทนค่ามัธยฐานและเปอร์เซ็นไทล์**: การส่งต่อจำนวนน้อยที่ใช้เวลานานและถูกส่งกลับจะดึงค่าเฉลี่ยให้สูงกว่าประสบการณ์จริงของผู้ป่วยทั่วไปมาก
- **สับสนระหว่างเวลาดำเนินการกับเวลารอคอยทั้งหมด**: เวลาดำเนินการครอบคลุมเฉพาะขั้นตอนการคัดกรองเท่านั้น ประสบการณ์ทั้งหมดของผู้ป่วยยังรวมถึงรายการรอทางคลินิกที่ตามมา ซึ่งเป็นตัวชี้วัดแยกต่างหากที่ควบคุมโดยข้อจำกัดด้านกำลังการให้บริการที่แยกต่างหาก
- **ไม่แยกแยะขั้นตอนย่อย**: บริการที่วัดเฉพาะเวลาจากต้นจนจบไม่สามารถบอกได้ว่าตัวเลขที่ช้าเกิดจากผู้ส่งต่อที่ส่งข้อมูลไม่ครบถ้วน จากกำลังการคัดกรองของบริการผู้รับ หรือทั้งสองอย่าง

## แหล่งอ้างอิง

- NHS England สถิติและข้อกำหนดบริการของ e-Referral Service (e-RS)
- วรรณกรรมที่ผ่านการตรวจสอบโดยผู้เชี่ยวชาญเกี่ยวกับระบบจัดการการส่งต่อทางอิเล็กทรอนิกส์และเส้นทางการคัดกรองดิจิทัล รวมถึงโรคผิวหนังทางไกล
- ONC / HealthIT.gov แนวทางด้านความสามารถในการทำงานร่วมกันและการประสานงานการส่งต่อ
