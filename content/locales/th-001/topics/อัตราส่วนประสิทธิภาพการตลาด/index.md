# อัตราส่วนประสิทธิภาพการตลาด

อัตราส่วนประสิทธิภาพการตลาด (MER) คือรายได้รวมหารด้วยค่าใช้จ่ายการตลาดรวมในช่วงเวลาที่กำหนด ให้การตรวจสอบอิสระเทียบกับผลตอบแทนจากค่าใช้จ่ายโฆษณา (ROAS) ที่แพลตฟอร์มรายงาน เนื่องจากใช้รายได้และค่าใช้จ่ายรวมของธุรกิจแทนที่จะพึ่งพาโมเดลการระบุที่มาภายในของแพลตฟอร์มโฆษณาเพียงแพลตฟอร์มเดียว MER จึงหลีกเลี่ยงการนับซ้ำการระบุที่มาที่เกิดขึ้นเมื่อหลายแพลตฟอร์ม (การค้นหา โซเชียล การแสดงผล) ต่างอ้างสิทธิ์การแปลงลูกค้าเดียวกัน

## เหตุใดจึงสำคัญ

การตลาดสมัยใหม่มักเกิดขึ้นในหลายแพลตฟอร์มพร้อมกัน และแต่ละแพลตฟอร์มมักรายงาน ROAS ที่ดูดี โดยอิงจากโมเดลการระบุที่มาภายในของตนเอง ซึ่งหมายความว่าผลรวมของตัวเลข ROAS ที่รายงานโดยแต่ละแพลตฟอร์มมักเกินจริงประสิทธิภาพการตลาดโดยรวมอย่างมาก เนื่องจากหลายแพลตฟอร์มต่างอ้างสิทธิ์การแปลงผู้ป่วยเดียวกัน MER หลีกเลี่ยงปัญหานี้โดยสิ้นเชิงด้วยการมองที่ธุรกิจทั้งหมด: รายได้รวมที่สร้างขึ้นหารด้วยค่าใช้จ่ายการตลาดรวมที่ใช้ไป โดยไม่คำนึงว่าแพลตฟอร์มใดอ้างสิทธิ์การระบุที่มา สิ่งนี้ทำให้เป็นการตรวจสอบสามัญสำนึกอิสระที่สำคัญสำหรับทีมการตลาดใดๆ ที่รายงานประสิทธิภาพที่แข็งแกร่งโดยอิงจากตัวเลข ROAS เฉพาะแพลตฟอร์ม และมีคุณค่าอย่างยิ่งสำหรับผู้บริหารและผู้มีส่วนได้ส่วนเสียทางการเงินที่ต้องการตัวเลขเดียวที่น่าเชื่อถือเกี่ยวกับผลงานโดยรวมของการตลาดต่อธุรกิจ

## วิธีคำนวณ

```
อัตราส่วนประสิทธิภาพการตลาด (MER) = รายได้รวมในช่วงเวลาหนึ่ง / ค่า
                                       ใช้จ่ายการตลาดรวมในช่วงเวลา
                                       เดียวกัน

สิ่งนี้แตกต่างจาก ROAS ซึ่งโดยทั่วไปคำนวณต่อช่องทางหรือแคมเปญและ
ขึ้นอยู่กับโมเดลการระบุที่มาภายในของแพลตฟอร์มนั้น:
  ROAS (ต่อแพลตฟอร์ม) = รายได้ที่แพลตฟอร์มระบุที่มา / ค่าใช้จ่ายบน
                         แพลตฟอร์มนั้น
```

## ตัวอย่างการคำนวณ

บริษัทสุขภาพดิจิทัลดำเนินแคมเปญการตลาดในโฆษณาการค้นหา โซเชียลมีเดีย และโฆษณาแบบแสดงผล ซึ่งรวมกันอ้างสิทธิ์ ROAS รวม 8:1 โดยอิงจากการรายงานการระบุที่มาภายในของแต่ละแพลตฟอร์ม แต่เมื่อมองที่ธุรกิจทั้งหมด รายได้รวม 2,000,000 ดอลลาร์ที่สร้างขึ้นในไตรมาสหารด้วยค่าใช้จ่ายการตลาดรวม 400,000 ดอลลาร์ในทุกช่องทาง MER ที่แท้จริงอยู่ที่เพียง 5:1 เผยให้เห็นว่ารายงานการระบุที่มาเฉพาะแพลตฟอร์มมีการนับซ้ำการแปลงลูกค้าจำนวนมาก ความแตกต่างนี้ผลักดันให้ทีมการตลาดตรวจสอบการซ้อนทับการระบุที่มาข้ามแพลตฟอร์มและปรับการจัดสรรส่วนผสมช่องทางตามตัวเลข MER ที่น่าเชื่อถือกว่า แทนที่จะใช้รายงาน ROAS เฉพาะแพลตฟอร์มที่สูงเกินจริง

## แหล่งข้อมูลและข้อควรระวัง

MER ต้องการเพียงสองตัวเลขเท่านั้น คือ รายได้รวมของธุรกิจและค่าใช้จ่ายการตลาดรวม ทำให้การคำนวณค่อนข้างตรงไปตรงมาเมื่อเทียบกับการวิเคราะห์การระบุที่มาเฉพาะแพลตฟอร์ม แต่ความเรียบง่ายนี้ก็เป็นข้อจำกัดด้วยเช่นกัน: MER ไม่ได้บอกว่าช่องทางหรือแคมเปญเฉพาะใดกำลังขับเคลื่อนผลลัพธ์ บอกเพียงว่าความพยายามทางการตลาดโดยรวมมีประสิทธิภาพหรือไม่ MER ยังอาจได้รับผลกระทบจากการเปลี่ยนแปลงรายได้ที่ไม่ได้ขับเคลื่อนโดยการตลาด (เช่น ความต้องการตามฤดูกาลหรือการเปลี่ยนแปลงราคา) ดังนั้นจึงสำคัญที่จะพิจารณาว่าการเปลี่ยนแปลงรายได้นั้นเกิดจากกิจกรรมการตลาดจริงหรือไม่

## ข้อผิดพลาดที่พบบ่อย

- **พึ่งพา ROAS ที่แพลตฟอร์มรายงานเพียงอย่างเดียว**: หลายแพลตฟอร์มที่ต่างอ้างสิทธิ์การแปลงลูกค้าเดียวกันอาจทำให้ ROAS รวมเกินจริงประสิทธิภาพการตลาดที่แท้จริงอย่างมาก
- **ใช้ MER เพื่อปรับแต่งช่องทางเฉพาะ**: MER เป็นตัวชี้วัดรวมระดับธุรกิจและไม่ให้รายละเอียดที่จำเป็นในการตัดสินใจเกี่ยวกับช่องทางหรือแคมเปญเฉพาะ
- **ละเลยปัจจัยขับเคลื่อนรายได้ที่ไม่ได้มาจากการตลาด**: MER ที่คงที่หรือดีขึ้นพร้อมกับรายได้ที่เพิ่มขึ้นอาจสะท้อนการเติบโตแบบธรรมชาติ (การแนะนำ การค้นหาแบบธรรมชาติ การบอกต่อ) มากกว่าประสิทธิภาพการตลาด แยกรายได้ตามแหล่งที่มาของการได้มาเมื่อเป็นไปได้เพื่อหลีกเลี่ยงการให้เครดิตมากเกินไปแก่การตลาด
- **เปรียบเทียบ MER ระหว่างช่วงเวลาที่มีส่วนผสมการตลาดต่างกัน**: ช่วงเวลาที่ครอบงำด้วยค่าใช้จ่ายสร้างแบรนด์ (ที่มีผลกระทบต่อรายได้ล่าช้า) เทียบกับค่าใช้จ่ายตอบสนองโดยตรง (ที่มีผลกระทบต่อรายได้ทันที) จะให้ตัวเลข MER ที่แตกต่างกันโดยไม่จำเป็นต้องสะท้อนการเปลี่ยนแปลงประสิทธิภาพที่แท้จริง
