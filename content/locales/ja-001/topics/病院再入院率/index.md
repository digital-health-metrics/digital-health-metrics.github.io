# 病院再入院率

病院再入院率とは、退院した患者のうち、退院後定められた期間内——最も一般的には30日以内——に予定外で病院に再入院した患者の割合を指す。デジタルヘルスにおいては、これは支払者の経済性と価値ベースのケア契約に最も直接的に結びついた指標である。遠隔モニタリング、退院後フォローアップ、またはデジタルケア移行プログラムが再入院に対して信頼できる効果を示せない場合、エンゲージメント数値がどれほど良くても、継続的な償還支援を得ることは難しい。

## なぜ重要か

予定外の再入院は費用がかかり、患者にとって負担となり、現在多くの医療システムで直接的なペナルティの対象となっている。米国のHospital Readmissions Reduction Programのような制度は、特定の疾患について予想より高い再入院率を持つ病院への支払いを削減する。このため病院は、再入院を減らすことを目的としたデジタル退院後プログラムや遠隔モニタリングプログラムを積極的に委託している。再入院のかなりの割合は潜在的に予防可能であると考えられている——不十分な退院指示、フォローアップ予約の見逃し、服薬の誤解、あるいは適切に設計されたデジタルタッチポイントであればより早く察知できたはずの未対応の症状悪化によって引き起こされる——これはまさにデジタル移行ケアツールが対象とするギャップである。再入院率は常にケースミックスとともに読み解かれるべきである。より重症で複雑な患者集団にサービスを提供するプログラムは、プログラムの質とは無関係に、より健康な集団にサービスを提供するプログラムよりも構造的に高いベースライン率を持つことになる。

## 算出方法

```
30日再入院率 = 退院後30日以内の予定外再入院数 / 指標となる
              退院総数 × 100

分子から除外するもの: 予定された再入院(例:予定された
フォローアップ処置)、および同一ケアエピソードの継続である
転院(新規入院ではないもの)。

可能な限り、異なる患者集団や期間間で率を比較する前に、
承認されたケースミックスまたは併存疾患指数を用いてリスク
調整を行うこと。
```

## 計算例

ある病院が四半期に心不全患者1,200人を退院させた。このうち210人が30日以内に再入院し、そのうち15人は予定された処置のための予定された再入院であり除外される。予定外の30日再入院率は(210 − 15) / 1,200 × 100 = 16.25%である。これらの患者のうち400人の部分集合(臨床的リスクに基づいて選択されたもので、無作為ではない)に対して遠隔モニタリングプログラムが導入され、その予定外再入院率は14%であり、登録されていない800人の18%と比較される。登録は無作為割り付けではなく臨床的リスクに基づいていたため、この差はプログラムの効果の決定的な証拠ではなく示唆的なものであり、額面通りに受け取るのではなく、リスク調整分析と併せて解釈すべきである。

## データソースと注意点

再入院データは通常、同一施設への再入院については病院自身のadmission-discharge-transfer(ADT)フィードから抽出されるが、別の病院に再入院した患者はそのフィードにまったく現れないため、単一病院の再入院追跡は、地域の医療情報交換、支払者の請求データ、または州レベルの全支払者データベースで補完しない限り、真の再入院率を体系的に過小評価することになる。デジタルプログラムへの帰属には注意が必要である。任意参加の遠隔モニタリングプログラムに参加する患者は、退院した集団の無作為なサンプルであることはめったにない。そのため、登録者と非登録者の再入院率の単純な比較は、そもそも一部の患者を登録しやすくした選択効果によって交絡される傾向がある。

## 落とし穴

- **リスク未調整の生の率を異なる集団間で比較すること**: より重症な集団にサービスを提供するプログラムは、そのプログラム自体がより効果的であっても、より健康な集団にサービスを提供するプログラムよりも高い生の再入院率を示す。比較する前に常にリスク調整を行うこと。
- **他施設への再入院を過小計上すること**: 単一病院自身のADTデータのみに頼ると、特に複数の競合する病院システムがある地域では、他所での再入院を見逃し、真の率を過小評価することになる。
- **任意プログラム登録における選択バイアス**: デジタルフォローアッププログラムへの参加を選ぶ患者は、参加しない患者と(健康リテラシー、社会的支援、またはモチベーションにおいて)体系的に異なることが多く、単純な前後比較や登録者/非登録者比較を交絡させる。
- **同一施設へのすべての復帰を再入院としてカウントすること**: 予定された計画的な再入院(例:予定された第二段階の処置)は失敗した退院の兆候ではなく、分子から除外すべきであり、真に予定外の復帰と混ぜるべきではない。
