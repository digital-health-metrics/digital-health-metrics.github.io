# マーケティング効率比率

マーケティング効率比率(MER)は、定められた期間について、すべてのチャネルにわたる総マーケティング費用で割った総収益である。これは、プラットフォームが報告する広告費用対効果(ROAS)に対する意図的な独立した現実チェックとして存在する。ROASは各チャネル自身の主張する収益への貢献を測定するものであり、構造的に自己を過大評価しやすい。MERは代わりに、単一の広告プラットフォームでは歪めることのできない数値である、総費用に対する総収益を見る。

## なぜ重要か

各広告プラットフォームは独自のアトリビューションモデルを使用してROASを報告し、ほとんどの組織は複数のチャネルを同時に運用しているため、同じコンバージョンした顧客が複数のプラットフォームによって頻繁にクレジットされる。その結果、各プラットフォームの自己報告ROASの合計は、実際の総収益と比較すると日常的に総マーケティング貢献を過大評価する。MERは、組織レベルで総収益と総費用を比較することによってこの問題を完全に回避し、アトリビューションゲームやプラットフォームに有利な報告を通じて歪めることをはるかに困難にする。これこそが、財務や経営幹部チームがますますこれを、個々のプラットフォームが報告する数値を較正するための信頼できるトップライン効率チェックとして扱う理由である。個々のすべてのチャネルで強いROASを報告しながら全体のMERが低下しているマーケティングチームは、チャネルレベルの報告だけでは明らかにならない、本物の効率性またはアトリビューションの重複の問題を抱えている。

## 算出方法

```
MER = 総収益 / 総マーケティング費用(すべてのチャネル、同じ期間)

ROASとは異なり、MERはチャネルごとに計算されない——これは単一の
組織全体の数値である。まさにその価値が、どのプラットフォームの
アトリビューションの主張にも左右されないことから来ているためで
ある。

安定または増加する費用の下で時間とともに上昇するMERは、全体的な
マーケティング効率の改善を示す。増加する収益の下で安定したMERは、
成長が非マーケティング主導の源泉(例:紹介、オーガニック検索、
口コミ)から来ていることを示す可能性がある。
```

## 計算例

あるデジタルヘルス企業が四半期に$2,400,000の収益を生み出し、すべての有料チャネルにわたる総マーケティング費用は$480,000である。MERは$2,400,000 / $480,000 = 5.0である。個別には、有料検索プラットフォームはROAS 6.0を報告し、有料ソーシャルプラットフォームはROAS 5.5を報告し、プログラマティックディスプレイプラットフォームはROAS 4.0を報告する——これらが総収益貢献への主張として単純に合計された場合、コンバージョンした顧客のかなりの割合が複数のチャネルにさらされ二重または三重にカウントされているため、企業が実際に生み出した以上の総アトリビューション収益を暗示することになる。5.0という組織全体のMERは、これを調整する数値である。プラットフォームレベルのROAS数値が構造的に膨らませられるようなやり方では、アトリビューションの重複によって膨らませることができない。

## データソースと注意点

総収益は組織自身の財務または請求システムから得られ、総マーケティング費用はすべてのチャネルにわたる実際に請求され支払われたマーケティングコストから得られる——両方とも、いかなる広告プラットフォーム自身のダッシュボードからも独立して取得されるべきである。MERは単一の普遍的なベンチマークに照らして判断するのではなく、時間をかけたトレンドとして追跡されるべきである。なぜなら「良い」MERはビジネスモデル、マージン構造、成長段階によって大きく異なるためである。成長に積極的に投資している初期段階の企業は、収益性のために最適化している成熟した企業よりも意図的に低いMERを受け入れるかもしれない。MERは効率性の変化の責任がどのチャネルにあるかを診断しない——その診断作業には依然としてチャネルレベルの分析が必要であり、理想的にはプラットフォームが報告するアトリビューションだけでなく、インクリメンタリティテスト(マーケティングへの露出を受けないホールドアウトグループ)で補完されるべきである。

## 落とし穴

- **プラットフォームが報告するROASをチャネル間で加算可能として扱うこと**: 各プラットフォームの自己報告ROASを合計すると、顧客が複数のチャネルにさらされクレジットされるたびに総マーケティング貢献を過大評価する。これはよくあることである。MERは設計によってこれを回避する。
- **MERを固定された普遍的なベンチマークと比較すること**: 適切なMERはビジネスモデル、マージン、成長段階によって異なる。固定された合否閾値としてではなく、1つの組織の時間をかけたトレンドとして使用すること。
- **MERをチャネルレベルの診断として使用すること**: MERは意図的に組織全体の数値であり、それ自体ではどのチャネルが効率性の変化を牽引しているかを特定できない。その目的のためにはチャネルレベルの分析とインクリメンタリティテストと組み合わせること。
- **非マーケティング収益の推進要因を無視すること**: 増加する収益の下で安定または改善するMERは、マーケティング効率ではなく有機的成長(紹介、口コミ、獲得メディア)を反映している可能性がある。マーケティングに過剰にクレジットを与えることを避けるため、可能な限り獲得元別に収益を分解すること。
