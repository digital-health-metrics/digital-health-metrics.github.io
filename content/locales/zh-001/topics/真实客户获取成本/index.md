# 真实客户获取成本

真实客户获取成本（真实CAC）是获取一名新付费客户或登记患者的完全负载成本，不仅包括付费广告支出，还包括所有实质性促成该次获取的其他成本：代理与创意费用、营销技术与分析基础设施，以及——数字健康所特有的——用于接诊、资格核验和入职的临床或运营人力成本。它之所以作为一个独立指标存在，是因为广告平台报告的获取成本数字，经常性且大幅地低估了机构获取一名客户的真实成本。

## 为何重要

仅使用广告平台报告的单次获取成本数字来管理增长的数字健康机构，其资源分配决策系统性地基于遗漏了30%至50%真实获取成本的数字，因为这些平台数字仅捕捉媒体支出，排除了代理费用、营销技术许可，以及——对医疗保健而言至关重要的——每一位新患者在被计为已获取之前，临床或运营团队所投入的劳动密集型接诊与资格核验工作。这一差距在数字健康领域比大多数其他行业都更为重要，正是因为临床接诊人力昂贵且是强制性的，不同于电子商务，后者的一次"销售"基本上不需要类似的后台人力。针对人为偏低的CAC数字优化营销支出的团队，会系统性地过度投资于在平台仪表盘上看似便宜、但计算出真实CAC后其实昂贵的渠道。

## 计算方法

```
真实CAC = (付费媒体支出 + 代理与创意费用 + 营销技术与
           分析成本 + 临床/运营接诊人力成本) / 期间内
           获取的新客户或患者数

临床/运营接诊人力成本应根据完全负载人力成本（工资、福利、
管理费用）× 每位获取患者在接诊、资格核验和入职上所花费
的平均小时数来估算。
```

## 实例解析

一家数字健康公司在一个月内获取500名新患者。广告平台仪表盘报告的综合单次获取成本为120美元，基于6万美元的付费媒体支出。加上9000美元的代理费用、6000美元的营销技术成本，以及以每小时40美元的完全负载员工成本估算每位患者45分钟的接诊人力成本（500 × 0.75 × 40美元 = 1.5万美元），总获取成本达到6万 + 9000 + 6000 + 1.5万 = 9万美元。真实CAC为9万 / 500 = 180美元——比广告平台单独报告的120美元数字高出50%，而这才是真正应该用来指导渠道预算分配和单位经济决策的数字。

## 数据来源与注意事项

付费媒体支出和平台报告的单次获取成本直接来自广告平台本身（搜索、社交、程序化）；代理费用和营销技术成本来自财务或应付账款记录；接诊人力成本是最难准确获取来源的部分，通常需要进行时间与动作研究，或与运营领导层商定合理的估算，因为大多数机构并不天然地按获取追踪员工时间。在数据量允许的情况下，应按获取渠道分别计算真实CAC，因为每位患者的接诊人力成本在各渠道间往往相近，而媒体成本差异巨大，这意味着平台报告CAC与真实CAC之间的差距，在那些看似最便宜的渠道上按比例最大。

## 常见误区

- **仅依赖广告平台仪表盘**：平台报告的单次获取成本在结构上排除了代理费用、营销技术成本和接诊人力，不能替代真实CAC计算。
- **遗漏临床或运营接诊人力**：这在数字健康领域一贯是最常被遗漏的成本组成部分，通常也是平台报告成本与真实CAC之间差距的单一最大贡献因素。
- **在所有渠道间平均真实CAC**：一个综合的真实CAC数字可能掩盖某一渠道在计入负载成本后其实昂贵得多，即使它在广告平台上看起来最便宜。
- **未在接诊流程变化时更新人力成本估算**：接诊流程重新设计（例如自动化资格核验）可能显著改变真实CAC，陈旧的人力估算将无法准确反映当前数字。
