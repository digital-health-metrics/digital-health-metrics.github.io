# 医院再入院率

医院再入院率是指出院患者在特定时间窗口内——最常见为30天——非计划性再次入院的比例。对数字健康而言，这是与支付方经济利益和基于价值的医疗合同最直接相关的指标：无法证明对再入院率有可信影响的远程监测、出院后随访或数字化护理过渡项目，无论其参与度数字看起来多好，都不太可能获得持续的报销支持。

## 为何重要

非计划性再入院成本高昂、给患者带来困扰，而且在许多医疗系统中如今会被直接处罚：例如美国医院再入院减少计划（Hospital Readmissions Reduction Program）等制度，会降低对特定病种再入院率高于预期的医院的付款，这正是医院积极委托开发旨在降低再入院率的数字化出院后与远程监测项目的原因。相当一部分再入院被认为是潜在可预防的——由出院指导不充分、随访预约错过、用药理解错误，或未被察觉的症状恶化所导致，而设计良好的数字化接触点本可以更早发现这些问题——这正是数字化护理过渡工具所针对的缺口。再入院率应始终结合病例组合来解读：服务于病情更复杂、更严重人群的项目，其结构性基线再入院率会高于服务健康人群的项目，这与项目质量无关。

## 计算方法

```
30天再入院率 = 出院后30天内非计划再入院数 / 指标出院总数 × 100

从分子中排除：计划性再入院（例如预定的后续手术），以及
作为同一护理事件延续而非新入院的转院。

在比较不同患者人群或不同时期的比率之前，应尽可能使用公认
的病例组合或合并症指数进行风险调整。
```

## 实例解析

某医院在一个季度内为1200名心力衰竭患者办理出院。其中210人在30天内再入院，其中15人是为预定手术进行的计划性再入院，予以排除。非计划性30天再入院率为(210 − 15) / 1200 × 100 = 16.25%。针对其中400名患者（按临床风险而非随机方式选定）引入了远程监测项目，其非计划再入院率为14%，而未纳入项目的800名患者为18%。由于纳入项目是基于临床风险而非随机分配，这一差异只能作为提示性证据，而非项目效果的确证性证据，应结合风险调整分析来解读，而非直接采信表面数字。

## 数据来源与注意事项

再入院数据通常来自医院自身的入院-出院-转院（ADT）数据流，用于追踪同一机构的再入院情况，但再入院至另一家医院的患者根本不会出现在该数据流中，因此仅依靠单一医院的再入院追踪会系统性地低估真实再入院率，除非辅以区域健康信息交换数据、支付方理赔数据或州级全支付方数据库。将再入院归因于某个数字化项目需要谨慎：自愿加入远程监测项目的患者很少是出院人群的随机样本，因此对已加入与未加入患者的再入院率进行简单比较，往往会受到正是那些促使部分患者更倾向于加入项目的选择效应的干扰。

## 常见误区

- **比较未经风险调整的原始比率**：服务于病情更重人群的项目会显示出比服务健康人群的项目更高的原始再入院率，即使该项目本身更有效也是如此；比较前应始终进行风险调整。
- **低估转至其他机构的再入院**：仅依赖单一医院自身的ADT数据会遗漏转至其他机构的再入院情况，从而低估真实比率，尤其是在存在多个竞争性医院系统的地区。
- **自愿项目加入中的选择偏倚**：选择加入数字化随访项目的患者，在健康素养、社会支持或积极性方面往往与未加入的患者存在系统性差异，这会干扰任何简单的前后对比或加入/未加入对比。
- **将所有返回同一机构的情况都计为再入院**：计划性、预定的再入院（例如预定的第二阶段手术）并非出院失败的信号，应从分子中排除，而不应与真正的非计划返回混为一谈。
