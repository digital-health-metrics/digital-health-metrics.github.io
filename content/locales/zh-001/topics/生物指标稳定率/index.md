# 生物指标稳定率

生物指标稳定率是指登记患者中，通过联网监测设备——最常见的是低于130/80 mmHg等阈值的血压——在一段持续时期内（而非单一时间点）达到并维持临床定义目标范围的比例。它与生物指标改善率（参见该主题）不同：改善衡量的是相对基线的变化幅度，而稳定衡量的是一旦开始治疗或监测后，患者是否被可靠地维持在安全范围内，这对已接近目标或已在接受治疗的患者而言，是最重要的结果。

## 为何重要

对于慢性病项目中的很大一部分患者——尤其是高血压，其指南血压目标已被明确确立，并与心血管风险直接相关——临床目标不是一次性改善，而是持续控制，而在目标范围内外反复波动的患者所面临的风险，与仅改善一次后便维持稳定的患者截然不同。联网设备（蜂窝血压袖带、连续血糖监测仪）使持续测量稳定性成为可能，而不仅仅局限于门诊就诊时，从而发现那些诊室读数看似受控、但家庭读数却不稳定的患者——这种被称为"隐匿性高血压"的模式，仅靠定期的面对面测量是无法察觉的。报告稳定率而非仅仅报告某一时刻"达标"的快照，迫使项目正视其维持患者在范围内的一致性，而不仅仅是频率。

## 计算方法

```
生物指标稳定率 = 在测量期间内 ≥ 80% 读数处于目标范围内的患者数 /
                  在该期间内拥有最低数量有效读数的患者数 × 100

常见阈值示例：
  血压     —— 目标 < 130/80 mmHg（或适用于该患者风险特征
              的临床指南阈值）
  血糖     —— 按连续血糖监测指导的目标范围，报告为"目标范围
              内时间"

在将患者纳入分母前，应设定最低读数频率阈值（例如每周至少
3次读数），以避免读数稀少的患者显得人为地稳定。
```

## 实例解析

一个高血压远程监测项目招募了600名使用蜂窝血压袖带的患者，每人预期每周至少测量3次。其中540人在3个月的测量期间内达到了最低读数频率阈值，并被纳入分母。在这540人中，有350人至少80%的读数低于130/80 mmHg，生物指标稳定率为350 / 540 × 100 = 65%。因读数不足而被排除的60名患者，被单独报告为数据完整性缺口，既不计入"已稳定"组，也不计入"未稳定"组，因为他们的真实控制状态实际上是未知的，而非欠佳。

## 数据来源与注意事项

读数直接来自联网设备自身的数据流，比门诊测量更客观、频率也高得多，但设备放置和操作技术上的错误（尺寸或位置不正确的血压袖带）可能引入系统性偏差，而单次诊室验证读数未必能捕捉到这种偏差。目标范围的选择应遵循适用于患者具体风险特征和合并症的现行临床指南，而非单一通用阈值，因为指南目标会因患者年龄、肾功能和心血管风险而异。绝不应默认将读数频率低的患者视为"稳定"；将其透明地从分母中排除，比基于过少数据将其归类为受控或未受控更为诚实。

## 常见误区

- **将单次达标读数视为稳定**：稳定关乎特定期间内的持续控制，而非快照；应始终要求该期间内一定比例的读数处于范围内，而非单次合格测量。
- **悄悄排除读数稀少者而不加报告**：很少测量的患者并不自动等同于稳定或不稳定；应将其透明地从分母中排除，并将排除率作为单独的数据完整性指标报告。
- **忽视设备校准与操作技术误差**：安装不当的袖带或未经校准的设备可能使读数系统性地偏向某一方向，若不进行定期验证，从原始设备数据简单计算出的稳定率无法察觉这一点。
- **对所有患者使用单一通用目标范围**：临床指南目标因患者风险特征和合并症而异；对临床异质性人群应用单一笼统阈值，会导致部分患者相对其实际个体化目标被错误分类为已稳定或未稳定。
