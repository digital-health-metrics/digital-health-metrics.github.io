# 医生职业倦怠率

医生职业倦怠率是指报告显著职业倦怠症状的临床医生比例——通常通过经验证的调查工具评估情绪衰竭、去人格化，或个人成就感低落——而对数字健康而言，这一指标特别与面向临床医生的数字工具负担衡量指标一同追踪，例如用于文书工作或电子健康档案（EHR）记录的时间。之所以将其纳入数字健康指标框架，是因为设计不良的临床软件已被证实是职业倦怠的一个可衡量的促成因素，绝不应仅凭面向患者的指标来评估数字健康工具的成功，而忽视其对必须操作它的临床医生所造成的影响。

## 为何重要

数字健康工具经常以减轻临床医生行政负担为明确目标而被引入，但设计不良的电子健康档案工作流程、过多低价值的临床警报（参见临床警报忽略率），或笨拙的远程医疗界面，同样容易增加职业倦怠，而非减轻它——一款改善了面向患者参与度指标、却悄悄增加了临床医生文书负担的工具，并未为整个护理系统带来净正面的结果。职业倦怠在临床文献中与医疗差错、临床医生流失和护理质量下降密切相关，因此它是下游安全与劳动力可持续性问题的领先指标，而不仅仅是工作场所满意度方面的细枝末节。任何声称减轻临床负担的数字健康项目，都应能够依据已测量的基线来证明这一主张，而非仅将其作为设计意图来断言。

## 计算方法

```
医生职业倦怠率 = 得分超过经验证工具倦怠阈值的临床医生数 /
                  接受调查的临床医生总数 × 100

常用的经验证工具：马斯拉赫职业倦怠量表（MBI）、职业成就
感指数，或经过与更完整工具验证的单项倦怠筛查问题。

应一并报告可用的数字负担代理指标：
  每次患者接触的EHR系统内停留时间
  发生在预定临床工作时间之外的文书记录时间（"睡衣时间"）
```

## 实例解析

某医院系统在引入一款旨在减少笔记书写时间的环境临床文书记录工具之前，使用马斯拉赫职业倦怠量表对300名医生进行调查。基线数据显示，135名医生（45%）得分超过倦怠阈值，EHR审计日志数据显示，每位医生每天平均有58分钟的文书记录时间发生在预定临床工作时间之外。该工具推出六个月后，对同一批医生的重复调查发现，108人（36%）超过倦怠阈值，同时非工作时间文书记录时间降至每天34分钟。倦怠率与客观EHR代理指标的相关变化，都增强了该工具正在产生贡献的论证，尽管正式的前后比较仍应考虑同期其他并发的工作量变化。

## 数据来源与注意事项

职业倦怠调查数据来自定期（每年或更频繁）施测的经验证工具，应答率至关重要：低应答率存在无应答偏倚的风险，即倦怠程度最高的临床医生（最没有余力完成额外调查的人）在系统性上代表性不足，从而低估真实比率。源自EHR的数字负担代理指标——系统内停留时间、非工作时间文书记录时间、每次接触的点击次数——作为与定期调查数据互补的客观、持续可用的指标很有用，但在将其作为独立可靠的倦怠指标之前，应针对特定机构与调查报告的倦怠情况进行验证，因为系统内停留时间与真实倦怠之间的关系可能因专科和个人工作方式而异。

## 常见误区

- **仅依赖EHR代理指标**：系统内停留时间和点击计数在总体上与倦怠相关，但并不等同于倦怠本身，对于具有真正不同文书记录需求的个别临床医生或专科而言，可能具有误导性。
- **调查应答率低掩盖真实比率**：受倦怠影响最大的临床医生往往最没有余力应答自愿调查，这会使低应答率的结果人为地偏向看似更健康的数字。
- **在未考虑混杂因素的情况下将倦怠变化归因于单一工具**：倦怠受许多并发因素影响（人员配置水平、患者量、组织变革）；围绕某一工具推出的前后比较应尽可能控制这些因素，而非假设单一原因。
- **纯粹将倦怠视为个人韧性问题**：倦怠研究一致发现，工作量、系统设计和组织因素是主要驱动因素；将其仅仅归结为个别临床医生的问题，会使干预措施偏离数字工具和工作流程这一通常才是真正根本原因的方向。
